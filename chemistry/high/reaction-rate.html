🎯 影响反应速率的因素

点击每个因素查看其如何影响反应速率。拖动滑块改变参数。

🌡️ 温度

温度升高 → 分子运动加快 → 有效碰撞增多 → 速率增大
每升高10°C，速率约增大2~4倍

3

⚗️ 浓度

浓度增大 → 单位体积分子数增多 → 碰撞频率增大 → 速率增大

3

🧪 催化剂

降低活化能 → 更多分子达到反应能量 → 速率显著增大
催化剂不参与反应，反应前后质量不变

无催化剂

📐 接触面积

固体颗粒越小 → 表面积越大 → 接触越充分 → 速率越大
