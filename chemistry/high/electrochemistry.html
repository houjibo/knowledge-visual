原电池工作原理

负极(Zn): Zn → Zn²⁺ + 2e⁻ (氧化反应)
正极(Cu): 2H⁺ + 2e⁻ → H₂↑ (还原反应)
总反应: Zn + 2H⁺ → Zn²⁺ + H₂↑

电解池工作原理

阳极(+): 2Cl⁻ → Cl₂↑ + 2e⁻ (氧化)
阴极(-): Cu²⁺ + 2e⁻ → Cu (还原)
总反应: CuCl₂ → Cu + Cl₂↑

金属腐蚀与防护

吸氧腐蚀: Fe → Fe²⁺ + 2e⁻
O₂ + 2H₂O + 4e⁻ → 4OH⁻
总反应: 2Fe + O₂ + 2H₂O → 2Fe(OH)₂ → Fe₂O₃·xH₂O (铁锈)
