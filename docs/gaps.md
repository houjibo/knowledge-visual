# 项目差距与后续方向

最后核查：2026-11-07；基于仓库文件和静态引用扫描，而非全站人工审计。优先级是当前判断，不代表已排期；每次交付应复核相关项并把可执行工作转为 OpenSpec change。

| 优先级 | 事实或差距 | 下一步及验收方向 |
| --- | --- | --- |
| 高 | 已有 [逐页面静态盘点](assessments/README.md)、330 页桌面浏览器加载冒烟，以及四条路径的桌面及窄屏浏览器自动化，但缺乏全站交互、知识准确性和无障碍验证；静态检查无法证明这些行为。 | 选取代表性学科与年龄的学习路径，记录操作、窄屏、键盘和内容依据；按证据拆分修复。 |
| 高 | 三个试点页面的顶层模式按钮已支持键盘；机械运动页面的速度和图像选择也已支持键盘；源码仍有多页使用 div.tab，具体影响尚未逐页确认。 | 盘点用途，按页面批次替换并用真实键盘及回归测试验证。 |
| 中 | 折线统计图的并列极值及无上升、下降区间已修复并有浏览器回归；步数题单位和挑战标题已校正；其他图表题型及单位、教学解释尚未系统核验。 | 按主题核对实际图形、问题、单位及反馈，覆盖边界和错误答案。 |
| 中 | 数学新进度已按学段隔离；六个同名主题的旧记录无法自动归属，原数据保留并提示，尚无人工确认界面。 | 根据学习者反馈评估历史记录确认流程，保留旧数据与回退能力。 |
| 中 | 首页已支持按主题标题及现有导航文字跨学科查找；同义词、搜索排序和跨学科学习路径的真实需求尚未核实。 | 根据真实学习任务检查搜索与筛选是否有效，按证据完善词汇与学习路径。 |
| 中 | 数学学段主题清单及物理、化学学段进度分母已校准，后者及数学初中至大学清单有静态漂移检查；历史无效 slug、单个主题是否正确记录完成，以及科学“沉与浮”已验证测验得分和完成记录刷新恢复，其他学科进度仍未全面验证。数学、物理、化学各学段及科学的主题页均可静态找到 markDone 调用，但这不能证明触发条件正确。 | 按实际学习路径检查完成记录与统计口径，发现问题后单独修复。 |
| 高 | 全站冒烟多次发现随机题目生成可能无限循环，已修复相关主题，包括有余数除法的四类选择题；其余随机生成逻辑未系统盘点。 | 盘点无界重试与候选数量，优先为边界或可能阻塞页面的场景增加确定性测试。 |
| 中 | 共享资源和自包含页面并存，覆盖与一致性未盘点；直接合并可能影响既有交互。 | 先梳理重复与依赖，选可观察的单一重构切片，保持行为。 |
| 中 | 静态检查只覆盖部分引用，未覆盖动态路径、CSS 资源、外链及浏览器异常。 | 根据实际缺陷逐步扩展检查；失败时保留证据。 |
| 低 | README 已移除过期的手工主题数；未来目录结构变动时仍需同步说明。 | 内容交付时核对并更新入口文档。 |
