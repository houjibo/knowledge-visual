# 项目差距与后续方向

最后核查：2026-11-07；基于仓库文件和静态引用扫描，而非全站人工审计。优先级是当前判断，不代表已排期；每次交付应复核相关项并把可执行工作转为 OpenSpec change。

| 优先级 | 事实或差距 | 下一步及验收方向 |
| --- | --- | --- |
| 高 | 已有 [逐页面静态盘点](assessments/README.md)，但缺乏全站交互、知识准确性和无障碍验证；静态检查无法证明这些行为。 | 选取代表性学科与年龄的学习路径，记录操作、窄屏、键盘和内容依据；按证据拆分修复。 |
| 高 | 数学四学段共用 `kv-math-progress`，高中和大学等有同名 slug；旧记录无法区分来源，学段徽章可能同时计入两边。 | 先调查同名冲突及兼容旧数据的迁移策略，再设计独立变更；不得静默丢失学习进度。 |
| 高 | 目前按学科、学段和知识地图进入，尚未核实跨学科学习路径、搜索等需求。 | 先从真实学习任务确定发现内容的障碍，再用小切片验证，不预设模仿参考站的所有功能。 |
| 中 | 数学学段主题清单及物理、化学学段进度分母已校准，后者及数学初中至大学清单有静态漂移检查；历史无效 slug、单个主题是否正确记录完成，以及其他学科进度仍未全面验证。数学、物理、化学各学段及科学的主题页均可静态找到 markDone 调用，但这不能证明触发条件正确。 | 按实际学习路径检查完成记录与统计口径，发现问题后单独修复。 |
| 中 | 共享资源和自包含页面并存，覆盖与一致性未盘点；直接合并可能影响既有交互。 | 先梳理重复与依赖，选可观察的单一重构切片，保持行为。 |
| 中 | 静态检查只覆盖部分引用，未覆盖动态路径、CSS 资源、外链及浏览器异常。 | 根据实际缺陷逐步扩展检查；失败时保留证据。 |
| 低 | README 已移除过期的手工主题数；未来目录结构变动时仍需同步说明。 | 内容交付时核对并更新入口文档。 |

参考站的章节组织、阅读引导和循序学习值得调研；其视觉风格或信息架构是否适合儿童及各学段，仍需实际验证。

阶段目标、优先顺序和验收标准见 [可视化学习站演进计划](plans/visual-learning-roadmap.md)。
