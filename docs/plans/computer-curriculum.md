# 计算机课程设计

状态：持续建设。当前站点开放小学算法与初中数据表示主题；其他学段尚未建立课程入口。实现和交互验收以各项 [OpenSpec 变更](../../openspec/changes/)及[差距台账](../gaps.md)为准。

## 目标与边界

帮助学习者观察计算机如何表示信息、执行指令、组织程序并连接系统。每个主题应说明目标，允许主动操作，解释状态变化，并用练习或挑战检验理解。计算机课程聚焦计算系统、算法、数据、编程、网络与安全；分类学习和神经元模型归入[人工智能课程](ai-curriculum.md)。

当前主题在静态页面本地运行，不执行用户代码、不要求账号、不上传输入或进度。完成记录保存在当前浏览器。

## 已交付主题约束

### 指令小机器人

- 用有限网格、起点、目标、墙面和可见指令列表展示算法，提供单步与运行操作。
- 每条指令造成可解释的位置变化；撞墙不越界；到达目标时显示反馈并记录完成。
- 让学习者看见指令顺序决定结果；后续可增加循环和条件分支。

### 二进制像素工坊

- 8 个可访问的二进制位与权值可见，切换后同步更新二进制表示、十进制数与像素明暗。
- 提供目标编码及检查反馈；正确答案可完成学习记录，错误答案说明差异并允许再试。
- 说明练习只展示有限位宽的编码关系，不把单色值表述为完整图像文件格式。

## 共通验证要求

- 从首页进入学科、学段、主题，主题返回对应学段与学科；搜索按主题、计算机学科和实际学段直达页面。
- 关键操作使用有名称的原生控件，支持键盘、可见焦点和状态播报；在 320 CSS 像素宽度检查页面无横向溢出。
- 核心交互使用本地 HTML/CSS/JavaScript 与相对资源路径；静态服务、仓库子路径和直接文件模式不依赖服务器、账号或外部模型。
- 浏览器测试覆盖初始状态、边界/错误输入、正确完成、重置、存储拒绝和窄屏；交互测试不代替教学审校。

## 课程依据

- 教育部《义务教育信息科技课程标准（2022 年版）》提供数据、算法、网络、信息处理和安全等内容方向。[官方文件 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582361024968.pdf)
- CSTA PK-12 计算机科学标准提供算法、编程、数据、系统、安全、人本设计与伦理等 K–12 参考。[CSTA](https://csteachers.org/pk12standards/about/)

这些参考不表示本站获得官方认证或完整覆盖对应标准；具体主题仍需核对知识来源、年龄适配和页面解释。
