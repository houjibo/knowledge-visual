## 目标与边界

帮助学习者观察计算机如何表示信息、执行指令、组织程序并连接系统。每个主题应说明目标，允许主动操作，解释状态变化，并用练习或挑战检验理解。计算机课程聚焦计算系统、算法、数据、编程、网络与安全；分类学习和神经元模型归入[人工智能课程](ai-curriculum.md)。

当前主题在静态页面本地运行，不执行用户代码、不要求账号、不上传输入或进度。完成记录保存在当前浏览器。

### 循环指令工坊（已公开验收）

**学习目标**：把重复出现的同一组指令表示为“重复 N 次”；观察当前轮次、轮内指令和累计动作；比较循环块与展开序列的逐步执行结果。两种表示执行相同的动作次数，循环让书写更简洁，不能据此声称实际执行更快。

**当前范围**：使用固定小网格、由两条有限方向指令组成的循环体和 1–4 次重复，提供循环块与展开序列的并排表示，以及单步、连续执行、暂停和重置。目标关卡要求学习者调整重复次数，完整执行后判断最终位置；使用页面内固定数据与原生控件，运行和进度保持本地。嵌套循环和自由代码执行留待后续设计；条件分支由独立主题承接。

| 验收项 | 可观察条件 |
| --- | --- |
| 循环与展开对应 | 每一步的方向、位置和累计动作一致；总动作数等于重复次数乘以每轮指令数；同时显示当前轮次与轮内指令。 |
| 完整执行与反馈 | 执行完整个程序后判断目标，途中经过目标不会提前完成；次数不合适、碰到边界或结束未达目标都有原因说明，允许修改后重试。 |
| 参数变更与重置 | 修改次数或循环体时停止连续执行，将位置、轮次、当前指令和累计动作重置；旧计时器不会继续推进，重置后可再次运行。 |
| 键盘与窄屏 | 主要操作可用键盘完成且焦点可见；状态可读；在 320 CSS 像素宽度无横向溢出，减少动态效果时仍可单步学习。 |
| 进度与存储失败 | 正确完成关卡才写入主题标记；目录、首页数量与搜索同步更新；刷新后进度一致，存储拒绝或记录损坏时仍能操作并如实提示保存状态。 |
| 运行与发布 | 相关功能测试覆盖正常、错误和边界状态；检查静态服务、仓库子路径、直接文件打开及发布包中的导航与资源。 |

### 条件分支机器人（本地验收通过，待公开发布）

**学习目标**：先求一个条件的真假，再且只执行 `if` 或 `else` 中的一个动作。学习者可选择检查右侧或上方是否有障碍，并分别编排成立、不成立时的方向动作；检查方向和动作方向独立，条件为真不保证动作安全。

**当前范围**：固定 5 列 3 行地图，起点在第 1 列第 3 行，目标在第 5 列第 1 行，墙位于第 3 列第 3 行和第 5 列第 2 行。方向采用地图绝对方向，机器人没有朝向。每次手动操作只做一次完整判断和一次动作，没有自动循环或自由代码执行。

| 验收项 | 可观察条件 |
| --- | --- |
| 判断与动作快照 | 同时显示上次判断前位置、检查格、墙/边界/畅通结果、真假、唯一选中分支、动作和动作后位置；移动后不在新位置重新计算旧条件。 |
| 两条有效规则 | 默认检查右侧、真向上、假向右，及检查上方、真向右、假向上，均可实际探索至目标；不以配置等于示例代替执行和完成判断。 |
| 碰撞与完成 | 碰墙或越界时不移动但计一次判断；必须在同一规则下无碰撞地观察真假两种结果并抵达目标，才赢得主题完成资格。 |
| 编辑、重置与进度 | 任一规则变化清空本次探索；回到起点保留规则，恢复示例还原默认；已有完成及已赢得但未保存的资格保留。保存成功按 `SubjectProgress.markComplete` 返回值确认，损坏原文不覆盖，失败可重试。 |
| 可访问与发布 | 关键操作支持键盘、有标签和可见焦点，320px 无横向溢出；file 协议、项目子路径、搜索、目录和小学 3 主题/计算机 4 主题进度均需验证。 |

本地完整检查通过：1896项功能回归、开发站及发布包各363页、8项发布路径；证据见[核查记录](../assessments/condition-branches-2026-11-12.md)。当前仍待主分支集成及公开发布验收，不代表已取得真实学习者验证。

## 已交付主题约束

### 指令小机器人

- 用有限网格、起点、目标、墙面和可见指令列表展示算法，提供单步与运行操作。
- 每条指令造成可解释的位置变化；撞墙不越界；到达目标时显示反馈并记录完成。
- 让学习者看见指令顺序决定结果；循环与条件主题继续展示重复结构和真假判断如何组织指令。

### 二进制像素工坊

- 8 个可访问的二进制位与权值可见，切换后同步更新二进制表示、十进制数与像素明暗。
- 提供目标编码及检查反馈；正确答案可完成学习记录，错误答案说明差异并允许再试。
- 说明练习只展示有限位宽的编码关系，不把单色值表述为完整图像文件格式。
