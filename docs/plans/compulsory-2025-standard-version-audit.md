# 义务教育课程标准 2025 年日常修订：来源校正与迁移任务

核查日期：2026-11-13。此前[课程来源登记](curriculum-sources.md)把 2022 年版 `CE22` 当作小学、初中现行基线；继续核对时发现“2022 年版 2025 年修订”的日常修订版。本站现改用 `CE25` 标识待重建的现行要求，`CE22` 保留为历史对照。**这只确定版本迁移，不代表已判明每条学习要求的变化或本站页面的新版覆盖状态。**

## 迁移验收顺序

1. 为五科保存修订版原文的稳定出处、文件版本和印刷页；将 `CE22` 对照表显式标为历史，防止历史汇总被当成现行全站覆盖率。
2. 逐条比较 `CE22→CE25` 的内容要求、学业要求、跨学科主题和学业质量，标记“保留、改写、新增、删除、待判”；不能只替换来源 ID 或链接。
3. 以 `CE25` 重建各学段稳定 ID、页面证据与已验证／部分／缺失／未映射状态；先复核有理数和初中信息科技试点，再扩展所有适用格。
4. 另查人教版示例教材的实际版次和完整公开目录；版次与课标版本分别记录。只有逐项复核通过后才更新[全站差距矩阵](curriculum-gap-map.md)的现行要求数。

当前可以复算的只有站点页面供给数；`CE25` 下的要求总数、已验证覆盖数和新旧条款差异均未完成核查。
