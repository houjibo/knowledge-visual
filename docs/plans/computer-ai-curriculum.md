# 计算机与人工智能课程地图索引

计算机和人工智能已拆分为两门学科；以下文档分别记录课程范围、已交付主题和后续候选内容：

- [计算机课程设计](computer-curriculum.md)：算法、数据表示、程序结构、系统与网络。
- [人工智能课程设计](ai-curriculum.md)：数据分类、模型评价、神经网络、可靠性与责任实践。

两个学科共享可视化学习的交付约束：主题应有可解释的学习目标、可操作模型和诚实反馈；演示使用本地虚构数据，不接收身份或敏感信息，也不调用外部 AI API。每一项新内容按独立 OpenSpec change 推进，课程地图中的候选项不表示已实现或已通过教学验收。
