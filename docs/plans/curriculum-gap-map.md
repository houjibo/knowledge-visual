# 全站课程覆盖差距：首轮基线与任务计划

基线日期：2026-11-13；范围为本站现有六个学科、四个学习阶段，另列模拟世界。依据与版本见[课程来源登记](curriculum-sources.md)，执行契约见[OpenSpec 提案](../../openspec/changes/curriculum-source-gap-baseline/proposal.md)。课程标准是主线；用户选择现行审定人教版作能适用学科的章次示例，小学科学采用人教/鄂教版，义务教育信息科技、AI 和大学按来源例外处理。本页是**提案和待核对清单**，不是已完成的课程认证。

这里的“全站”指目前公开导航中的数学、物理、化学、科学、计算机和人工智能。语文等首页预告类目及国家课程中本站尚未设立的学科，不在本轮分母内；若决定扩展学科，应先独立确定范围与来源，再扩大矩阵。

## 如何计算距离

- **供给基线**：从[逐页清单](../assessments/page-inventory.json)统计主题 HTML。当前 334 个学科主题、10 个模拟场景；项目总计 378 个 HTML，其中还包括目录、首页和兼容入口。一个页面可含多个知识点，多个页面也可能重复同一目标。
- **课程距离**：正式分母应是选定来源中逐条可观察的学习要求，分类为“已验证覆盖／部分覆盖／缺失／未映射／不适用”。只有逐条拆解、链接到页面和内容/交互核查之后，才可算已验证覆盖率。**当前 19 个适用学科×阶段均未完成这种逐条交叉映射，故全站覆盖百分比不可计算。**这表示审计尚未完成，不表示现有学习内容的覆盖为零。
- **可见预警**：19 个适用格均有至少 1 个主题；其中 5 格只有 1–2 个主题：初中、高中、大学计算机与小学、大学人工智能。它们是先核对的候选，不据页数直接判定知识缺失程度。
- **适用边界**：小学物理和小学化学主要融入小学科学，暂不设独立站点学段；“初中科学”在义务教育课程方案中可作为物理/化学/生物学的替代安排，本站是否设置该独立入口待决；高中和大学“科学”不是本站选定的统一独立课程。五格保持“范围待定／不单列”，不算成已覆盖或缺失。

## 分批执行计划

1. **P0：来源可追溯（当前）**。保留 CE22、HS20、AI25、教材目录与大学参考的版本链接；为 24 格标适用性，生成本页页面基线。已选六三学制、人教版现行审定教材为适用学科的章次示例；逐册版次和公开章目仍须核对。验收：每格都有来源和边界，`334 + 10` 可由清单复算。
2. **P1：建立可计算分母**。先选高中数学和初中计算机作为两种粒度试点：从原始标准的内容要求与学业质量提取稳定 ID、学习目标、必修性和来源位置，再把本站主题、练习与核查证据逐条连上。通过同行复核后依次完成其余 17 格；大学先定义基础轨。验收：每格 `已验证+部分+缺失+未映射+不适用` 与已拆解要求总数一致，尚未拆解的范围单列；全局覆盖率只有在适用范围均已拆解且“未映射”为零时才发布。
3. **P2：按价值补齐**。优先审查五个稀疏格及真正缺失的基础先修，再审已有大页的教学准确性与交互；每个新主题独立 OpenSpec、小步提交、桌面/移动/键盘/320px/file/子路径/公网核查。每批结束更新矩阵和总数，不把发布成功当课程要求自动通过。
4. **P3：向学习者呈现**。映射经审校后，再评估公开的可交互课程地图：学科/阶段/主题筛选、学习路径、来源说明与未覆盖提示。先验证一科，再决定是否推广；内部“缺口”状态与学习者的完成进度保持分离。

已知页面体验、质量和发布风险继续在[差距台账](../gaps.md)追踪；本计划只解决课程范围和优先级的可见性。下一步工作以[OpenSpec tasks](../../openspec/changes/curriculum-source-gap-baseline/tasks.md)为准。
