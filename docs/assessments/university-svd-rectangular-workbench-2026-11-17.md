# 大学数学：矩形矩阵 SVD 有限工作台核查

日期：2026-11-17。课程依据：[MIT 18.06SC 奇异值分解](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/positive-definite-matrices-and-applications/singular-value-decomposition/)。该课程说明 `A=UΣVᵀ`，非零奇异值是 `AᵀA` 特征值的平方根，奇异方向连接四个基本子空间。本站使用 3×2 有界整数矩阵，只展示薄 SVD 的有限案例。

## 问题与设计

此前[矩阵变换](../../math/uni/matrix.html)只有二维变换图示，没有奇异值预测、零空间或乘回任务。新增[工作台](../../math/uni/svd.html)：学习者编辑矩阵和向量，预测 Gram 迹、秩、零奇异值和 `Ax`；正确后揭示非零奇异方向、零空间、薄分解及误差。绘图是在左奇异基中的像空间坐标，满秩为椭圆，秩 1 为线段，秩 0 为一点。

模型用整数精确计算 Gram 迹、行列式及秩；不同方向的特征值、单位向量与乘回用浮点数，并在页面显示近似与最大元素误差。零奇异值不作除数，零矩阵展示二维零空间；相同奇异值时选标准右基，不暗示方向唯一。主动查看示范不记完成，编辑撤销旧答案。
