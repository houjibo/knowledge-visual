# 首页主题查找试点（2026-11-07）

首页的本地目录来自站点页面标题及静态导航链接文字，按页面路径保留主题身份。本次生成包含 316 个主题，覆盖数学、物理、化学、科学；每个主题在当时至少有一条来自导航的文字。学科与学段来自目录路径，不能据此推断先修关系或教学质量。

重新生成：`python3 scripts/build_topic_catalog.py`；检查漂移：`python3 scripts/build_topic_catalog.py --check assets/topic-catalog.js`。主题或导航变更后还应按 [页面清单说明](README.md) 更新页面盘点。两个检查均已纳入 `npm run check:static`。

浏览器专项验证覆盖桌面及模拟窄屏：导航别名（例如“加法”）、跨学段同名主题、学科和学段筛选、空结果、键盘清空、直接打开本地文件、禁用脚本及目录加载失败。桌面浏览器人工检查了“导数”结果和排版。

查找只匹配现有文字，并非语义检索；未验证真实用户检索习惯、相关性排序、真实移动设备或所有页面的教学内容。主题标题与导航描述来自现有页面，不代表它们已经过知识审核。
