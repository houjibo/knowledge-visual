# 数学进度学段隔离（2026-11-07）

四学段原来共用 `kv-math-progress`，文件扫描确认 `circle`、`derivative`、`fractions`、`probability`、`sets` 和 `statistics` 出现在多个学段。旧记录只有 slug，无法可靠判断学段。

新完成记录写入 `kv-math-progress-v2`，以 `primary:`、`middle:`、`high:`、`uni:` 加主题 slug 区分；不会修改或删除旧键。无同名冲突的旧记录继续作为回退显示；同名旧记录不自动归属学段，数学入口列出受影响主题，允许学习者重新完成对应学段的内容。首页将旧记录与新记录去重后给出保守总数，存在同名旧记录时显示提示。清除旧回退时写入新格式的覆盖标记，旧数据仍保留。

冲突清单由 `python3 scripts/check_site.py` 对照实际学段文件检查；新增跨学段同名主题时需同步各处规则。浏览器回归覆盖高中/大学导数、小学/初中分数、未冲突旧记录、同名旧记录、清除与刷新、两个标签页依次写入、禁用存储、仅写入失败和 Chromium 的 `file://` 场景。测试使用隔离浏览器上下文，不操作真实学习者的数据。

回退到旧版本时仍可读取原 `kv-math-progress`，但旧版本不认识新格式，因此回退期间新完成记录不会显示；重新使用新版本后新键仍保留。不同浏览器对 `file://` 存储有不同策略；本次只验证 Chrome，禁用存储或写入失败时状态不会持久化；两个标签页依次写入已验证，并发同时写入不具备事务保证。旧同名记录仍需学习者自行确认，不能从现有数据恢复精确学段。

后续为小学、初中、高中、大学进度脚本增加损坏数据保护和失败后重试合并：拒绝覆盖非对象或无法读取的原始数据，在本页保留待写变更，恢复写入时与最新有效记录合并。浏览器回归覆盖四学段损坏内容、读取被拒绝、另一标签顺序写入及恢复；并发同时写入仍不具备事务保证，刷新会丢失未保存的本页变更。
