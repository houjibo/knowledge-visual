# 小学相邻交换排序实验室核查

## 缺口与教学边界

小学计算机已有顺序指令、循环、分支和顺序查找；在这次变更之前，学习者无法逐对操作并解释排序中的交换、轮次和右侧已就位区域。新增固定的五张不同数字卡片，先预测第一轮交换次数，再逐对比较。左数大于右数才交换；每轮跳过右侧已就位数字；整轮没有交换即可停止。该页面展示冒泡排序的一种有限实现，不用比较次数推断现实数据处理速度，也不声称五张卡片可代表所有输入。

规则参照 [MIT OCW 6.100L 排序讲义](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/mit6_100l_f22_lec24.pdf)和 [Virginia Tech OpenDSA Bubble Sort](https://opendsa-server.cs.vt.edu/ODSA/Books/pubbook/odsa-all/fall-2019/Public_Instance/html/BubbleSort.html)。固定卡片、第一轮预测和两类输入的完成门槛由本站设计，未经过真实学习者效果研究。

## 验收范围

| 风险 | 检查方式 |
| --- | --- |
| 排序步骤和轮次错误 | 纯模型用独立参考算法核对五数 120 种排列的每一步；浏览器核对默认、原本有序和逆序输入的交换、比较次数、右侧已就位区域和无交换早停。 |
| 提前泄露答案或虚假完成 | 第一轮最后一次比较后才反馈预测；预测错误、只完成一类或只比较部分卡片均不保存。两类都完整且预测正确后才尝试保存。 |
| 自动计时跨轮 | 连续、暂停、更换预置、重置、隐藏页面时旧计时器不得继续推进。 |
| 进度误写 | 损坏记录原文保留，拒写不显示已保存，已赢得资格可在重置后重试；目录和首页只计有效主题。 |
| 静态发布和可用性 | 键盘及 320px、减少动态、直接文件、发布包子路径、公开 revision、资源一致性与公网交互分别核对。 |
