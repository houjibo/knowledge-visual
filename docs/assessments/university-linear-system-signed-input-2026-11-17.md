# 大学线性方程组：有符号输入与消元一致性

核查日期：2026-11-17。[MIT 18.06《Linear Algebra》课程大纲](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/pages/syllabus/)把消元、主元、回代和完整求解列为基础目标；[大学线性代数差距对照](university-linear-algebra-mit-18-06-2026-11-17.md)已记录本站局部证据及未覆盖范围。本轮只修复现有三元高斯消元交互的输入一致性，不宣称完成整个课程目标。

[线性方程组页](../../math/uni/linear-systems.html)原来的第二行固定显示 `y −`，默认 z 系数却为正 1，增广矩阵也使用正数。现在 x、y、z 和右端常数均明确标为有符号输入，动态方程预览使用同一组数；负系数显示减号，零系数保留，矩阵和求解不再读取另一种符号。输入仅接受绝对值不大于 100 的有限数；空值、非法数或越界时标出错误、停止自动播放、清除旧步骤与结果，并禁用消元按钮。纠正后从新系统的初始状态重新计算。该限制只约束教学输入规模，不保证任意病态矩阵的数值稳定性。

桌面和移动专项共 6 项通过：正负零系数预览、初始增广矩阵、唯一解代回、无效输入撤销旧解、修复后重新求解、键盘、320px、静态文件直开与构建子路径。320px 截图中四列输入自动分为两列，方程预览和按钮无横向溢出。完整 `npm run check` 通过：全站功能测试 2600 项通过、8 项按条件跳过，401 页加载与发布构建专项 3 项通过。远端工作流及公网验收待补；任意秩亏矩阵的完整参数解仍须独立完善。变更契约见[OpenSpec](../../openspec/changes/university-linear-system-signed-input/proposal.md)。
