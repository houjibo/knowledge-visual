# 高中化学平衡模型一致性核查

日期：2026-11-23。范围：`chemistry/high/reaction-rate.html` 的 A⇌B 平衡建立和 N₂ + 3H₂ ⇌ 2NH₃ 平衡扰动两段。先前[速率概念与键盘核查](high-reaction-rate-concept-access-2026-11-23.md)已将粒子速率指标限定为示意量，本次继续核两段平衡数值。

## 可复现差距

- 原 A⇌B 模块的“逆反应开始”在变量互换后仍从纯 A 开始；“双向开始”趋向与另两个按钮相反的组成。浓度、正逆速率使用不同的经验式，所谓“平衡线”每帧取当前 A 值而移动，不能验证动态平衡。
- 原合成氨模块对温度、压强采用固定加减计数并乘速率倍率；加 N₂ 只改 N₂ 和速率条，却宣称 NH₃ 将增多。重复操作触及 `Math.max(1, n)` 钳位后破坏氮氢守恒。它没有平衡商、目标 K 或动力学模型，速率条也不是可解释的正逆反应速率。

## 模型与依据

- [IUPAC 化学平衡定义](https://goldbook.iupac.org/terms/view/C01023)指出平衡时正逆速率相等、组成表面保持不变；[质量作用定律条目](https://goldbook.iupac.org/terms/view/08184)同时限定从浓度写速率律的适用条件。本站 A⇌B 明示为封闭恒容、1:1 一级**教学模型**，采用 k正=0.5、k逆=0.2、A+B=1，故平衡 A≈0.286、B≈0.714，正逆模型速率各≈0.143。三个起点只改变初始组成；曲线、柱图与读数取同一解析状态，时间为相对模型量。
- [IUPAC 平衡常数定义](https://goldbook.iupac.org/terms/view/E02177)按化学计量数构造平衡表达式。合成氨模型用理想气体相对分压的 `Q=p(NH₃)²/[p(N₂)p(H₂)³]`，以初始 `(8,24,12)` 在压强档位 1 的 Q 定基准 K。温度方案用 K×1/4 或 K×4 表示放热反应方向，压强方案为相对档位 2 或 0.5；每次求 `Q=K` 的新平衡，份额沿 `(−ξ,−3ξ,+2ξ)` 改变。加料时总压保持当前档位，容器体积可变。
- 合成氨页不从计量式推断真实反应速率；已删除没有动力学根据的速率条和工业压强数字。温度方案、粒子份额和时间均不是实测量，理想气体模型不代表真实高压合成氨设备。

- `tests/browser/reaction-equilibrium-model.spec.js` 在桌面/移动核三个起点、正逆读数和状态、六类扰动、连续操作、重置、320px 键盘、`file://` 及发布子路径。原画布与速率概念专项共 10 项复跑通过。320px 两段截图已人工检查。
