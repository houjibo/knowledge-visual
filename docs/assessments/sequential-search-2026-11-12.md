# 小学顺序查找实验室核查

## 缺口与教学边界

小学计算机已有顺序指令、循环和条件分支主题，缺少能观察逐项查找、早停与完整扫描区别的页面。本站用三组固定的五张无序数字卡片，学习者先预测比较次数，再逐张执行；“找到”只说明这一组卡片中有目标，“未找到”只在五张均已比较后成立。目标 9 在三组卡片中都不存在。排列变化不是排序，不用本主题推断二分查找或现实数据库性能。

资料参照：[CS Unplugged 查找算法](https://www.csunplugged.org/en/topics/searching-algorithms/)说明顺序查找和数据排列关系；[MIT OCW Searching and Sorting](https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/resources/lecture-12-searching-and-sorting/)提供算法教学背景。固定卡片、预测题与完成门槛是本项目的教学设计，未经过真实学习者效果研究。

## 验收范围

| 风险 | 检查方式 |
| --- | --- |
| 直接跳到匹配项、错误比较次数 | 独立位置预期核对三组顺序 × 六个可选目标；逐步轨迹、早停、未找到五次与终止后稳定。 |
| 预测泄露或虚假完成 | 浏览器验证开始前必选预测、结束才给正误；错误预测和未完成轮不计入，找到与未找到均正确后才写入。 |
| 自动计时串轮 | 连续、暂停、更换目标、重置后核对比较次数和旧计时器不会再推进。 |
| 进度误写 | 损坏记录原文保留、失败可在重置后重试；目录和首页只数有效主题。 |
| 静态发布可用性 | file 无远程运行请求；320px 键盘与减少动态；构建后的项目子路径加载与操作；公网 revision 与资源需独立核对。 |

## 本轮结果

- 纯模型两项测试覆盖三组顺序、六个可选目标的所有比较序列，以及输入复制和非法边界。
- 专项 Playwright 桌面/移动模拟视口 **19 通过、1 项按配置跳过**；包含发布包子路径的一次桌面交互。
- 第一轮完整检查发现两处旧主题浏览器测试仍按计算机 4 个主题断言，实际新增后分母为 5；修正后相关 20 项通过。第二轮 `CI=true npm run check` 全部通过：OpenSpec 严格校验 **254 项**，功能回归 **1969 通过/3 项按配置跳过**，开发站 **365 页**、发布交互 **12 项**、发布包 **365 页**。结束后对补强的连续运行终点断言单独复验，专项仍为 **19 通过/1 项按配置跳过**。
- GitHub Actions 与公网操作结果待本轮后续记录，不以本地通过代替公开验收。

## 剩余范围

还需真实学习者测试目标描述、预测难度和反馈是否易懂；真实设备、屏幕阅读器与整页无障碍仍未全面验收。后续算法课程还可补排序、编码、数据安全等主题，优先级以课程差距和新证据决定。
