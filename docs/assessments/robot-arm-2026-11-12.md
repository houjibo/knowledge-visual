# 二维机械臂模拟核查

## 学习问题与模型边界

原有模拟涵盖齿轮传动、曲柄滑块与流水线，但没有让学习者把两个关节角、末端位置和目标可达范围联系起来。新增二维两连杆机械臂，先预测拾放目标是否在可达环带内，再检查边界并观察两种肘向。设基座 O=(0,0)，肘点 A=(L1 cosθ1,L1 sinθ1)，末端 B=A+(L2 cos(θ1+θ2),L2 sin(θ1+θ2))；两关节均允许整圈旋转时目标距离 r 满足 |L1−L2|≤r≤L1+L2。

依据：[MIT OCW 2.086 Problem Set 5](https://ocw.mit.edu/courses/2-086-numerical-computation-for-mechanical-engineers-fall-2012/3a6ea77d5d5d63905832eb9a597293db_MIT2_086F12_pset5.pdf)的两关节坐标关系及[Modern Robotics](https://modernrobotics.northwestern.edu/nu-gm-book-resource/inverse-kinematics-of-open-chains/)的平面2R工作空间。本站目标预设、交互和预测题为教学设计，不模拟真实设备关节限位、负载、碰撞、抓取与安全控制。

## 验收点

| 风险 | 证据 |
| --- | --- |
| 图形与数值不同步 | 模型穷举杆长和角度，独立计算两段距离；浏览器读取真实 SVG 端点、圆半径与文字读数。 |
| 边界或逆解错误 | 伸直、折叠、内外包含、不可达无解、两肘向和末端误差独立核对；极值边界不提供重复的第二肘向。 |
| 预测与操作误导 | 未预测不能显示姿态；错判可更正；杆长或目标变化清除旧判断；图上目标可拖动，数字框与预设等效。 |
| 静态可用性 | 桌面/320px移动、键盘、减少动态、file直开、无进度写入、首页/目录搜索和项目子路径。 |
| 公开发布 | 完整门禁、Actions七项、公开revision与资源、实际浏览器操作需分别核对。 |

## 当前结果

- 纯模型五项测试通过，包含全杆长与角度组合、四象限可达网格、两种逆解、边界、非法输入和调用方输入不变。
- 新场景桌面/移动专项 20/20，通过真实 SVG 长度与端点、预测纠错、双肘向、指针/数字输入、320px键盘、file直开、无进度以及构建后子路径；五场景联合回归 90/90。静态门禁通过。
- 完整门禁和公开发布待执行；未通过前不记为已验收。

## 后续

需真实学习者检查“肘角是相对第一杆”“可达不等于可安全执行”是否易懂；真实触屏与屏幕阅读器仍待专项验证。后续可考虑带有限位的工作空间、抓取或分拣，但需另立模型和验收。
