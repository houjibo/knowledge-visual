# 高中查找策略对照实验室核查

## 缺口与教学边界

计算机学科在这次变更前没有高中入口。小学顺序查找和排序可以展示算法步骤，但没有让学习者比较具体输入的查找次数、解释二分查找排除半边的依据，或区分“有序序列上查找较少”与“为一次查找先排序也有成本”。本轮以 7 和 15 个固定不同整数、首位/靠后/未出现三类目标，把顺序查找与二分查找并排逐步执行。乱序预置只允许顺序查找，不伪造二分结果。

依据：[MIT OCW 6.100L Lecture 24](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/mit6_100l_f22_lec24.pdf)说明二分需有序，以及一次排序可分摊到多次查找；[Virginia Tech OpenDSA Binary Search](https://opendsa-server.cs.vt.edu/ODSA/Books/cnu/cpsc270/fall-2017/TR8-915_TR130-245/html/BinarySearch.html)给出中点比较、排除候选半边与未找到的终止条件。固定数组、预测题和完成门槛由本站设计，不是来源对适龄性或学习效果的认证。

## 验收范围

| 风险 | 检查方式 |
| --- | --- |
| 中点、范围、次数或终止错误 | 纯模型用独立顺序/二分参考轨迹核对 7/15 项、三类目标、有序/乱序每一步；浏览器核对首位 1/4、靠后 14/3、未出现 7/3 与 15/4。 |
| 乱序误报二分结果 | 乱序只执行顺序查找，二分次数显示不可用；前提问答错后可更正，不因仅选答案而伪造已查找结果。 |
| 预测泄露或虚假完成 | 开始前必须预测；两侧结束后才揭晓；四组正确预测且完整终止，再正确回答乱序前提，才尝试保存。 |
| 计时器和进度误写 | 连续、暂停、切换规模与页面隐藏不得串轮；损坏记录保留原文，拒写不宣称保存，已赢得资格可重试。 |
| 可发现与静态发布 | 首页搜索、高中目录和 7 主题进度；320px 键盘与减少动态、直接文件、项目子路径、公网 revision、资源一致性和实际交互分别核对。 |

## 剩余范围

7 与 15 项只用于有限规模的直观对照，不提供真实设备性能基准。还需真实学习者检验中点、候选区间和“先排序的成本”是否易懂；真实触屏设备、屏幕阅读器与整页无障碍仍待专项核验。大学计算机课程入口及高中其他算法、系统和网络主题仍为空白。
