🧊 物质的三种状态

物质世界丰富多彩，但大多数物质都有固态、液态、气态三种状态。
比如水：冰→水→水蒸气 🧊💧☁️
🧊 固态
分子排列紧密，只能在原位振动，有固定形状和体积
💧 液态
分子可以相互移动，有近似固定体积但无固定形状
☁️ 气态
分子间距很大，高速运动，无固定形状和体积
🔑 关键
温度升高通常使粒子热运动更剧烈；粒子间距还与物质及状态有关。

🌡️ 物态变化

物质从一种状态变成另一种状态，叫做物态变化。
吸热：熔化、汽化、升华
放热：液化、凝固、凝华
🧊 固态 → 熔化 吸热 →
← 凝固 放热 ← 💧 液态 → 汽化 吸热 →
← 液化 放热 ← ☁️ 气态
固态 ⇌ 气态：升华吸热 / 凝华放热（如霜的形成）
0°C

标准大气压下，0°C 时冰和水可能共存；具体状态还取决于过程和热量。

🧊→💧 熔化
标准大气压下，冰在 0°C 熔化时吸热
💧→☁️ 汽化
标准大气压下水在 100°C 沸腾；蒸发在液态温度范围内发生
☁️→💧 液化
水蒸气遇冷变成小水滴（露珠、雾）
💧→🧊 凝固
标准大气压下纯水在 0°C 凝固时放热

📏 热胀冷缩

大多数物质都有热胀冷缩的性质：
温度升高 → 分子运动加快 → 间距增大 → 体积膨胀
温度降低 → 分子运动减慢 → 间距缩小 → 体积收缩

画面的伸缩比例为便于观察而夸大的示意，不代表特定材料的实际膨胀率。

铁桥留有缝隙，防止夏天热胀变形

用热水烫瓶盖，金属盖膨胀就能拧开
⚠️ 水的反常
液态水在约 4°C 密度最大；冰的晶体结构较疏松，密度小于水。
