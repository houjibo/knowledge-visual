重复的人只能数一次

⭕ 什么是重叠问题
班里参加美术组的有 9 人，参加音乐组的有 8 人，其中 3 人两组都参加了。参加的一共几人？9+8 会把"都参加的 3 人"数两遍！
总数 = 9 + 8 − 3 = 14 人
🎨 韦恩图（集合图）
画两个相交的圆：左圆 = 美术组，右圆 = 音乐组，中间重叠的部分 = 两组都参加的。三部分分开数：只美术 + 只音乐 + 都参加，一个都不会多数。
🧮 万能公式
总数 = A + B − 重叠。为什么减？因为重叠部分在 A 里数了一次、在 B 里又数了一次，多数的一次要减掉。
A ∪ B = A + B − A∩B
