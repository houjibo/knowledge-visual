认识三种不同的"线"

📏 线段

✅ 有2个端点 ✅ 可以测量长度 ❌ 不能延伸
线段是直的，有两个端点，不能向任何方向延伸。它可以测量长度。
🌰 生活中的线段：尺子、铅笔、桌子的边

🔦 射线

✅ 有1个端点 ❌ 不能测量长度 ✅ 向一端无限延伸
射线只有一个端点，可以向一个方向无限延伸。它无法测量长度。
🌰 生活中的射线：手电筒的光、激光笔、太阳光

〰️ 直线

❌ 没有端点 ❌ 不能测量长度 ✅ 向两端无限延伸
直线没有端点，可以向两个方向无限延伸。它也无法测量长度。
🌰 想象一下：无限长的铁轨（向两边永远延伸）

三种线的对比，找出它们的相同和不同

特征 线段 射线 直线
端点个数 2个 1个 0个
能否延伸 不能 向一端 向两端
能否测量 能 ✓ 不能 ✗ 不能 ✗
都是直的吗？ 是 ✓ 是 ✓ 是 ✓
生活例子 尺子 手电筒光 无限铁轨
💡 重要关系
• 线段是直线的一部分
• 射线也是直线的一部分
• 把线段向一端无限延伸 → 射线
• 把线段向两端无限延伸 → 直线
