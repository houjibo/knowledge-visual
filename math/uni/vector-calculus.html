📐 核心公式

梯度：grad φ = ∇φ = (∂φ/∂x, ∂φ/∂y, ∂φ/∂z)
散度：div F = ∇·F = ∂P/∂x + ∂Q/∂y + ∂R/∂z
旋度：curl F = ∇×F

🟢 梯度 grad φ
标量场的最大增长方向，方向导数最大值 = |∇φ|。垂直于等值面。
🟡 散度 div F
单位体积的净通量。正 = 源，负 = 汇，零 = 无源（不可压缩）。
🟣 旋度 curl F
场的旋转强度与方向（右手定则）。curl F = 0 时场为保守场。
🔵 关系
curl(grad φ) = 0（梯度无旋）；div(curl F) = 0（旋度无源）。
