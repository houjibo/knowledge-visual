🔵 复数与复平面
复数 z = x + iy 对应平面点 (x, y)。模 |z| = √(x²+y²)，辐角 arg z = atan2(y, x)。欧拉公式 e^(iθ) = cosθ + i sinθ 是连接指数与三角的桥梁。
🟠 解析函数与柯西-黎曼方程
f(z) = u(x,y) + iv(x,y) 解析 ⇔ ∂u/∂x = ∂v/∂y 且 ∂u/∂y = -∂v/∂x。解析函数具有任意阶导数，且局部是共形（保角）映射。
🟢 共形映射
解析函数在 f'(z₀) ≠ 0 处保持角度不变：两条曲线在 z₀ 处的夹角等于其像在 f(z₀) 处的夹角。观察网格线正交性在映射下保持。
🔴 奇点与柯西积分公式
f(z) = 1/z 在 z=0 有极点，绕奇点积分 ∮ dz/z = 2πi。留数定理将围道积分转化为奇点留数之和，是复变函数最强工具。
