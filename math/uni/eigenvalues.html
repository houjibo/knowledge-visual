📐 特征值计算步骤

det(A - λI) = 0
特征多项式 = 0 → 解出特征值 λ
矩阵 A（2×2）
  1. 1写出矩阵 A - λI
  2. 2计算行列式 det(A - λI)
  3. 3展开得到特征多项式
  4. 4令特征多项式 = 0，求解 λ
  5. 5代入求特征向量
