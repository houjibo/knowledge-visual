离散型随机变量与分布列
随机试验的结果用变量 X 表示，叫随机变量。X 的所有可能取值与对应概率列成的表叫分布列，满足：pᵢ ≥ 0 且 Σpᵢ = 1。
三种重要分布
①二项分布 B(n,p)：n 次独立重复试验中成功次数；②超几何分布：N 件中含 M 件次品，不放回取 n 件中的次品数（E = n·M/N）；③正态分布 N(μ,σ²)：钟形曲线，3σ 原则——约 68.3% / 95.4% / 99.7%。
⚠️ 易错点
① 二项分布是有放回/独立重复，超几何是不放回——抽样方式决定用哪个；② 期望是"长期平均"，不是某次试验的结果；③ 正态曲线下的总面积 = 1，对称轴 x = μ；④ σ 越小曲线越"瘦高"。
