🎯 三维空间坐标系
在空间中，建立三条互相垂直的坐标轴 x、y、z，构成空间直角坐标系。空间中任意一点 P 的位置可以用有序实数组 (x, y, z) 表示。
📌 核心概念
• 空间直角坐标系：由三条互相垂直的坐标轴组成
• 右手系：右手定则确定坐标轴方向
• 坐标表示：点 P 对应 (x, y, z)
• 距离公式：|PQ| = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]

➕ 空间向量运算
空间向量的运算与平面向量类似，包括加法、减法、数乘、数量积（点积）和向量积（叉积）。
📌 向量运算公式
• 加法：a⃗ + b⃗ = (a₁+b₁, a₂+b₂, a₃+b₃)
• 减法：a⃗ - b⃗ = (a₁-b₁, a₂-b₂, a₃-b₃)
• 数乘：λa⃗ = (λa₁, λa₂, λa₃)
• 点积：a⃗ · b⃗ = a₁b₁ + a₂b₂ + a₃b₃ = |a⃗||b⃗|cosθ
• 叉积：a⃗ × b⃗ = (a₂b₃-a₃b₂, a₃b₁-a₁b₃, a₁b₂-a₂b₁)

📐 空间角计算
利用向量法可以方便地计算空间中的各种角：两直线所成角、直线与平面所成角、二面角。
📌 空间角公式
• 线线角：cosθ = |a⃗ · b⃗| / (|a⃗|·|b⃗|)
• 线面角：sinθ = |a⃗ · n⃗| / (|a⃗|·|n⃗|)，n⃗ 为法向量
• 二面角：cosθ = |n⃗₁ · n⃗₂| / (|n⃗₁|·|n⃗₂|)
线线角计算：
cosθ = |2×1 + 1×2 + 0×2| / (√5 × 3) = 4 / (3√5) ≈ 0.596
