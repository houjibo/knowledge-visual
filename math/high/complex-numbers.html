🔢 复数

探索复数的概念、运算与几何意义

📐 复平面（高斯平面）

复数 z = a + bi
在复平面上用点 (a, b) 表示。
横轴为实轴，纵轴为虚轴。
z = a + bi  ↔  点 (a, b)
|z| 模
到原点的距离 √(a²+b²)
arg(z) 辐角
非零复数与正实轴的夹角 θ；z = 0 时未定义
共轭复数
z̄ = a − bi，关于实轴对称
虚数单位
i² = −1

➕ 复数运算可视化

加法：向量相加（平行四边形法则）
减法：两点之间的距离向量
乘法：模相乘，辐角相加
z₁ + z₂ = (a₁+a₂) + (b₁+b₂)i
z₁ · z₂ = r₁r₂ · ei(θ₁+θ₂)
加法几何
平移向量，构成平行四边形
减法几何
从 z₂ 指向 z₁ 的向量
乘法几何
旋转 + 缩放
除法几何
反向旋转 + 缩放

🔄 旋转与缩放

乘以 eiθ = cosθ + i·sinθ 实现旋转 θ 角。
乘以实数 r 实现缩放 r 倍。
动画中，端点按当前角度旋转并同步缩放；两者同时变化时沿螺旋线移动。
z · eiθ = r · ei(α+θ)
