🎯 随机事件与概率

必然事件：在一定条件下必然发生的事件，P = 1
不可能事件：在一定条件下必然不发生的事件，P = 0
随机事件：在一定条件下可能发生也可能不发生的事件，0 ≤ P ≤ 1
0 ≤ P(A) ≤ 1

📐 几何概型

特点：在区域内均匀随机取点，可用几何度量（长度、面积、体积）计算概率
公式：P(A) = 构成事件A的区域度量 / 总区域度量
P(A) = μ(A) / μ(Ω)
