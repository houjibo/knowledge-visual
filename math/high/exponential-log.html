🎯 指数与对数的关系

💡 核心概念

指数与对数是互逆运算：若 a^x = N，则 log_a(N) = x

📊 指数运算

a^x = N

底数 a > 0 且 a ≠ 1
指数 x 为任意实数
幂 N > 0

📊 对数运算

log_a(N) = x

底数 a > 0 且 a ≠ 1
真数 N > 0
对数值 x 为任意实数

⇅ 互逆转换 ⇅

📐 运算法则

指数法则

a^m · a^n = a^(m+n)

指数法则

(a^m)^n = a^(mn)

指数法则

(ab)^n = a^n · b^n

对数法则

log(MN) = logM + logN

对数法则

log(M/N) = logM - logN

对数法则

log(M^n) = n·logM

🔑 特殊对数

  • lg 常用对数：lg(N) = log₁₀(N)
  • ln 自然对数：ln(N) = log_e(N)，其中 e ≈ 2.71828
  • 1 log_a(1) = 0（任何底数的1的对数为0）
  • a log_a(a) = 1（底数的对数为1）

💡 反函数性质

  • 1 定义域与值域互换：指数函数定义域为 R，值域为 (0,+∞)；对数函数定义域为 (0,+∞)，值域为 R
  • 2 图像关于 y = x 对称：若点 (a, b) 在指数函数图像上，则点 (b, a) 在对数函数图像上
  • 3 单调性相同：两者同为增函数或同为减函数
