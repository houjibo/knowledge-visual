📚 什么是集合？

集合是数学中最基本的概念之一。 把一些确定的、互不相同的对象看作一个整体，就是集合。

集合 = { 元素1, 元素2, 元素3, ... }

例如：{1, 2, 3, 4, 5} 是由 1~5 这五个数字组成的集合。

🎯 集合的表示方法

列举法

把元素一一列出来

{1, 2, 3, 4, 5}

描述法

用条件描述元素特征

{x | 1≤x≤5, x∈Z}

🔢 常见数集符号

N — 自然数集 {0, 1, 2, 3, ...}
N* 或 N₊ — 正整数集 {1, 2, 3, ...}
Z — 整数集 {..., -2, -1, 0, 1, 2, ...}
Q — 有理数集
R — 实数集

📐 子集与真子集

如果集合 A 的每一个元素都是集合 B 的元素，则 A 是 B 的子集。

A ⊆ B（子集）  |  A ⊊ B（真子集）

例如：A = {1, 2}，B = {1, 2, 3, 4}，则 A ⊊ B。动画将逐步展示这些元素。

∩ 交集

由既属于A又属于B的所有元素组成的集合。

A ∩ B = {x | x ∈ A 且 x ∈ B}
A = {1, 2, 3, 4, 5}
B = {3, 4, 6, 7}
A ∩ B = {3, 4}

∪ 并集

由属于A或属于B的所有元素组成的集合。

A ∪ B = {x | x ∈ A 或 x ∈ B}
A = {1, 2, 3, 4, 5}
B = {3, 4, 6, 7}
A ∪ B = {1, 2, 3, 4, 5, 6, 7}

∁ 补集

由全集U中不属于A的所有元素组成的集合。

∁ᵤA = {x | x ∈ U 且 x ∉ A}
U = {1, 2, 3, 4, 5, 6, 7, 8}
A = {2, 4, 6}
∁ᵤA = {1, 3, 5, 7, 8}
