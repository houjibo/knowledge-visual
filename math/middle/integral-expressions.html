整式的概念 — 单项式与多项式

📗 单项式

由数与字母的积组成的代数式叫做单项式。
单独的一个数或一个字母也是单项式。
例子：
  • 3x   系数=3, 次数=1
  • -5a²b   系数=-5, 次数=3
  • 7   系数=7, 次数=0
  • πr²   系数=π, 次数=2

📘 多项式

几个单项式的和叫做多项式。
每个单项式叫做多项式的项。
例子：
  • 3x + 2y   两项式
  • a² - 2a + 1   三项式
  • x² + xy + y²   三项式
  • 2m³ - m + 5   三次三项式
📌 整式 = 单项式 + 多项式
判断关键：分母中不含字母（如 1/x 不是整式，因为它可以写成 x⁻¹）

合并同类项 — 颜色标记法

💡 同类项：所含字母相同，并且相同字母的指数也相同的项。
例如：3x²y 和 -5x²y 是同类项（字母都是x²y）
合并方法：系数相加减，字母和指数不变。
同类项组 ①
3x²y , -5x²y
同类项组 ②
2ab , 7ab
同类项组 ③
-4m , m
常数项
6 , -2

📝 合并步骤演示

化简：3x²y + 2ab - 4m + 6 - 5x²y + 7ab + m - 2
→ 找同类项：3x²y 与 -5x²y，2ab 与 7ab，-4m 与 m，6 与 -2
→ 合并：(3-5)x²y + (2+7)ab + (-4+1)m + (6-2)
→ 结果：-2x²y + 9ab - 3m + 4

去括号 — 注意符号变化

✅ 括号前是"+"号

a + (b + c) = a + b + c
去掉括号，各项符号不变

⚠️ 括号前是"−"号

a - (b + c) = a - b - c
去掉括号，各项符号全部变号

📝 去括号步骤演示

化简：(3x + 2y) - (x - 4y + 5)
原式 = (3x + 2y) - (x - 4y + 5)
= 3x + 2y - x + 4y - 5 ← 第二个括号前是"−"，各项变号
= 2x + 6y - 5 ← 合并同类项

📝 再来一个

化简：2(a² - 3a) + 3(2a - a²)
原式 = 2a² - 6a + 6a - 3a² ← 分别展开
= -a² ← 合并：(2-3)a² + (-6+6)a = -a²
