📐 绝对值的几何意义

绝对值 = 数轴上的点到原点的距离

5
距离 = 5
|5| = 5

正数的绝对值

|a| = a
|+5| = 5
（正数的绝对值是它本身）

负数的绝对值

|a| = -a
|-3| = 3
（负数的绝对值是它的相反数）

零的绝对值

|0| = 0
|0| = 0
（零的绝对值是零）
💡 重要性质：
• 任何数的绝对值都是非负数（≥ 0）
• 互为相反数的两个数绝对值相等：|+a| = |-a|
• 绝对值最小的数是 0

🧮 有理数运算计算器

输入有理数进行加减乘除。负数先按“−”再按数字；括号可改变运算顺序。

输入算式开始计算

加法：两个非零数同号取相同符号；异号且和不为 0 时取绝对值较大的数的符号，绝对值相等时和为 0。
减法：减去一个数 = 加上这个数的相反数
乘法：两个非零数同号得正、异号得负；有 0 则积为 0。
除法：两个非零数同号得正、异号得负；0 除以非零数得 0，除数不能为 0。
