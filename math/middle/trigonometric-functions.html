🎯 三角函数定义
在直角三角形中，对于一个锐角A，它的正弦、余弦、正切分别定义为：
sin A = 对边 / 斜边
cos A = 邻边 / 斜边
tan A = 对边 / 邻边

📊 特殊角的三角函数值
30°、45°、60° 是最常用的特殊角，它们的三角函数值需要牢记：
角度 sin cos tan
30° 1/2 = 0.5 √3/2 ≈ 0.866 √3/3 ≈ 0.577
45° √2/2 ≈ 0.707 √2/2 ≈ 0.707 1
60° √3/2 ≈ 0.866 1/2 = 0.5 √3 ≈ 1.732

🧠 记忆技巧

正弦值：30°→1/2，45°→√2/2，60°→√3/2（分子依次是1、√2、√3）

余弦值：与正弦相反，30°→√3/2，45°→√2/2，60°→1/2

正切值：tan = sin/cos，所以 tan30°=√3/3，tan45°=1，tan60°=√3

📊 函数性质

正弦 sin：从 0 递增到 1，角度越大值越大

余弦 cos：从 1 递减到 0，角度越大值越小

正切 tan：从 0 递增到无穷大，接近 90° 时急剧增大

🏔️ 实际应用：仰角与坡度
三角函数在实际生活中有广泛应用，如测量高度、计算坡度等。

📐 仰角测高

当你站在距离建筑物 50 米处，测得楼顶的仰角为 30°，则建筑物高度为：

h = 50 × tan30° = 50 × 0.577 ≈ 28.87 米
