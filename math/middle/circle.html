📐 圆周角定理

定理：同弧上的圆周角等于圆心角的一半。

∠APB = ½ ∠AOB

拖动点 P 在圆上移动，观察圆周角和圆心角的变化关系。

💡 推论

  • 同弧（或等弧）上的圆周角相等
  • 半圆（直径）上的圆周角 = 90°
  • 圆内接四边形对角互补

📏 切线的性质

核心性质：过切点的半径 ⊥ 切线

OA ⊥ 切线 l

拖动切点 T 观察切线始终与半径垂直。

🔑 切线判定与性质

  • 判定：到圆心距离 = 半径 → 切线
  • 性质1：切线与过切点的半径垂直
  • 性质2：从圆外一点引两条切线，切线长相等
  • 切线长公式：从 P 到圆 (半径r, 圆心距d)，切线长 = √(d²−r²)

🔄 弧长与扇形面积

弧长 l = nπr / 180
扇形面积 S = nπr² / 360 = ½lr

拖动滑块改变圆心角和半径，观察弧长和扇形面积的变化。

📝 推导过程

  • 圆周长 = 2πr，对应 360°
  • ∴ n° 对应弧长 = (n/360) × 2πr = nπr/180
  • 圆面积 = πr²，对应 360°
  • ∴ 扇形面积 = (n/360) × πr² = nπr²/360
  • 又 S = ½lr（类比三角形面积 = ½底×高）
