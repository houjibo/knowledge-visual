观察真假怎样选择动作

目标在第 5 列第 1 行。用同一条未更改的规则，无碰撞地走到目标，并观察过“成立”和“不成立”两种结果，就完成本关。抵达目标后停止探索，最近一次判断会保留。

默认规则能绕过两面墙。也试试“检查上方，成立时向右，否则向上”。检查方向和动作方向是分别选择的：例如右侧有墙时，若成立动作仍选向右，机器人会碰墙留在原地，这次判断仍计数。

修改规则会回到起点并清空本轮判断。“回到起点”保留参数，“恢复示例”恢复检查右侧、成立向上、不成立向右。每次点击执行一次完整 if / else，没有自动循环或动画。

学习进度保存在当前浏览器。

条件分支的含义与示例范围

Microsoft MakeCode if 官方说明介绍：条件为真时执行 if 内的代码；条件为假时可执行 else 中的代码。本页用一项判断和两个方向动作展示这种选择。固定地图和完成规则是本站教学示例，不代表完整编程课程或真实机器人的感知系统。
