# 设计

计算 3×2 整数矩阵 `A` 的 Gram 矩阵 `G=AᵀA`，以整数计算迹、行列式和判别式。秩由迹和行列式精确分类；二次公式得到 `G` 的非负特征值，较小正特征值用 `det/λ₁` 计算，避免相近根相减的消去。不同特征值时取单位右特征方向及其垂线；重根时 `G=λI`，选标准基。仅对正奇异值计算 `uᵢ=Avᵢ/σᵢ`，从而避免零除；零奇异方向作为零空间基展示。用有限精度乘回，并报告最大元素误差，页面不把小数写成精确等式。

单位圆的像在左奇异方向的坐标系中绘制，不能标成三维空间投影。预测逐项反馈，全部正确才记完成，查看示范不记完成；编辑后清除旧结果。输入限定 `−3..3` 整数。浏览器验收包括满秩、秩 1、秩 0、重根、错误输入、320px、键盘、文件直开和发布子路径。
