## Why

CE25 初中信息科技第四学段“物联网实践与探索”模块的内容要求（6）要求了解自主可控技术对物联网安全的意义。现有物联网页面覆盖概念区分（IOT-01）、反馈控制（IOT-02/04）、设备数字身份与隐私（IOT-05），但没有任务涉及供应链可信、系统更新维护或核心技术/数据的自主可控。该要求在 `middle-information-technology-ce25.json` 中仍为 `missing`，其 gap 明确“没有供应链、系统更新或可控性相关主题”，next_step 要求先核对年龄适宜的设备维护案例与权威来源。需要用边界清晰、全程本地固定脚本、不连接真实设备或网络的可视化任务呈现。

## What Changes

- 新增初中“物联网自主可控与安全实验室”，围绕虚构的校园物联网设备，串起三步实践：供应链来源可信判断、系统更新与维护责任、自主可控与受制风险对照。
- 以本地固定脚本给出供应链采购/更新渠道案例（官方可信渠道与不明来源、被篡改固件）、系统更新维护案例（及时安全补丁、忽略更新、停止维护 EOL 设备）、自主可控对照场景（核心技术/数据/服务能否自主掌控、断供或远程停服影响）；明确不连接真实设备、不发送网络请求、不收集自由文本或真实机构信息。
- 让学习者先判断哪些来源与更新方式可信，再识别停止维护和滞后补丁的风险，最后判断哪些做法增强自主可控（本地化、开源/标准、数据自持、可替代）；错误选择保留重试并给出可核查解释，避免把“使用国产/进口品牌”简单等同于自主可控。
- 将 CE25-IT-L4-IOT-06 从 `missing` 调整为 `partial`，第四学段信息科技 19 条随之变为 0 已验证、16 部分、3 缺失；记录有限模拟证据、未覆盖的真实供应链调研与真实学习者迁移。
- 补充纯模型 Node 用例，以及桌面、移动、键盘、320px 小屏、直接文件、项目子路径、进度存储失败恢复和无外部请求的浏览器回归。

## Capabilities

### New Capabilities

- `middle-iot-autonomous-control-security-lab`: 在虚构校园物联网场景中判断供应链可信来源、系统更新维护责任与自主可控做法，理解自主可控技术对物联网安全的意义，全程使用本地固定脚本与合成数据。

### Modified Capabilities

无。

影响 `computer/middle/` 的新页面与本地模型、该学段目录卡片（初中第 12 个主题）、首页学科计数（计算机 28→29）、主题目录与页面清单生成件、CE25 初中信息科技交叉表、课程差距矩阵与核查记录、Playwright/模型测试和发布资源验证；不新增外部服务、账号、依赖或网络请求，不改变任何既有 URL 或进度结构。
