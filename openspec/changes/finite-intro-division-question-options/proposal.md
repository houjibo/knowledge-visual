## Why

“除法初步认识”页面在启动时会生成分一分和选择题。多个选项生成器使用随机重抽填满集合；固定随机值 0 或接近 1 时，页面无法完成初始化。选择算式题在除数与商相等时还会出现重复的正确选项，降低练习的确定性。

## What Changes

- 将分一分与两类数值选择题改为从有限候选集中选择互异干扰项，确保随机值重复时也能完成生成。
- 让选算式题始终包含三个互异选项，且恰有一个选项匹配题目要求。
- 增加桌面和移动浏览器回归，覆盖固定随机值 0、0.5、0.8、0.999999、三类题型、除数等于商的边界、选项唯一性、正确答案和继续作答。

## Capabilities

### New Capabilities

- `intro-division-finite-options`: 除法初步认识页面的有限选项生成与题目答案唯一性。

### Modified Capabilities

无。

## Impact

- 影响 `math/topics/intro-to-division/index.html` 的分一分和选择题生成。
- 新增浏览器回归文件并注册到 `npm run test:browser`；不引入依赖，不改变题目范围、计分方式或学习进度。
