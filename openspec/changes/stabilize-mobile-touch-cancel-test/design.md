## Context

CDP 触摸取消通过浏览器事件循环送达页面。`Input.dispatchTouchEvent` 返回时，页面事件处理器可能尚未完成，因此紧随其后的同步读取有机会观察到旧状态。

## Goals / Non-Goals

### Goals

- 允许异步取消处理在 Playwright 的默认有限轮询时限内完成。
- 取消处理一直未完成时，仍以明确失败暴露回归。
- 保持后续重新拖动步骤，以验证取消后交互可以恢复。

### Non-Goals

- 不调整页面事件监听器、产品交互或测试超时时间。
- 不通过重试或跳过隐藏真实状态未复位的问题。

## Decisions

- 使用 `expect.poll` 重读同一组运行时状态，目标仍为形变归零、未拖动、无活动指针。
- 保持 Playwright 默认轮询超时，避免为单个断言放宽整项测试时限。

## Risks / Trade-offs

- 轮询会容忍事件处理器的短暂调度延迟；若状态不能复位，断言仍会在有限时间后失败。
