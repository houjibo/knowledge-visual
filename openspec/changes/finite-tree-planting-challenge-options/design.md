## Context

见 [proposal.md](proposal.md) 的 Why。活动脚本在初始化时立即调用 `genQuizV2()`，并在两个重复实现的生成器里用随机重抽补足四个选项。题目答案范围为 2–16；合法干扰项须为正整数并避开答案。

## Goals / Non-Goals

**Goals:**

- 让有效题目的选项生成有固定上界，包括持续重复的随机序列。
- 同时收敛活动和旧版生成器中的重复选项循环，避免保留相同故障路径。

**Non-Goals:**

- 不改变植树题的间隔数、题型、正确答案、反馈或自动进入下一题行为。
- 不重写故事、探索和生活应用模式，也不清理无关旧逻辑。

## Decisions

- 从答案附近的有限偏移 `[-3, -2, -1, 1, 2, 3, 4]` 构造候选，过滤非正数与答案，再用现有随机洗牌选取三个干扰项。此范围保留原本的邻近干扰项和低答案时向上补充候选的意图。相较随机重抽，即使随机值固定也必定有限结束。
- 将候选生成提取为单一函数并由两个生成器共用，而不是只改当前活动的 `genQuizV2`；否则旧实现仍保留同类无界循环。
- 若有效答案下候选不足三个，抛出明确错误，不退回到随机重抽。当前题目范围的最小答案为 2，过滤后至少有五个干扰候选，测试覆盖该边界。

## Risks / Trade-offs

- 固定随机值会使选项顺序固定，但不影响答案唯一性或学习路径；回归测试分别覆盖固定值 0、0.5 与接近 1 的输入。
- 候选池会较当前概率分布更均匀地产生附近数字；题目答案和计分规则不变。

## Migration Plan

- 先运行固定随机值回归确认修复前的页面初始化阻塞，再实施有限候选生成。
- 运行专项、静态及完整站点检查后推送；若出现回归，回滚本次代码提交并保留 OpenSpec 证据。
