## Purpose

本能力保障植树问题的闯关练习在页面加载和连续作答时能有限地生成四个互异正整数选项，其中恰有一个选项符合题目规则，避免随机重复导致页面无法使用。

## ADDED Requirements

### Requirement: 植树练习有限生成选项

闯关练习 MUST 为每道题生成四个互异的正整数选项，其中恰有一个选项等于按题目类型和间隔数计算出的正确棵数；选项生成 MUST 在随机源重复返回相同值时结束。

#### Scenario: 随机源重复时页面仍完成初始化

- **WHEN** 页面初始化或生成下一题期间随机源持续返回相同值
- **THEN** 页面 MUST 完成题目与四个有效选项的渲染，且不阻塞其他学习模式

#### Scenario: 答案处于练习范围边界

- **WHEN** 题目规则产生最小或最大棵数答案
- **THEN** 四个选项 MUST 都是正整数且互不相同，并且只有一个选项与规则计算的答案一致

#### Scenario: 正确作答后继续闯关

- **WHEN** 学习者选择当前题目的正确棵数
- **THEN** 页面 MUST 显示正确反馈、正确计数加一，并生成可继续作答的下一题
