## Context

见 [proposal.md](proposal.md) 的动机与范围。高中人工智能当前有二维分类边界主题；目录、查找、进度和发布清单由本地静态页面及仓库脚本维护。可视化内容需明确区分手动规则演示与模型训练。

教学边界参考 [Google ML Crash Course：划分数据集](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets) 对训练/验证/测试用途和重复使用测试集的说明，以及 [scikit-learn：数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage) 对测试数据不应用于模型选择的建议。

## Goals / Non-Goals

**Goals:**

- 用一个有界、可复核的实验展示在训练样本上选择规则，再在未参与选择的测试样本上查看结果。
- 将图示、指标、文本摘要、完成状态和测试集使用警示保持一致。
- 沿用静态部署、现有学科目录与进度格式，不引入运行时依赖。

**Non-Goals:**

- 不训练真实机器学习模型，也不实现随机数据划分、验证集或交叉验证。
- 不把少量人工构造样本上的准确率解释为对现实数据或模型能力的估计。
- 不更改现有分类边界实验或兼容 URL。

## Decisions

1. **使用固定样本和单阈值分类规则。** 横轴为虚构特征分值，`分值 >= 阈值` 预测 B，否则预测 A。训练集 A 为 `[1, 2, 5, 7]`、B 为 `[9, 10, 12, 14]`；测试集 A 为 `[3, 8]`、B 为 `[7, 11]`。初始阈值 8 时训练集为 8/8、测试集为 2/4；阈值 7 时分别为 7/8、3/4。固定小样本避免随机重抽、保证测试可重复，并展示两组指标可能不同。相较动态生成数据，固定案例更利于独立核对与键盘回归。
2. **在同一分值轴上分开绘制训练和测试泳道。** 训练真实标签从一开始可见；测试点在首次评估前以未知标记显示。阈值线贯穿两组，类别用形状区分、对错用颜色和文字同时表达。可访问文本摘要和逐样本列表提供画布之外的等价信息。
3. **首次评估后保留测试集已使用状态。** 显示测试指标后，之后的阈值变化可继续演示两组结果，但必须显示测试样本已被查看并参与选择的警示。恢复初始阈值不得隐藏已泄露标签或清除此警示；页面重新载入也只重置演示状态，不宣称生成了新的测试集。
4. **将首次查看测试集作为完成条件。** 复用 `SubjectProgress` 在 `ai/high` 保存 `train-test-generalization`。存储拒绝不阻止计算或指标展示，提示与现有 AI 页面一致。
5. **保留静态寻址与发布证据。** 新主题由高中目录链接，使用相对路径及现有样式/进度脚本；更新 AI 主题目录生成结果、静态页检查、发布包清单和部署后代表交互。专项浏览器测试涵盖准确率边界、测试标签解封、阈值调整警示、键盘、存储拒绝及 320px。

## Risks / Trade-offs

- **极小的人工样本容易被误解为现实模型评估** → 在标题旁、图表说明和指标下说明样本为虚构且数量不足以外推；课程来源给出进一步阅读。
- **学习者看到测试结果后继续调参** → 保留测试集已查看状态，在测试指标旁持续显示独立性警示。
- **测试数据标签隐藏降低静态图表可理解度** → 使用显式“未查看”图例、测试样本数和 `aria-live` 文本说明，不只依赖颜色。
- **新增主题造成目录和进度分母不同步** → 通过页面目录链接、生成目录断言、首页计数回归和浏览器端进度断言共同检查。

## Migration Plan

新增 `ai/high/train-test-generalization.html` 并挂入既有高中 AI 目录；扩展站点目录、发布后资源校验和课程文档。无需转换既有浏览器记录。若页面交互出现错误，可撤销该新增页面和入口；已有分类器、AI 进度键及旧兼容路径不变。
