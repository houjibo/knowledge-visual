# 设计

对 `W=[[a,b],[c,d]]` 用整数判定 `D=ad−bc`。`D≠0` 时，以伴随矩阵 `adj(W)=[[d,−b],[−c,a]]` 生成简分数，计算 `c=adj(W)x/D` 与 `B=adj(W)AW/D`。模型精确核验 `Wc=x`、`AW=WB`、`W(Bc)=Ax` 及相似矩阵的迹、行列式不变；不用浮点容差决定是否为基。画布仅按数值比例绘制 W 两列、x 与 Ax，文字保留分数。

`D=0` 时不定义 W⁻¹、c 或 B。若 W 为零矩阵，列空间只有 0；否则用与非零列的二维叉积判定 x 是否在列空间，分别说明“表示不唯一”或“无法表示”。学习者可正确识别非基并查看解释，但只有在有效基下完成坐标和矩阵元预测才记录进度。编辑或无效输入清除旧结果。输入限定 W、A 为 −3..3 整数，x 为 −4..4 整数；验收覆盖有效、分数、负行列式、相关列、零矩阵、320px、键盘、文件直开和发布子路径。
