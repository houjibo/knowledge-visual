# 设计：小学人工智能特征分类

## 学习模型

页面使用 6 个带标签的训练样例和 4 个标签先隐藏的新样例。每张图使用页面内绘制的水果示意图，并显式写出颜色与形状；所有数据均为固定虚构数据。

训练样例中，苹果有红、绿、黄三种颜色且均为圆形；香蕉有黄、绿两种颜色且均为弯形。分类器按学习者选择的单一特征，统计训练样例中各特征值对应的标签多数：

- 按形状：圆形预测苹果，弯形预测香蕉。
- 按颜色：红色预测苹果，黄色预测香蕉；绿色两类各一个，规则无法决定。

测试样例为黄圆苹果、绿弯香蕉、红圆苹果和黄弯香蕉。按颜色预测时有 2 个正确、1 个错误、1 个不确定；按形状预测时为 4 个正确。每项均可用训练样例和逐项规则复核。

## 交互状态

1. 默认选择颜色，训练标签和多数规则表可见；测试图片展示模型预测，但真实标签与结果统计保持隐藏。
2. 学习者可以用原生单选控件切换颜色或形状，页面即时更新每张测试图片的预测。
3. 点击“查看真实标签”后展示正确、错误或不确定状态及统计，并记录主题完成。
4. 标签已揭示后继续切换线索只用于比较已见样例；页面持续说明这些图片已不再是未见样例。

## 边界与无障碍

页面说明这是按样例多数模拟的规则分类，不进行真实训练，不从真实照片提取特征。图示有文字类别和特征，结果由状态区域播报；单选控件、查看按钮和重置操作均支持键盘。布局在 320 CSS 像素下检查，无页面级横向溢出。进度写入失败不阻断分类。

## 依据

- Google 监督学习说明用带标签的样例学习特征与标签的关系：[Supervised Learning](https://developers.google.com/machine-learning/intro-to-ml/supervised)。
- UNESCO 学生人工智能能力框架强调从理解到应用的循序发展：[AI competency framework for students](https://www.unesco.org/en/articles/ai-competency-framework-students?hub=84624)。

这些来源用于概念和学习路径设计；它们不认证本站，也不支持将多数规则描述为经过训练的实际模型。
