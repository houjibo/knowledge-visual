# 为小学人工智能增加特征分类可视化

## 问题

人工智能入口从高中开始，小学阶段没有适龄主题。课程设计已有“图像特征分类”方向，但站点还没有让低年级学习者观察样例、特征、标签和预测之间关系的交互。

## 变更

- 在人工智能入口增加小学学段目录和“特征线索分类实验室”。
- 用固定、虚构的水果样例比较颜色与形状两种线索，展示训练样例形成的简单多数规则、未见样例预测和结果反馈。
- 让学习完成状态进入人工智能首页统计、学段进度、本地查找目录、发布包和部署后核验。
- 更新人工智能课程图、交互证据、项目差距、主题目录和页面清单。

## 边界

本主题是可复核的多数规则模拟，不执行机器学习训练、不使用相机或真实图像、不连接外部服务。样例只用于说明“特征影响分类”，不构成水果识别模型或现实性能证据。初中人工智能课程和小学其他主题留待后续变更。

## 验收

学习者能切换分类线索、查看预测、揭示真实标签、发现颜色规则中的错误与不确定结果，并看到小样本局限。导航、搜索、进度、键盘、320px 窄屏、静态发布子路径及公网版本核验均通过相应检查。
