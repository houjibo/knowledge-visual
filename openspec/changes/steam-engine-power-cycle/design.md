## Context

[ASME 的 Boulton & Watt 旋转蒸汽机记录](https://www.asme.org/about-asme/engineering-history/landmarks/111-boulton-watt-rotative-steam-engine)说明双作用气缸和工厂用旋转动力的历史联系；[ASME 的 Hacienda La Esperanza 蒸汽机记录](https://www.asme.org/getmedia/464cbbcc-e6db-47c1-a469-e4e0d88f3b41/35.pdf)描述活塞往复、曲柄旋转并驱动机器。本页只抽取动力路径，并不复原这两台机器。

## Decisions

- 采用水平双作用气缸的教学示意：曲柄半径 65 示意单位、连杆长 200 示意单位，十字头中心 `x=670−65cosθ−sqrt(200²−65²sin²θ)`，活塞中心比十字头向左 240 示意单位。零度是左死点；0° 至小于 180° 规定左腔进汽、活塞向右，180° 至小于 360° 规定右腔进汽、活塞向左。死点为换向边界，图示不求阀门提前角。
- 进汽侧先预测后揭晓；揭晓前两侧管路不显示答案。可选 0° 至 345° 每 15° 的起始角，改变角度或转速清空预测和演示。揭晓后可按 45° 单步或主动播放两圈，15/30 rpm 仅改变演示周期，不改变相同角度的几何位置。自动播放用单个 requestAnimationFrame，暂停、页面隐藏与减少动态偏好会取消；恢复偏好不自动重播。
- 蒸汽锅炉与气缸间箭头为概念路径。左右交替进汽和排汽是理想化分配规则，不显示蒸汽实际压力、流量、膨胀、冷凝或阀机构；给定匀速由外部教学时钟控制，不声称蒸汽必然使轴匀速转动。图形和文字都显示当前侧与位移，不能只靠颜色理解。
- 使用 SVG 与原生 select、range、button；无脚本时有明确静态降级。直接文件打开与 GitHub Pages 项目子路径均保持相对资源路径。

## Verification

独立模型测试端点、中心及连杆长度、两侧相位、周期与非法输入。浏览器测试目录和搜索、预测门禁、真实 SVG 坐标/文字一致、速率对比、键盘、320px、减少动态、隐藏页面、文件直开和发布子路径。本地完整门禁、Actions 及公网实际操作另记证据。
