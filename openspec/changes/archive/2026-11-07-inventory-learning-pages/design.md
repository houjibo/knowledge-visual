## Context

项目没有逐 URL 基线；当前静态检查不执行 JavaScript，页面也可能以脚本生成链接或交互。仓库无需构建工具即可使用。

## Goals / Non-Goals

通过 HTML 静态解析建立可重复的页面和导航线索，支持筛选与后续测试；不声称识别所有交互、证明导航孤页或验证学习正确性。

## Decisions

使用 Python 标准库，遍历仓库 HTML，以相对路径识别并归一化站内静态链接；从首页广度遍历，输出稳定 JSON。数学小学主题目录的 index 按主题分类，其余 index 标为导航。交互标签计数仅是静态线索，页面验证状态统一标为未验证；不把文件数量作为通过指标。

## Risks / Trade-offs

动态 DOM、外部脚本、CSS、运行时异常、file:// 与真实交互不能由该工具证明；静态不可达项需要浏览器或代码调查，禁止自动删除。生成清单后需要检查漂移。
