## Context

学段导航主题数为 28、19、27；原静态清单分别有 21、18、20。小学地图有两类主题链接，合计 124 个不同目标，单取 topic-card 遗漏主题。

## Goals / Non-Goals

让数学学段统计覆盖导航目标并防止清单漂移；保持旧存储和现有完成语义，不解决跨学段同名 slug 歧义。

## Decisions

小学按 topic-card 和 topic-node 的主题链接提取 slug 并用 Set 去重。其余学段保留离线可用的静态清单，按导航同步，并用标准库检查集合相等及重复项；不在浏览器中跨页面请求。

## Risks / Trade-offs

小学链接必须符合现有目录约定，检查无法证明所有学习主题的完成逻辑；共享存储中的同名主题仍会跨学段计数。
