## Context

页面脚本在首次展示时就调用 `newFill()` 和 `newProduct()`。两处循环通过重新抽样直到集合达到目标数量；公共 `Random.shuffle()` 本身是有界的，问题在于候选重抽。参见 [proposal.md](proposal.md) 和变更规格。

## Goals / Non-Goals

**Goals:**

- 让填空题和看积找口诀题在任意重复随机输入下有限生成四个选项。
- 保持填空答案唯一；看积找口诀题保留该积的全部有效口诀，其余选项是不同的错误因数对。

**Non-Goals:**

- 不改变口诀表数据、计分、连对、挑战模式或学习进度。
- 不统一站内其他随机题生成器；后续逐页复现并另立变更。
- 不修改共享随机工具，避免扩大所有页面的回归范围。

## Decisions

1. **填空题从有限近邻集合抽取。** 取正确数值上下 5 的整数并限制在 1–81，排除正确答案后打乱并选 3 个。边界答案 1 和 81 仍各至少有 5 个候选。相比限制重试次数，这始终得到完整干扰项；相比全范围随机，近邻数值更适合作为练习干扰项。
2. **找口诀题枚举 1–9 的规范因数对。** 一次枚举 `1 ≤ a ≤ b ≤ 9` 的 45 个候选，先纳入该积的全部正确因数对，再从错误对中有限打乱并补足四项。避免随机重抽，也避免把乘积相同的另一口诀误标为错误。
3. **用重复与边界随机值回归。** 桌面和移动测试固定 `Math.random` 为 0、0.4、0.5、0.999999。测试页面首次加载、两种模式的选项数/唯一性/正确答案集合，并检查答对后反馈及下一题仍可生成；无需增加依赖或更改全站随机 API。

## Risks / Trade-offs

- 固定随机值下 Fisher–Yates 的排列不均匀，但候选有限且结果正确；均匀随机分布不属于本变更承诺。
- 近邻干扰项可能比原随机方案更规律；限制范围和固定随机回归验证其数量与唯一性。

## Migration Plan

直接更新静态 HTML 与浏览器测试，无存储格式或外部 API 迁移。回滚源码会恢复原有随机卡死风险；发布前由 Actions 完成全量检查、Pages 部署和发布后核验。
