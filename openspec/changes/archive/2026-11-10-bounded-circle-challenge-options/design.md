## Context

见 [proposal.md](proposal.md)。页面会先对公式生成的选项去重；若不足四个，再通过随机偏移反复补项。部分半径下重复公式项会留下三个选项，重复的随机偏移可能使页面一直重试。

## Goals / Non-Goals

**Goals:**

- 保留原有公式答案和有效干扰项，只补齐去重后不足四项的情况。
- 生成候选数量有限、值为正，并按题目答案的小数精度显示。
- 按数值去重，防止整数答案与格式化为两位小数的同值选项重复。

**Non-Goals:**

- 不修改题型、圆周率近似规则、答题反馈或挑战计分。
- 不修改其他数学主题的选项生成。

## Decisions

- 从正确答案附近固定的正负整数偏移中构造有限候选，排除非正值和数值上与已有选项重复的候选，再有限打乱并补足四项。现有题目答案均为正值；对最小整数答案 1，正向偏移也足以补项。
- 整数答案保持整数格式，小数答案保留两位小数；去重比较使用数值而非显示字符串。
- 保留当前公式干扰项；把“增加无界重试上限”作为替代方案排除，因为即使停止循环，也可能仍少于四项。

## Risks / Trade-offs

- [干扰项距离较近] → 仅在原公式选项不足时启用有限偏移，并沿用当前 ±5 的范围。
- [有限候选与已有选项重合] → 候选按数值过滤，并由五类题型、最小半径和重复随机序列回归检查四项及答案唯一性。

## Migration Plan

页面为静态 HTML，无持久数据迁移。验证后通过 GitHub Pages 发布；若发布验证失败，可回退页面与对应测试的提交。
