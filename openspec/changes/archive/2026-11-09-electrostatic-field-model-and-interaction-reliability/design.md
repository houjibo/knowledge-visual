## Context

See proposal.md - Why. 当前页面把像素间距直接代入库仑定律；场图用像素坐标求方向，电势用无量纲的 q/r 着色。页面使用固定内部分辨率画布，主题切换和拖动依赖鼠标/点击，练习靠未锁定的定时器推进。

## Goals / Non-Goals

**Goals:**
- 为三张静电场图统一一个显式的屏幕物理比例，使控件、模型读数和解释使用同一单位。
- 把物理计算与 DOM/Canvas 绘制分开，便于节点单测和浏览器回归。
- 保持当前单页静态发布方式，不引入构建时或运行时依赖。

**Non-Goals:**
- 不模拟有限尺寸导体、介质边界、三维空间或时间变化的电磁场。
- 不声称场线积分和色彩图能够替代专业数值求解；画布用于建立方向、符号、叠加与数量级直觉。
- 本次不做整站屏幕阅读器审计或真实设备认证。

## Decisions

1. **以 SI 制为计算边界，屏幕映射只负责展示。** 新增 `physics/high/assets/electrostatic-model.js`，接受以 μC 表示的点电荷与米制坐标，内部换算库仑并使用 `k = 8.9875517923×10⁹ N·m²/C²`。页面统一采用 `1 px = 0.001 m`；库仑距离滑块为 0.05–0.30 m，画布间距按 1000 px/m 映射。这样 0.15 m、+5 μC、−3 μC 默认显示约 5.99 N，且距离加倍可直接检查反平方关系。备选方案是沿用像素并给公式加经验比例系数；它会掩盖量纲错误，因此不采用。

2. **电势图使用可解释的定量映射，电荷核心与颜色饱和显式标注。** 用点电荷电势叠加计算伏特值；地图以 ±1 MV 为对称色标，超出范围饱和，离点电荷小于 0.02 m 的显示计算按 0.02 m 截断，电荷圆盘遮盖该核心。以稀疏网格和边插值绘制等势线，避免当前每 10 px 抽样画散点造成的伪轮廓。备选方案是仅保留“高/低”色彩而不使用单位；但页面展示的是 V=kq/r，明确固定色标更容易核查，也能诚实呈现截断区域。

3. **场线保持定性方向演示。** 电场向量由带符号点电荷按叠加计算，积分在画布坐标中沿向量方向推进。文字明确线条是方向示意，不承诺其条数/疏密可作定量场强读数。这样保留现有可拖动探索，同时避免把积分离散误差包装为测量结果。

4. **交互状态由原生控件表达。** 四个主题采用 `tablist` / `tab` / `tabpanel` 关系，方向键循环切换并支持 Home、End。电荷画布使用 Pointer Events；键盘 `+`/`-` 在画布中央新增并选中电荷，方向键移动，Delete 移除，实时状态文本播报选择与电荷数。静态画布有可访问名称和说明。备选方案是仅加 ARIA 标签；这仍无法让键盘用户操作核心拖动探索，因此加入键盘命令。

5. **练习按题锁定并区分当轮得分与页面累计。** 每次选择同步锁定当前题、禁用所有选项并只创建一个推进定时器；正确题 ID 集合在当前页面加载期间保留，重练只重置当轮分数和题目位置。知识地图累计按不同题 ID 增长。同步锁定比只在定时器中判断可靠，可消除快速点击的竞态。

物理关系以 OpenStax《University Physics Volume 2》为核对来源：库仑定律及符号决定力方向（[5.3 Coulomb's Law](https://openstax.org/books/university-physics-volume-2/pages/5-3-coulombs-law)）；点电荷电势叠加和等势关系（[7.3 Calculations of Electric Potential](https://openstax.org/books/university-physics-volume-2/pages/7-3-calculations-of-electric-potential)、[7.5 Equipotential Surfaces and Conductors](https://openstax.org/books/university-physics-volume-2/pages/7-5-equipotential-surfaces-and-conductors)）；场线方向和疏密解释（[5.6 Electric Field Lines](https://openstax.org/books/university-physics-volume-2/pages/5-6-electric-field-lines)）。

## Risks / Trade-offs

- **有限网格让等势线呈近似曲线** → 用插值连接网格边交点、在桌面与窄屏验证代表性点电荷和偶极子；不宣称数值求解精度。
- **固定色标会让较远处颜色接近零色** → 页面始终显示伏特图例与饱和范围，并用模型测试验证图中源电荷与符号。
- **键盘新增电荷从画布中心开始** → 状态文本说明选中对象，并允许方向键移动到目标位置。
- **键盘/语义修复不能单独证明屏幕阅读器体验** → 本次只报告可测试的 DOM 关系、焦点及状态，不把模拟浏览器结果表述为屏幕阅读器验收。

## Migration Plan

1. 先加入模型单测和专项浏览器回归，再替换页面计算与交互。
2. 更新静态发布所需文件、交互证据和页面清单，运行专项/全量检查及严格 OpenSpec 校验。
3. 推送后以 GitHub Actions 的检查和 Pages 发布后核验为发布门槛；失败时按失败步骤修正并重新推送。回滚时恢复本次页面、模型和证据提交，静态站无需数据迁移。
