## Context

物理按学段分别存储进度，但首页使用全学科 Set 按 slug 去重，跨学段 motion、electrostatic-field 和 em-induction 因此可能少计。数学使用单个共享存储，无法从同名旧记录推断所属学段。

## Goals / Non-Goals

保持独立存储记录的身份并累计；不改存储格式、数学学段归属、无效旧记录过滤或首页分母。

## Decisions

对每个已有存储的键数分别求和；同一存储天然以键去重。相比数据迁移，这是保留当前契约的最小修复。

## Risks / Trade-offs

历史无效记录仍可能影响计数，数学共享存储的问题仍存在；另行分析和修复。
