## Context

动机和范围见 [proposal.md](proposal.md)。现有家庭电路页面将触电处置压缩为“先切断电源”，并把熔断后的操作题写成“查明原因再更换”，没有区分学生、成年人和专业人员。

依据[福州市卫健委答复](https://www.fuzhou.gov.cn/zgfzhd/znhd/swjw/ylfw/202407/t20240711_4857993.htm)，发现触电应保证施救者安全，未切断电源时不能直接拉拽伤者；[西安市应急管理局科普](https://yjglj.xa.gov.cn/kp/64fee17cf8fd1c1a70387e76.html)要求高压事故远离现场并联系电力部门和急救；[周口市政府安全用电常识](https://www.zhoukou.gov.cn/page_pc/zwgk/jcxxgk/yjgl/yjzs/article2d9c0fc307d640a988e1048202a88776.html)要求更换保险丝前断电、不得冒险带电操作，并将电气维修交给有资质人员；[永州市公安局用电安全说明](https://gaj.yzcity.gov.cn/gaj/ggff/201110/59d810ccb23842869e964390a7b933c0.shtml)说明保险丝熔断可能表示超负荷或其他危险，应由专业人员检查。

## Goals / Non-Goals

**Goals:**

- 让中学生首先识别自身危险、呼救和远离高压的边界，不让页面暗示儿童应独自断电、触碰伤者或维修线路。
- 让应急顺序常显、可扫读，并在窄屏保持步骤关系清晰。
- 让保险丝测验的正确反馈与页面安全提示一致。

**Non-Goals:**

- 不教授触电急救、心肺复苏、临时挑线或家庭配电操作。
- 不改变家庭电路示意的电压、负载与保护装置计算模型。

## Decisions

1. **用常显的有序步骤图表达应急边界。** 三步依次为呼救并自保、安全条件下由成年人断电、断电未确认前不接触伤者或线路；高压与落地电线额外强调远离和联系专业救援。采用有序 HTML 列表和 CSS 箭头，保留屏幕阅读器阅读顺序。不同于折叠说明，安全步骤不会被隐藏；不同于画布图，它在窄屏和无脚本时仍可读。
2. **不提供非专业者的替代救援动作。** 不在页面说明如何使用木棍、绝缘工具、断线或实施 CPR。此页学习者包含未成年人，处置应由成人和专业救援人员负责。
3. **用情境题替代“查因后更换”。** 保险丝熔断时，正确选项为停止自行操作、告知成年人并请专业人员检查；保留不得用铜丝替代的基础知识。其他选项使用反复送电或金属丝替代等错误做法作为辨析对象。

## Risks / Trade-offs

- [风险] “由成年人断电”仍可能被理解为靠近带电设备 → 明确只有能从安全位置操作时才可断电；遇高压或疑似带电落地线直接远离。
- [风险] 流程图样式丢失后箭头不显示 → 使用有序列表的数字顺序和完整文字，不依赖颜色或 CSS 箭头传达含义。
- [风险] 安全步骤被简化成完整急救方案 → 明确页面不教授救援操作，并持续引导成年人、急救和电力专业人员。

## Migration Plan
