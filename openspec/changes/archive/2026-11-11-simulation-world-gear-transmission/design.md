## Context

模拟世界是独立的静态 HTML 分类，现有主题由 `simulation-world/index.html` 手工列卡片，再由页面清单和主题目录生成器自动登记到首页搜索。模拟页面不使用学科学段或进度。当前太阳系页面依赖本地 Three.js；齿轮是平面机构，适合用现有浏览器 2D Canvas 能力表达，不需要复用三维引擎。

## Goals / Non-Goals

**Goals:**
- 让动画、公式、数值和文字替代共享同一组参数，避免显示状态漂移。
- 从目录和分类搜索发现新主题，并由静态发布核验覆盖。
- 保持无外部运行依赖、无学习进度存储，并在 320px 和减少动态效果环境可用。

**Non-Goals:**
- 不模拟完整工厂生产线、电机控制、齿轮箱多级传动或可用于工程选型的负载。
- 不复用太阳系三维渲染器，不加入框架、账户或用户数据存储。

## Decisions

- 新增独立 `simulation-world/gear-transmission.html`。目录页增加场景卡；首页模拟数量改为 2；页面清单、主题目录和交互证据继续使用现有生成器，避免手工维护生成文件。
- 使用一张响应式 2D Canvas 绘制比例示意的两齿轮，并在旁边保留可访问的文字替代、公式和实时数字。与 Three.js 3D 替代方案相比，Canvas 更贴合平面机构，减少加载和发布依赖；屏幕阅读器仍通过文字结果获取数据。
- 将输入齿数 `Zin`、输出齿数 `Zout`、输入转速 `nin`、输入转矩 `Tin` 和效率 `η` 作为唯一状态。转速按 `nout = nin × Zin / Zout` 计算，转矩按 `Tout = Tin × Zout / Zin × η` 计算，功率按 `P = T × 2πn / 60` 计算；各读数、画布文字和动画均由同一更新路径刷新。
- 以真实时间差推进输入角度，输出角度按相反方向和齿数比推进。暂停、零转速和减少动态效果偏好停止动画；用户可主动重新启动。画布上下文不可用时保留数值模型与模型说明并提示画布状态。
- 新增浏览器专项测试覆盖目录搜索、比例公式边界、效率/功率守恒、齿轮方向与运行控制、键盘、减少动态效果、画布降级及 320px 布局；完整检查继续验证发布包与主题清单。

## Risks / Trade-offs

- 简化齿形不是工程齿形，可能被误认为可制造设计 → 页面明确标注为齿数与传动关系示意，说明不计算接触、惯性或真实负载。
- 输出读数的四舍五入可能与公式产生表面差异 → 内部使用未舍入数值计算功率，只在显示端统一舍入，测试使用合理数值容差。
- 低转速下动画不明显 → 同时显示方向、转速和进度标记，不以动画作为唯一的信息通道。
- 生成清单遗漏会导致首页或发布搜索不完整 → 静态检查约束目录链接，交互测试核对首页数量、分类搜索和无学段结果。

## Migration Plan

无需数据或 URL 迁移。部署新静态页面与生成后的搜索/清单文件；回滚时移除场景卡、首页数量增量、发布核验条目和新增页面即可，不影响太阳系场景。
