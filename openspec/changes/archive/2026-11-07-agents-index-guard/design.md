## Context
根索引应保持简短且按需指向长期知识；现有检查只查链接目标，无法发现混入的过程指令。路线图需要反映真实未完成工作。

## Goals / Non-Goals
检查根文件仅含标题与仓库内 Markdown 索引，并保留架构、约束、差距、三个工作流及 OpenSpec 入口；不限制 docs 内具体内容，不声称可自动判断文字质量。

## Decisions
在静态检查中运行专用验证器和隔离临时目录回归；阻止缺失、越界、外部、重复链接和非索引文本。路线图使用现有动态证据入口而非硬编码已过期数量。

## Risks / Trade-offs
格式有意限定为独立链接项，若未来需要其他索引结构应先修改契约和测试；内容是否准确仍需人工或代理复核。
