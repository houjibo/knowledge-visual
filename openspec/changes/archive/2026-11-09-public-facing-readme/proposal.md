## Why

README 仍将公开站点描述为“逐步建设”，并披露旧项目合并来源；这些内容对访问者理解和使用当前学习站没有帮助，也把本地历史带入了公开介绍。应以稳定的站点地址、学习方式和项目内容替换这些过时信息。

## What Changes

- 明确介绍项目的可视化学习定位和当前公开站点链接。
- 说明访问者如何在线浏览学科、学段和主题，以及如何本地预览静态站点。
- 删除迁移来源、私有本地历史和不再准确的建设状态及冗长内部维护说明。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无；只调整 README 的公开文案，不改变学习站功能或工程契约。`.openspec.yaml` 设置 `skip_specs: true`。

## Impact

仅修改仓库根目录 `README.md` 和相关差距记录，不改变站点页面、API 或发布产物。
