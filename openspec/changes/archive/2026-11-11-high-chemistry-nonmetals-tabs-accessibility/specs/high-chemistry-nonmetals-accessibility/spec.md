## Purpose

确保高中化学非金属主题入口及氮、硫转化系列可由键盘和辅助技术发现、选择与确认，并让当前可视化、转化列表和文字摘要表达同一知识网络。

## ADDED Requirements

### Requirement: 非金属学习主题可通过可访问页签切换

非金属页面 MUST 将元素特性、氯气实验、转化关系和互动练习作为一个有可访问名称的页签组呈现。每个入口 MUST 暴露 `tab` 语义、可访问名称、选中状态及其内容面板关系；当前内容 MUST 暴露为有标签的 `tabpanel`。页签组 MUST 只有一个 Tab 停靠点；方向键 MUST 循环移动并激活对应主题，Home 和 End MUST 分别移动并激活首尾主题。Enter、Space、点击和触屏 MUST 可激活主题，页面 MUST 显示可见焦点。

#### Scenario: 初始主题和面板关联可识别
- **WHEN** 学习者打开非金属页面
- **THEN** 四个主题入口位于命名页签组中，只有“元素特性”被选中，且可访问的当前面板与该页签关联

#### Scenario: 键盘导航主题
- **WHEN** 焦点位于任一主题页签并按 Left/Right Arrow、Home 或 End
- **THEN** 焦点、选中状态及可见内容同步移动到对应主题

#### Scenario: 原生键盘和指针激活主题
- **WHEN** 学习者使用 Enter、Space、鼠标或触屏激活主题
- **THEN** 该主题成为唯一选中项并显示对应面板

### Requirement: 氮硫系列选择可访问且说明保持同步

转化关系面板 MUST 提供有名称的单选组，分别表示氮系列和硫系列；任一时刻 MUST 只有一个选项被选中，键盘焦点 MUST 可见。方向键 MUST 在选项间移动并激活；Enter、Space、点击和触屏 MUST 能选择选项。关系图 MUST 提供随系列更新、列明图中物质的文字替代；配套转化列表 MUST 提供物质间的关系。选择后关系图、转化列表、选中状态和文字摘要 MUST 全部对应同一系列。切换系列 MUST 清除之前选中的反应及其详情，避免保留另一系列的内容。

#### Scenario: 初始显示氮系列
- **WHEN** 学习者首次打开转化关系面板
- **THEN** 氮系列被选中，关系图、列表和说明均显示氮及其化合物转化

#### Scenario: 切换到硫系列
- **WHEN** 学习者选择硫系列
- **THEN** 硫系列成为唯一选中项，关系图和列表展示硫转化，说明显示硫系列摘要且不再显示氮系列摘要

#### Scenario: 切换系列时清除旧反应详情
- **WHEN** 学习者打开一条硫系列反应详情后切换到氮系列
- **THEN** 当前反应选择重置，详情区域显示中性提示且不再展示硫系列方程

#### Scenario: 键盘切换并恢复氮系列
- **WHEN** 焦点位于系列选项并使用方向键、Enter 或 Space 选择另一系列
- **THEN** 选中状态、关系图、列表和说明同步更新；再次选择氮系列时恢复氮系列内容

### Requirement: 非金属导航在窄屏内可用

四个主题入口及转化系列选项 MUST 在 320 CSS 像素视口中保持可见、可操作，页面 MUST 不产生横向溢出。

#### Scenario: 320 像素视口访问各入口
- **WHEN** 学习者在 320 CSS 像素宽度下访问四个主题并打开转化关系面板
- **THEN** 所有主题入口和系列选项均可见，页面滚动宽度不超过视口宽度
