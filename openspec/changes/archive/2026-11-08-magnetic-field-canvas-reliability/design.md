## Context

见 [proposal.md](proposal.md) 的复现证据。当前 `init` 和 `resize` 对所有画布执行尺寸重设；非活动 section 的 `offsetWidth` 为零。`switchTab` 只修改 class，不重设或重绘新活动画布。轨道动画在初始化时无条件启动，两个动画函数都通过 `requestAnimationFrame` 自行续帧。

## Goals / Non-Goals

**Goals:**

- 将画布生命周期集中在当前活动 section，确保其尺寸、缓冲区和图像同步。
- 离开动画主题时取消下一帧，重新进入时从已保存的主题状态继续。
- 保持既有物理公式、交互参数和按三道不同题完成的测验行为。

**Non-Goals:**

- 不重新评估磁场物理模型、题目答案、文案或颜色设计。
- 不重构全站 canvas API，不增加统一组件或运行时依赖。
- 不在本次改造中暂停浏览器整体隐藏标签页中的所有页面动画。

## Decisions

1. **按 section 映射绘制入口。** 磁感线、安培力、洛伦兹力和轨道分别使用现有 resize 与 update 函数。初始化只渲染默认 section；切换时先显示 section 再调用该入口；resize 事件只作用于活动 section。相比提前初始化隐藏画布，这避免零宽写入，也减少不活动主题的工作。
2. **磁针位置以画布相对坐标保留。** 缩放前记录旧 CSS 宽度，重设活动画布后按宽度比例变换 `needleX`，纵向固定高度不变。这样用户放置的磁针在横向视口变化时仍落在相同可视区域。
3. **动画帧句柄作为暂停/恢复状态边界。** 离开轨道或洛伦兹 section 时取消已排队的 RAF 并清空句柄，不修改轨道角度或粒子计时；重新进入主题时重绘一次当前状态，再按条件启动单一 RAF 链。洛伦兹粒子已自然结束时不自动重启。
4. **行为回归覆盖绘制和进度。** 桌面/移动专项测试检查四张 canvas 的显示尺寸、内部尺寸和非透明像素，验证滑块/方向/磁针、窗口变化、动画暂停恢复和三道不同题完成刷新。旧实现需在首次切换或缩放场景中失败，以确认测试捕捉到实际缺陷。

## Risks / Trade-offs

- [绘制入口和主题索引映射遗漏] → 测试显式枚举四个主题和四张画布，并在窄屏重复验证。
- [快速切换导致 RAF 重复启动] → 所有启动入口检查帧句柄；切出时取消并清空，测试主题往返及推进状态。
- [调整视口后磁针越出画面] → 只按宽度比例转换位置，回归检查坐标比例并覆盖 320 像素视口。

## Migration Plan

无需存储迁移。先提交能在旧代码下失败的专项回归，再加入活动主题绘制分发和 RAF 暂停/恢复；通过静态检查、全页冒烟及 OpenSpec 严格校验后归档，推送主分支并核验 Actions、Pages 清单和公网行为。回退本次页面脚本及专项测试即可恢复先前实现。
