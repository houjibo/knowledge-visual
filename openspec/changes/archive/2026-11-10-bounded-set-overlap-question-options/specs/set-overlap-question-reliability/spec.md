## Purpose

确保集合重叠练习和挑战在随机结果重复、正确答案为零或干扰项候选不足时仍能及时生成可作答题目，并保持答案与题意一致。

## ADDED Requirements

### Requirement: 集合重叠题有限生成唯一选项

集合重叠练习和十题挑战 MUST 在有限步骤内为每道题展示恰好四个互不相同的数值选项，并且 MUST 恰有一个选项等于该题正确答案。正确答案为零时 SHALL 保留零作为正确选项，且不得将零用作干扰项。

#### Scenario: 重复随机值下练习仍可作答
- **WHEN** 练习模式生成题目时随机值持续返回同一数值
- **THEN** 页面在有限步骤内显示题目及四个互异选项，且唯一正确选项符合题意

#### Scenario: 零重叠答案仍可作答
- **WHEN** 题目询问两组重叠人数且正确答案为零
- **THEN** 四个互异选项中包含且仅包含一个零，选择零后显示正确反馈并只记录一次答对

#### Scenario: 挑战模式重复随机值
- **WHEN** 挑战模式在重复随机值下开始一题
- **THEN** 页面在有限步骤内显示四个互异选项，选择唯一正确选项后正确计数增加一次并继续挑战

#### Scenario: 窄屏练习与挑战
- **WHEN** 学习者在 320px 视口打开练习或挑战题目
- **THEN** 四个选项均可见并可操作，页面不得出现横向溢出
