## Purpose

保证动量学习页的交互输入、可视化画面、物理量反馈和练习进度彼此一致，并支持键盘及窄屏操作。

## ADDED Requirements

### Requirement: 主题导航和画布状态保持一致
页面 MUST 提供具备标签页语义的四个学习主题入口，支持方向键及 Home、End 键移动和选择主题。切换主题或视口尺寸变化后，活动画布 MUST 按可见区域重新绘制，画布尺寸 MUST 与其可见布局匹配；切换主题 MUST 保留其他主题的控制参数和模拟状态。

#### Scenario: 键盘切换主题
- **WHEN** 键盘焦点位于主题标签并按下方向键、Home 或 End
- **THEN** 焦点和选中状态移动到对应主题，关联内容面板随之显示

#### Scenario: 首次显示隐藏画布
- **WHEN** 用户切换到碰撞或反冲主题
- **THEN** 画布具有非零的可见尺寸并绘制该主题的初始场景

#### Scenario: 缩放后重绘
- **WHEN** 用户缩小视口或调整浏览器窗口尺寸
- **THEN** 当前可见画布适配新尺寸并重新绘制，原主题控制参数保持不变

#### Scenario: 切换主题期间继续运行
- **WHEN** 用户在模拟运行期间切换到另一主题，再返回原主题
- **THEN** 原模拟状态继续推进且返回后按最新状态重绘，不因面板隐藏而提前结束

### Requirement: 冲量模拟忠实反映设定时长与输入
冲量主题 MUST 展示并允许用户设置作用时长，计算并显示初动量、冲量及当前动量，使 `I = FΔt` 且当前动量等于初动量加冲量。模拟运行期间，质量、初速度、作用力和作用时长 MUST 保持与本次模拟一致；重置或修改空闲状态下的输入 MUST 清除旧计时器和陈旧模拟结果。

#### Scenario: 不同作用时长
- **WHEN** 用户以相同质量、初速度和作用力运行两个不同的作用时长
- **THEN** 每次显示的冲量等于力乘以该次作用时长，当前动量符合动量定理

#### Scenario: 运行期间参数一致
- **WHEN** 冲量模拟正在运行
- **THEN** 参与该次模拟的控制参数不可修改，显示的冲量与速度变化使用同一组输入

#### Scenario: 重置取消活动模拟
- **WHEN** 用户在冲量模拟结束前重置
- **THEN** 动画立即停止，参数恢复可编辑，冲量回到零且当前动量恢复为初动量

### Requirement: 碰撞和反冲保留有符号动量关系
碰撞及反冲模拟 MUST 按设定的质量和速度计算并显示有符号动量。碰撞图中的动量柱 MUST 以零为共同基准，正动量朝右、负动量朝左；动画运行期间所用物理参数 MUST 保持固定，重置 MUST 立即停止当前动画。

#### Scenario: 三种碰撞类型
- **WHEN** 用户分别运行弹性、完全非弹性和一般碰撞
- **THEN** 碰撞前后总动量保持不变，并且仅完全弹性模型保持总动能不变

#### Scenario: 动量柱的方向
- **WHEN** 某球的动量为正或负
- **THEN** 对应动量柱分别从零基准向右或向左延伸，数值符号与方向一致

#### Scenario: 反冲参数改变
- **WHEN** 反冲动画运行中，或在动画结束后用户调整质量或抛射速度
- **THEN** 运行中的参数保持锁定；动画结束后的参数修改会将显示重置到与新参数一致的静止初态

### Requirement: 练习按不同题目计入学习进度
练习选项 MUST 可通过键盘访问和选择。每道题 MUST 只接受一次作答；页面 MUST 仅在三道不同题目均首次答对时标记动量主题完成，错误答案和重复答案 MUST NOT 增加完成数。

#### Scenario: 同题重复作答
- **WHEN** 用户选择一道题的选项后再次激活该题其他选项
- **THEN** 该题结果保持不变，答案控件保持禁用，完成计数不重复增加

#### Scenario: 三道不同题答对
- **WHEN** 用户首次答对三道不同题目
- **THEN** 动量主题完成状态被记录并在刷新页面后保留

#### Scenario: 一题答错
- **WHEN** 用户首次答错一道题并首次答对另外两道题
- **THEN** 动量主题仍未完成
