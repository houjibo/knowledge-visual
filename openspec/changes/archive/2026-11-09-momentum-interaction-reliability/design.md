## Context

页面将四个主题放在同一 HTML 中，使用 `display:none` 隐藏非活动面板。三个 canvas 在脚本初始化时立即读取宽度，故隐藏面板的缓冲区维持默认宽度；动画由局部 `setInterval` 驱动，重置函数没有持有 interval ID。主题和答案选项使用带 `onclick` 的 `div`，动量柱直接把有符号宽度传给 `fillRect`，但 A 柱反转了符号。

专项基线已在本地 Chrome 复现：初始 `collisionCanvas` 和 `recoilCanvas` 的 CSS 宽度为 0、内部宽度为 300；切换后 CSS 宽度变为 726，内部宽度仍为 300。重复点击同一道正确题三次即可点亮动量进度。

全量浏览器回归还发现多项测试在 `clock.install()` 后用 Node 的 `Date.now()` 调用 `pauseAt()`；墙钟可能早于刚安装的模拟时间而触发“Cannot fast-forward to the past”。本轮统一使用固定 UTC 起始时间，并保留原有定时器推进断言。

## Goals / Non-Goals

**Goals:**
- 在现有单页架构内修复交互、模型输入与绘制尺寸同步，不新增依赖。
- 让每个模拟拥有可取消的计时器，并确保一次运行只读取一组参数。
- 用桌面和窄屏浏览器回归覆盖页面可见行为及主要物理不变量。

**Non-Goals:**
- 不重写碰撞或反冲的物理教学内容，不改变页面地址或知识地图标识。
- 不将页面拆分为组件或引入全站共享模拟框架。
- 不声称覆盖真实设备、完整屏幕阅读器体验或所有物理边界组合。

## Decisions

1. **用原生按钮承载主题与测验选项，并实现标签页键盘模式。** 原生控件提供可预测的键盘、焦点和禁用行为；替代方案是保留 `div` 并手工补齐 role、tabindex 和键盘逻辑，维护负担更高。主题间以 `aria-selected`、`aria-controls`、`aria-labelledby` 连接，方向键、Home、End 同时移动焦点并切换内容。
2. **按可见面板尺寸管理 canvas，并用逻辑像素绘图。** 初始化和主题切换时仅测量并重绘活动 canvas；窗口缩放后再次测量。内部缓冲区按设备像素比设置，绘图坐标使用 CSS 逻辑像素。替代方案是在首次载入时给所有隐藏画布估算宽度，无法应对窄屏、缩放及实际布局差异。
3. **显式保存并清理三个模拟的 interval ID。** `reset` 和重新开始先清除旧 interval，再初始化状态；运行期禁用影响该次计算的滑块/选项，结束或重置时恢复。继续使用已有 interval 而不迁移到 RAF，避免扩大时间步长和物理模型的改动范围。
4. **所有空闲参数编辑都回到一致的静止初态。** 冲量页重置速度、时间和冲量；碰撞页以当前质量和速度重算初始值；反冲页清零速度并按当前参数刷新动量。替代方案是尝试将新参数并入已结束动画的状态，容易形成显示参数与运动结果不同源。
5. **将冲量时长设为离散秒数并在本次模拟中锁定。** 1–6 秒、1 秒步长、默认 3 秒，使 `FΔt` 可直接比较且与 0.05 秒模拟时间步整除；不新增暂停功能。
6. **进度按题目唯一标识去重，每题第一次选择后禁用整组答案。** 第一次答错也会展示解释并结束该题，只有首次答对的不同题目增加进度，三题完成条件仍与现有页面目标一致。
7. **测试时钟使用同一个确定时间点。** 安装与暂停共用固定 UTC 时刻，避免用递增的真实 `Date.now()` 产生模拟时钟倒退；替代方案是给 pauseAt 追加真实时间偏移，仍依赖机器负载和调度时序。

## Risks / Trade-offs

- **DPR 缩放可能让绘图尺寸逻辑混用。** → 绘制函数统一使用 `canvas.clientWidth/clientHeight`，以当前设备像素比设置 context transform，并用像素及尺寸断言回归。
- **在动画运行中禁用控件会降低试探自由度。** → 运行结束立即恢复控件；重置按钮持续可用，帮助用户快速开始另一组输入。
- **小屏碰撞画布中的球体可能过于接近。** → 保留当前画布高度和球体大小，只验证无裁切、可见尺寸与方向；更广泛的布局改版另开变更。
- **间隔计时与后台标签页节流会影响演示耗时。** → 验收关系以输入、动量/能量不变量和完成/重置状态为主，不依赖精确墙钟帧率。

## Migration Plan

1. 增加专项回归并用旧页面记录零宽画布、参数漂移、错向动量柱、旧 interval 与重复计分基线。
2. 一次只修改导航/画布、模拟生命周期、测验计分三个相互关联的切片，并立即运行对应桌面和窄屏回归。
3. 更新交互证据与风险清单，执行静态检查、完整浏览器回归、全站冒烟及严格 OpenSpec 校验。
4. 小步提交并推送；Actions 通过且 Pages 发布清单指向提交后，复核本地与公网页面并归档变更。

回滚时撤回该提交即可恢复原页面；不涉及持久化数据格式迁移。
