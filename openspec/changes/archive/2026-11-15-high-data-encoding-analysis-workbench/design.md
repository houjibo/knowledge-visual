## 学习模型

编码面板只提供 `A`、`中`、`🌱` 三个单码点符号；浏览器 `TextEncoder` 产生 UTF-8 字节，显示字节数及每字节十六进制、八位二进制。预测错误保留反馈并可再试。面板不把 JavaScript 字符串长度、码点数或字节数混为一谈，也不推断任意文字的“字符数”。

数据面板用周一 18 L、周二 21 L、周三 21000 mL、周四缺失、周五 23 L 和一条同 ID 的周五重复记录。学习者先选择换算、缺失和重复处理方案；三项均正确后才计算四个观测日及均值 20.75 L。周四明确显示缺失，不按 0 L 算；重复只留一条。四个有效读数可编辑，重新计算后图表、均值答案和报告同步刷新，不沿用旧答案。图表使用相同单位和从 0 开始的动态刻度，文字列表提供等价数值。

均值预测可接受两位小数，题意明确按清理后四个有效日计算。报告题只接受“当前四个观测日的均值，不能外推缺失日或更长时期”的结论。完成资格要求三种编码预测、清理方案、当前均值预测及报告判断全部正确；若 `SubjectProgress` 写入失败，保留已赢得资格供重试，不覆盖损坏的原始存储。更改数据后当前均值/结论挑战需要重新核对，但已保存的历史完成记录不删除。

## 内容与交付边界

HS25 1.1 涉及数据编码、挖掘、知识发现和大数据；此主题只补编码及小样本分析，状态从缺失变为部分。1.2 涉及任务方案、采集、整理、分析、可视化和报告；此主题加强整理、计算、可视化与限定结论，仍为部分。字体、页面结构和相对资源路径沿用计算机学科现有约定，支持直接文件、仓库子路径和无账号静态发布。
