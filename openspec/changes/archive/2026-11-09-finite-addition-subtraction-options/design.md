## Context

页面启动时顺序调用竖式演示、口算、选择挑战、估算和应用题生成器。选择挑战从精确答案附近随机抽取不同整数；估算练习从精确值附近抽取干扰项，同时要求选项包含精确值和整百估算值。固定随机值 0 时两处都会重复同一个结果而卡住，其中估算答案恰好等于精确值时还会因集合去重而缩小候选数。

## Goals / Non-Goals

**Goals:**

- 两种练习在任何重复随机值下都能有限终止。
- 每题有四个不同的非负整数选项；挑战恰有一个等于精确答案，估算恰有一个等于整百估算答案。
- 估算题的精确值与估算值不同时，保留精确值作为可辨认的错误选项。
- 验证桌面和移动作答计分、换题及窄屏选项可见范围。

**Non-Goals:**

- 不改动本页其他三种练习、竖式步骤、题目范围或挑战轮数。
- 不抽取跨页面公共题目生成器。

## Decisions

- 使用有限偏移表替代重抽：选择挑战的干扰项从精确答案的 ±10 至 ±200 候选中选取；估算干扰项从精确答案的 ±10 至 ±500 候选中选取。候选过滤负数、必需答案及重复值后有限取足所需数量，最后打乱选项。按当前题目范围至少有三个有效干扰项。
- 估算题仍以 `[estResult, estAnswer]` 为必需选项；集合去重确保两者相同仅显示一次，干扰候选生成仍只运行有限次数。
- 浏览器回归使用固定随机值 0、0.5、0.999999，分别覆盖加法、普通减法及答案接近零的减法；独立从算式及整百提示计算答案，验证四个互异选项、唯一正确答案、计分与下一题。320px 测试检查两种练习的选项边界和触控高度。

## Risks / Trade-offs

- 确定的偏移集合比原随机抽取更规律；最终选项仍会打乱，且每题的正确答案和精确/估算关系会变化。
- 如果日后缩小题目范围，偏移表可能不足以提供三个非负干扰项；生成器显式检查候选数量并抛出错误而不会无限挂起，回归也会验证四个选项。

## Migration Plan

替换两个选项循环并注册浏览器回归。无需迁移学习记录；如回归不通过，可回滚页面、测试和对应文档。
