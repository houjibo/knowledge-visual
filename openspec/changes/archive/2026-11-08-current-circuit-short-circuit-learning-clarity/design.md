## Context

动机和范围见 [proposal.md](proposal.md)。页面现有电路模型标注 6 V、每灯 10 Ω，并明确忽略导线和电源内阻；现有短路说明却把电流表述成无条件“极大”。

内容核对依据：OpenStax 将短路定义为连接电源端子的低电阻路径，并说明含电源内阻的回路电流取决于总电阻（[术语表](https://openstax.org/books/college-physics-2e/pages/20-glossary)、[电动势与端电压](https://openstax.org/books/college-physics/pages/21-2-electromotive-force-terminal-voltage)）。安全提示参考[西安市应急管理局安全用电科普](https://yjglj.xa.gov.cn/kp/64fee17cf8fd1c1a70387e76.html)：未确认断电前不直接接触伤者，高压事故应远离现场并呼救。

## Goals / Non-Goals

**Goals:**

- 让学习者看见“低阻通路 → 电流可能增大 → 过热或损坏风险”的因果顺序，并区分理想模型与真实电路。
- 让该说明可由键盘和辅助技术操作、读取，并在窄屏完整呈现。

**Non-Goals:**

- 不模拟或估算故障电流，不增加实际短路接线方案。
- 不修改现有串联、并联计算、学习进度或页面 URL。

## Decisions

1. **限定因果措辞，不提供故障数值。** 用“可能增大”和“存在过热、损坏或起火风险”，说明实际电流受电源内阻、线路及保护条件影响。本页没有这些参数，按欧姆定律不能推导真实故障数值。相较于只删掉“电流极大”，同时呈现原因和后果更有助于学习者理解。
2. **采用原生 `<details>/<summary>` 与有序步骤。** 浏览器原生控件已有键盘展开/收起及可识别状态；有序列表以 CSS 箭头形成因果流程，同时保留完整文字顺序。相较于自制按钮、SVG 画布或第三种电路模式，它不引入额外状态，也不会让人误以为页面正在计算故障电流。
3. **明确禁止把图示用于实操。** 因果流程仅解释风险，不提供接线细节；保留现有可操作的安全低压模型，不要求学习者短接任何电源。

## Risks / Trade-offs

- [风险] “短路可能导致火灾”可能被理解为每次短路都会起火 → 用“可能”和“风险”表述，并注明保护与线路条件会影响结果。
- [风险] CSS 箭头在窄屏或禁用样式时不能传递顺序 → 顺序以有序列表和文本标签表达，测试窄屏及键盘展开。
- [风险] 用户把低压教学模型误用于现实电路 → 清楚标注非接线图、非实验指导，提醒勿实际短接并求助成人或专业人员。
