## Context

现有站点为静态 HTML/CSS/JS，无构建依赖；存在 330 个 HTML 文件。直接打开文件是已记录的使用方式。OpenAI harness 建议将 AGENTS.md 作为知识地图，详细信息放在仓库中。

## Goals / Non-Goals

- 建立轻量、可维护的入口、工作流、差距台账和验证脚本。
- 保持静态站点和直接打开的兼容性，不迁移框架、不重写既有内容。
- 检查只覆盖静态声明的相对文件引用和选定文档链接，不声称验证交互、科学正确性或外链。

## Decisions

- AGENTS.md 只索引；项目事实与约束放 docs，变更契约放 OpenSpec，避免重复维护。
- 从指定 eng-* 技能提炼三个工作流并注明来源，保持流程自包含；不依赖源目录运行。
- 用 Python 标准库检查现存静态相对引用，报告定位和退出状态；不引入包管理器。
- 使用 OpenSpec CLI 的 spec-driven schema；以完整变更记录驱动后续增量，而非宣称无人值守自动运行。

## Risks / Trade-offs

- 静态扫描无法发现 JavaScript 动态路径或判断视觉和教学效果；交互修改仍需浏览器验证。
- 文档可能过期；将差距与更新责任写入工作流，并用检查守住入口链接。
