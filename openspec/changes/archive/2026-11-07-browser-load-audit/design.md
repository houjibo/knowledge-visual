## Context

仓库生成的静态清单列出所有 330 个 HTML，现有浏览器测试只覆盖四条学习路径；清单无法观察页面运行时异常。

## Goals / Non-Goals

检查所有列入清单页面在桌面 Chromium/HTTP 下加载时的 HTTP 响应、标题、本地资源 HTTP 错误和未捕获脚本异常；不代替交互、延迟事件、窄屏或教学内容验证。

## Decisions

按清单为每个页面生成独立测试、使用独立浏览器上下文并输出路径。加载后有限等待以捕获初始异步错误；过滤外部资源错误并明确边界。不把已知失败静默豁免，记录并按原因拆分修复。

## Risks / Trade-offs

测试依赖浏览器、网络及执行时间，既有页面可能存在加载问题；外链、动态交互和等待窗口之后的异常无法通过本检查证明。
