## Context

四条代表页面已有桌面手动抽查，仓库已有 Python 静态检查和模拟 DOM 进度测试，但没有可复跑的浏览器测试。

## Goals / Non-Goals

以独立的 HTTP 服务运行真实浏览器，覆盖从首页到主题的导航、关键操作与反馈；不宣称覆盖全站、全部题目或教学准确性。

## Decisions

采用固定版本 Playwright 测试依赖，默认使用其管理的 Chromium，允许通过环境变量指定本机浏览器用于受限环境。每个测试使用独立上下文，避免污染学习进度；服务绑定回环地址、独占端口，避免误用已有站点。分别验证四学科主要路径及键盘模式切换。

## Risks / Trade-offs

需安装 Node 开发依赖与浏览器；浏览器二进制依赖平台。样本不能替代全站冒烟、窄屏、无障碍和知识正确性测试。
