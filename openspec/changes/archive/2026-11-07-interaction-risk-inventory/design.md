## Context
全站加载冒烟和部分主题交互证据不能定位所有随机重试及不可键盘操作的模式入口；历史粗略扫描不可持续复现。

## Goals / Non-Goals
记录可定位的静态候选与局限，辅助选择后续 OpenSpec 变更；不以静态特征判定循环一定无限或控件一定不可访问。

## Decisions
使用标准库 HTML 解析器收集 div 的指定类名与内联脚本的 while 位置，稳定排序生成 Markdown；测试类名边界、行号、忽略依赖与陈旧文件。静态门禁检查清单同步。

## Risks / Trade-offs
不是 JavaScript 语法解析器，注释和字符串可能误报；外部脚本、动态 DOM 和其他循环可能漏报，报告明确列出限制。行号随页面编辑变化，需要重新生成。
