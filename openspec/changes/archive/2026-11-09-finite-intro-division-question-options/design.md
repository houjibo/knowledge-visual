## Context

页面启动时依次初始化分一分、写算式和选一选。分一分通过随机重抽补齐三个数字选项；选一选的“求商”和“求除数”题也通过随机重抽补齐两个干扰项。有限种子如 0 或 0.999999 会使同一候选反复出现。选算式题直接拼接三个表达式；当除数和商相等时，正向与反向算式相同。

## Goals / Non-Goals

**Goals:**

- 所有随机选项生成都以有限候选集完成，不依赖再次抽样才能取得新值。
- 每个选择题展示互异的三个选项，并且只有一个选项符合该题预期。
- 固定随机值下，页面仍能完成初始化、显示题目、判题并继续下一题。

**Non-Goals:**

- 不重构整页的模式切换、学习进度、题目范围或反馈时序。
- 不清理仓库其他页面的随机循环；按交互风险清单逐项核验。

## Decisions

- 为数值答案先构造范围内除正确答案外的有限整数候选，并按与答案的距离从近到远排列；取前两项作为干扰项后再打乱整组选项。分一分、求商、求除数均有足够候选，随机值只影响呈现顺序，不影响终止或干扰项的难度范围。
- 选算式题保留目标除法算式，并通过改变商构造不同且错误的算式选项；用集合去重后有限选取两项，避免除数等于商时重复正确选项。
- 浏览器用固定随机值 0、0.5、0.8 和 0.999999 覆盖启动卡死边界、三种选择题类型及除数等于商的边界；同时验证分一分与选择题的答案唯一，并对写算式练习执行完整作答回归。

备选方案是给原循环设置最大重试次数再补兜底值。该方案仍需另行保证候选不重复，且增加难以证明的分支，因此选用一次构造有限池的方式。

## Risks / Trade-offs

- 相邻数值干扰项会更规律 → 每道题会变化正确答案与选项次序，测试确保干扰项仍在正确答案附近且唯一；未来如题目目标改为更广范围的估算，再单独设计难度梯度。
- 将来扩大题目范围或更换题型时，候选构造可能不再足够 → 浏览器测试要求三个互异选项及唯一答案，范围调整时同步更新该契约。

## Migration Plan

替换当前页的选项构造并注册新增浏览器回归。无需迁移已有进度数据；如回归失败，可单独回滚页面实现、测试和此变更。
