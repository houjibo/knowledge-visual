## Context

实际本地页面的辅助树把四个主题和页内操作都识别为纯文本；从页面开始按第一次 Tab 直接到碳原子数滑块。源码中甲烷的 `n=1` 被通用烷烃分支先捕获，画了三个氢；C₆H₁₄ 的三个手写支链小图只有五个碳节点；命名画布绘制与题目无关的环状装饰。`PageProgress.markDone` 返回是否成功写入，但现页忽略返回值。结构滑块和命名上一题/下一题重复调用绘图入口会增加并行动画循环。

语义依据：[W3C 页签模式](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)规定命名的 tablist/tab/tabpanel、选中态和方向键；[原生按钮](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button)提供键盘和触屏激活。知识核对以 [PubChem 甲烷 CH₄](https://pubchem.ncbi.nlm.nih.gov/compound/Methane)、[PubChem 正己烷 C₆H₁₄](https://pubchem.ncbi.nlm.nih.gov/compound/hexane)及 [RSC 结构异构教学说明](https://edu.rsc.org/cpd/teaching-organic-chemistry-post-16/4014454.article)为限；页面其他反应条件和教学效果仍需另行审校。

## Decisions

- 四个按钮页签各关联一个 `tabpanel`。唯一的现有画布与参数区容器随选中页签移至对应面板，保留其 DOM 状态与事件绑定；未选面板隐藏。方向键循环，Home/End 到首尾，原生 Enter/Space 激活，只有当前页签进入 Tab 序列。切换后停止旧绘图、初始化目标内容，焦点留在目标页签。
- 页内互斥选择使用原生 `button type=button` 与 `aria-pressed`。同分异构卡片只更新自身状态和详情，不重建卡片，保持焦点；真正切换分子式才重建卡片。反应类型只更新内容与按钮状态，不重建按钮。命名上一题/下一题重绘后把焦点放到新题目。
- 以每种异构体的主链长度及甲基支链位置作为碳骨架数据；共用绘图函数从该数据画边与碳节点。C₄、C₅、C₆ 每张卡片都显示结构简式，图旁说明未画氢；数字、简式与碳节点数可以独立核对。甲烷独立画 CH₄；一个碳不能形成烯烃或炔烃时不给出甲烷图。
- 结构、异构、命名、反应四种画布状态在交互时更新 `aria-label`，并保留页面文字信息。命名画布只显示真实题目结构简式与用途说明。画布 2D 不可用时只提示图示不可用，不阻断文字和控件。
- 既有八题、每题一次作答、累计五道不同题正确的门槛保持；命名进度只在 `markDone('organic')` 返回 true 时显示已保存。失败时保留已达标集合与重试入口；不覆盖损坏的本机记录。旧已完成记录继续显示，但不代替本轮成功写入。
- 绘图入口取消旧帧再安排下一帧，最多一个待执行动画帧；减少动态偏好只画静态帧，页面隐藏后不自动恢复。页签/参数再次操作可重画。反应动画只是阶段示意，不呈现分子机理或实测时间。
