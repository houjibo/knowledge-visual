## MODIFIED Requirements

### Requirement: 公网核验覆盖计算机与人工智能
发布后检查 SHALL 在版本清单匹配当前提交时，分别验证计算机、人工智能学科入口和可检索主题；至少各完成一个代表性交互，并确认旧主题地址能到达新位置。

#### Scenario: 核验两个新学科
- **WHEN** GitHub Pages 部署当前提交且两学科资源可访问
- **THEN** 部署后浏览器测试可从首页分别搜索进入计算机与人工智能主题，执行核心操作并收到反馈

#### Scenario: 核验已发布 AI 交互
- **WHEN** GitHub Pages 部署当前提交且人工智能资源可访问
- **THEN** 部署后浏览器测试可从首页搜索进入人工智能主题、执行核心操作并收到反馈

#### Scenario: 核验旧地址兼容
- **WHEN** 发布后浏览器打开旧计算机与人工智能主题地址
- **THEN** 浏览器到达对应新学科主题且无站外导航或加载错误
