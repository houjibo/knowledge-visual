## Context

动机和用户可见范围见 [proposal.md](proposal.md)。读图数据的计数范围目前为 2～10。差值题用 `Math.abs` 求两类数据之差，但文案固定说第一类“比”第二类“多”；差值为 0 时，候选数组重复加入 0，再经 `Set` 去重而减少选项。

## Goals / Non-Goals

**Goals:**

- 让题干不依赖随机选择两类的先后顺序。
- 为零差值和非零差值都生成四个不同的非负整数选项。
- 保留现有随机题型选择、图表数据、按钮反馈和计分行为。

**Non-Goals:**

- 不修改条形图读图的其他题型、图表绘制或其他学科的统计题。
- 不改变调查数据范围、学习进度或题目完成条件。

## Decisions

1. **采用对称的“相差”题干。** 题目仍随机选两类数据，但使用“X 和 Y 相差几人？”；这与绝对差定义一致。另一种方案是每次交换类别，确保较大值在前，但相等时仍需要特殊措辞，而且会让题目顺序与随机选择相互耦合。
2. **从有限数值全集选三个干扰项。** 使用从 0 到图中最大计数（且至少到 3）的整数候选，排除正确差值后打乱并取三个，再连同正确答案打乱。候选范围足以包含正确差值，因为两个非负计数的绝对差不会大于其中较大值；与随机重试或 `Set` 后接受不足四项相比，此方法在零差值下也固定返回四个选项。
3. **在浏览器中注入相等数据。** 通过读图入口将数据固定为三个相等计数，并固定随机源选择差值题；测试题干、四个唯一选项和答对反馈。这样覆盖真实页面交互，同时不依赖概率碰到边界。

## Risks / Trade-offs

- [风险] 干扰项可能包含比观察值略大的数 → 候选上限基于最大观察计数且至少为 3，确保选项仍是非负整数并保留足够区分度。
- [风险] 题干更换后自动化测试若依赖旧短语会失效 → 新回归直接检查“相差”和计数为 0 的固定场景。

## Migration Plan

无需数据迁移。更新页面后运行目标浏览器测试和静态/OpenSpec 校验，再归档变更；回退仅涉及本页题干与选项生成，不影响存档进度。
