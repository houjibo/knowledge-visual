## Context

物理学段导航卡片数为 20、16、19，而入口脚本配置为 13、13、15。化学入口使用相同静态配置模式。

## Goals / Non-Goals

校准物理入口并用检查约束两个学科的进度数字；不改动进度存储或其他学科，不处理历史无效记录。

## Decisions

保留静态配置以兼容直接打开文件；在既有 Python 标准库检查中解析各学段导航的 topic-card 和入口的 STAGES 数据。预期结构不能识别时显式失败，避免静默漏检。

## Risks / Trade-offs

检查依赖现有静态 HTML 和脚本配置形式，结构变化需同步更新检查；它不验证每个主题是否能够正确记录完成状态，也不能阻止用户已有无效记录。
