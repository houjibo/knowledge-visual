## Context
通过逐页比较确认八个主题的题目结构、按钮 ID 和通关条件一致，现有回看实现仅以累计变量计分。七页可复现重复计分，坐标系页上一变更已修复。

## Decisions
使用静态 `assets/math-quiz.js`，调用方传入题库、主题标识和原学段进度 API；每题保存一个选项，跳过按零分，结果按答案数组计算，重测清空本轮答案。选项和模式切换用原生按钮，练习已答后禁用。进度 API 返回失败时显示未保存，并处理后续成功重试通知。路径使用相对 URL，保留文件协议。

## Verification / Limits
桌面与移动视口对每个页面测试回看、错误答案、80%通关、学段存储和刷新；初中及高中代表页以 file:// 测试共享脚本与保存失败。只验证题目答案索引驱动的行为，不代表题目知识内容已全面审核；其他测验实现仍待调查。
