## Model

- 使用有界的离散温度教学模型，数值和干扰均为人为设定，不作为现实温控建议。
- 在同一起始状态、目标区间和扰动下，对比预先固定的风扇时序与每轮读取传感值后决策的反馈控制。
- 逐轮呈现输入、扰动、控制动作、输出状态和与目标的距离；把累计偏差标为该样例的比较指标，而非普遍的效率或安全结论。
- 单独对照“本地决策”和“云端决策”两种部署示意。模型规定断网时云端路径暂停并进入本例的静止安全状态，本地路径仍可用已配置规则；页面明确现实系统可能有缓存、冗余或不同失效策略。
- 说明断网下功能延续只证明模型中的执行路径；真实自主可控还需核查设备、软件、更新、数据保护、接口权限及运行维护能力。模拟器不能证明任何产品或国家安全属性。

## Page flow

1. 学习者先预测：有中途热扰动时，定时控制或反馈控制哪种更贴近目标。
2. 提交预测后，逐轮运行两个控制方案，查看简化系统图、状态轨迹和偏差摘要。
3. 选择控制器部署位置和网络状态，观察命令路径及断网结果。
4. 完成对“离线延续”“本地控制”“自主可控”边界的判断后记录本机进度。

## Constraints

- 用原生表单和 DOM/SVG/CSS 呈现；无需运行时依赖，兼容 HTTP 静态目录、本机服务、`file://` 和 GitHub Pages 子路径。
- 学习者必须先提交预测和断网结论，结果区再展开；切换输入后清空过时轨迹和完成状态。
- SVG 提供可访问名称，所有关键状态也以文本和表格呈现；键盘、320px 宽度和减少动态偏好均需验证。
