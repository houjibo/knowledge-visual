## ADDED Requirements

### Requirement: 相邻比较按条件交换
主题 MUST 从最左侧开始逐对比较未就位区域中的相邻数字，仅在左数大于右数时交换。每步 MUST 展示比较前的两数、交换或保持、操作后顺序和累计比较/交换次数；不得跳过尚未比较的相邻对或提前把最终排序结果替代逐步过程。

#### Scenario: 默认第一轮
- **WHEN** 对 `[4,2,5,1,3]` 逐步执行第一轮
- **THEN** 四次操作依次为交换、保持、交换、交换，数组成为 `[2,4,1,3,5]`，累计比较 4 次、交换 3 次

### Requirement: 每轮确定右侧已就位范围并适时终止
第一轮结束 MUST 标记最右一张已就位，后续每轮 MUST 只比较剩余区域。任一整轮无交换 MUST 立即判定全部有序并停止；最多四轮、十次比较后必须终止。终止状态再次点击不得改变数组或计数。

#### Scenario: 已排序输入
- **WHEN** 选择 `[1,2,3,4,5]` 并运行第一轮
- **THEN** 四次比较均保持、交换 0 次、第一轮后提前结束并标记五张已就位

#### Scenario: 逆序边界
- **WHEN** 选择 `[5,4,3,2,1]` 并运行到终点
- **THEN** 最终为 `[1,2,3,4,5]`，最多执行四轮、十次比较，不再比较上一轮已就位的右侧卡片

### Requirement: 预测第一轮并分别完成两类练习
学习者 MUST 在开始前预测第一轮交换 0–4 次，第一轮结束后才得知预测正误。只有分别正确预测并完整运行一组无序输入和已排序输入，才 SHALL 尝试记录 `computer/primary/adjacent-swap-sort` 完成。错误预测、未运行到终点或重复同类输入 SHALL 不提前完成或重复计数。

#### Scenario: 两种输入完成
- **WHEN** 学习者将默认输入第一轮预测为 3 次并完成排序，再将已排序输入预测为 0 次并运行到提前终止
- **THEN** 页面显示两类练习完成，尝试写入独立排序主题标记

### Requirement: 参数与计时器不能串轮
主题 MUST 提供单步、连续运行、暂停、重新排序和恢复示例。更换预置 MUST 停止自动执行、清空当前比较和历史步骤并锁定新轮初始状态；执行中不得改动本轮预测。重置 MUST 保留当前预置，恢复示例 MUST 还原默认预置；两类已正确完成和未保存资格 MUST 跨本轮重置保留。

#### Scenario: 运行中更换预置
- **WHEN** 连续执行一到两次后学习者选择另一组卡片
- **THEN** 旧计时器停止，新轮从初始五张卡片和 0 次比较开始，不追加旧轨迹

### Requirement: 进度保存如实且本地可用
主题 MUST 仅在 `SubjectProgress.markComplete` 成功时声称保存；拒写或损坏进度不得覆盖原文，已赢得资格可在恢复后重试。主题 MUST 有键盘可用的原生控件、可见焦点、可读卡片和状态，在 320px、减少动态、file 协议和 Pages 子路径中正常使用，且首页搜索与目录可发现新主题。

#### Scenario: 保存拒绝后重试
- **WHEN** 完成两类练习后本机进度拒绝写入，随后重新排序并恢复写入
- **THEN** 页面可重试保存此前赢得的资格，并明确当前轮仍是未完成状态
