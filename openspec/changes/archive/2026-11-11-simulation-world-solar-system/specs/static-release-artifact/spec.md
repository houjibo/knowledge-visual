## MODIFIED Requirements

### Requirement: 子路径中的代表性学习操作可用

发布包 MUST 包含经跟踪的模拟世界页面和 Three.js 0.128.0 本地运行资源。模拟世界目录、太阳系页及库脚本 MUST 使用相对路径，在仓库 GitHub Pages 子路径下无需向第三方 CDN 发出运行请求即可加载。发布验证 MUST 检查模拟世界关键页面、依赖文件和与预期提交一致的发布 revision。

#### Scenario: 发布太阳系模拟

- **WHEN** 发布包部署到仓库子路径
- **THEN** 首页、模拟世界目录、太阳系模拟和本地 Three.js 资源返回成功，初始化不依赖外站脚本

#### Scenario: 从首页进入主题
- **WHEN** 学习者在子路径部署的站点从首页查找或进入四学科代表主题
- **THEN** 页面及资源加载，所选学习交互可用
