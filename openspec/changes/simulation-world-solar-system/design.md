## Context

现有页面清单由路径决定 `subject`、`stage` 和 `kind`。首页搜索将学科与学段分别筛选；首页数量校验把每个可发现主题计为相应学科的知识点，学科卡片以 `subject-progress` 展示学习进度。模拟世界需要进入这些发现和发布链路，但没有真实学科、学段或学习完成语义。

用户提供的 `/Users/houjibo/Downloads/solar-system.html` 使用 Three.js 0.128.0、OrbitControls 和 CSS2DRenderer 展示太阳、八大行星、地球月球、轨道、小行星带和星空；用速度滑块与参考中心选择器控制动画，并支持鼠标旋转、平移和滚轮缩放。该文件是实现参考，发布页面需移除第三方 CDN 运行依赖并保留可解释的模型边界。

## Goals / Non-Goals

### Goals

- 新增独立的模拟世界导航入口和首个太阳系模拟主题，保持现有学科/学段入口、进度模型不变。
- 首页主题查找能发现无学段主题，并区分主题所属分类与学段筛选。
- 页面在静态站点根路径和仓库子路径运行；浏览器不能创建 WebGL 渲染器时，页面保留导航和文字说明并给出可理解的状态提示。
- 主要控件有原生标签、键盘操作和可读状态；移动视口不丢失主要操作。
- 以有限明确的测试覆盖初始场景、速度、参考中心、重置、画布缩放和发布资源。

### Non-Goals

- 不计算真实太阳系星历、牛顿引力、多体摄动、真实单位或现实尺度轨道。
- 不引入模拟主题的完成徽章、学科进度、账户、数据收集或服务器。
- 不据此一次性设计或承诺其他模拟世界主题。

## Decisions

### 目录和元数据

- 路径为 `simulation-world/index.html` 与 `simulation-world/solar-system.html`；界面分类名为“模拟世界”。
- 库存中 `subject` 为 `simulation-world`、`stage` 为 `null`、目录页为 `navigation`、主题页为 `topic`。主题目录生成器保留有 `subject` 但没有 `stage` 的主题；学段过滤只匹配实际学段。
- 首页使用独立类别卡片与“1 个模拟”徽标，不插入 `subject-progress`。首页一致性校验检查分类总数/徽标，但只为具有真实进度模型的类别读取进度区块。

### 模拟实现

- 使用与原 HTML 相同的 Three.js 0.128.0 API，保存必要的库文件和 MIT 许可证于仓库 `assets/vendor/three-r128/`；页面使用相对路径，不请求 CDN。
- 动画以帧时间推进，速度值 0 可以暂停；行星阶段初值固定，便于复现。选参考中心时将对应天体在模拟视图中保持居中，同时不在每帧重置 OrbitControls 的目标，以保留自由平移。
- 距离、行星半径和角速度仅为方便观察的示意值。学习说明直述尺寸/距离不按比例、轨道为圆形示意、运动由指定角速度驱动，不进行引力求解。
- WebGL 初始化失败时不替换整个文档；显示局部 `role=status` 信息并保留控件与静态模型说明。
- 尊重系统减少动态效果偏好：页面默认暂停运动，但学习者仍可显式调节速度开始观察。鼠标/触控导航沿用 OrbitControls，同时通过滑块、选择器和重置按钮提供可键盘操作的替代控制。

### 验收和发布

- 浏览器回归使用本地服务测试主题页、速度暂停/调速、参考中心、重置、窄屏、键盘和依赖请求；WebGL 不可用场景另测提示与文字说明。
- 静态目录测试验证首页、目录、搜索索引和发布文件关系；全页冒烟涵盖新增两个 HTML 页面。
- GitHub Pages 子路径验证本地库脚本、主题路径、标题与代表资源；发布后浏览器检查实际 WebGL 场景及控件。

## Risks / Trade-offs

- 本地 vendoring 增加约 650 KB 的静态资源与许可证维护责任，但消除 CDN 可用性对主题的运行时影响。
- Three.js 旧 API 被固定用于匹配提供文件，后续升级应作为单独变更并包含视觉/交互回归。
- headless CI 的 WebGL 能力可能与真实浏览器不同；测试要分别覆盖正常渲染与明确的不可用降级，不把 DOM 存在误当作 3D 绘制成功。
- 参考中心只改变观察坐标，不是从该行星出发的物理积分；UI 和说明需避免误导为真实观测数据。

## Migration

新增无学段分类记录，不迁移或改写现有学科、路径、进度键和已保存用户数据。
