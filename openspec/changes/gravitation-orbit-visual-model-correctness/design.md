## Context

参见 [proposal.md](proposal.md) 与 [spec](specs/gravitation-learning-reliability/spec.md)。页面把发射速度分支映射为手绘圆、椭圆和直线，未使用位置相关引力；速度比较目前按帧数推进。轨道面板将高度与半径混用，月球按钮给滑块赋值 384,400 km，但滑块上限为 40,000 km。各画布在隐藏面板初始化时读取零宽度，主题标签是不可聚焦的 `div`。

本次只使用现有静态 HTML/JavaScript、Canvas、Playwright 和 Node，不引入运行时依赖或构建步骤。

## Goals / Non-Goals

**Goals:**

- 用可独立单测的物理模型为近地点切向发射和圆轨道参数提供唯一计算来源。
- 将计算量、显示单位、轨道预设、画布和测验状态连成可观察、可回归的学习路径。
- 保持直接静态托管，模型假设、数值近似和示意比例明确可见。

**Non-Goals:**

- 不模拟大气阻力、地球自转、火箭推力、地形、非球形重力、月球/太阳摄动或日心转移；第三宇宙速度不接入地球二体发射积分。
- 不做真实比例的地月空间绘图，不将动画速度伪装成现实时间流逝。
- 不重构其他学段或其他页面的标签、画布和测验系统。

## Decisions

1. **把动力学计算放在无依赖模型文件中。** 新增 `physics/high/assets/gravitation-model.js`，暴露常量、半径对应圆轨道/逃逸速度、初始切向状态、轨道类别、引力加速度、一步积分与地表交点。文件采用浏览器与 CommonJS 兼容的轻量导出方式，使页面和 Node 单测调用相同实现；页面现有内联代码只负责编排和绘制。新页面脚本相对路径继续适配文件直开和静态服务器。

2. **使用地心反平方加速度与固定步长 Velocity Verlet。** 状态以 km、s、km/s 表示，地球取体积平均半径 6,371 km 和取整引力参数 μ=398,600 km³/s²；发射初始高度为地表以上 100 km，速度沿局部切线。Velocity Verlet 比当前阈值绘图提供真实位置依赖的中心力轨迹，且适合长时间有界轨道；固定 1 s 积分步、浏览器时间累加器和受限的单帧真实时间差，避免结果随刷新率显著漂移。绘制状态同时保留碰撞前轨迹，并把步进时穿过地表的线段插值到地表。

3. **根据比机械能和离心率判断轨迹类别。** `v_c=√(μ/r)` 与 `v_e=√(2μ/r)` 从初始地心半径计算。低于圆轨道速度的切向发射会与球形地球相交，速度等于圆轨道值时为圆，高于圆轨道且低于逃逸速度为椭圆；零比机械能为抛物线，正值为双曲线。屏幕用近似两位小数输入，因此边界按钮将速度设为显示精度内的对应值，模型只在这一舍入精度范围容许边界误差。

4. **区分高度与地心距离。** 轨道参数计算直接使用 r=R地+h。月球预设采用 NASA 标注的平均地月中心距离 384,400 km，设置的地表高度为 378,029 km；读数是把月球视作测试物体绕固定点质量地球的二体圆轨道估算，不冒充真实月球周期或轨道形状。滑块最大值覆盖该高度；地球同步预设取当前球形地球参数对应的近似高度。轨道图在屏幕半径上采用对数压缩以同时容纳低轨与地月距离，图例和旁注说明空间不按真实比例，计算读数不使用压缩后半径。

5. **采用单一活动主题绘制和语义标签。** 进入主题或窗口变化时只调整可见画布缓冲区并重绘，画布使用设备像素比；每个标签通过 `aria-controls` 连接 `tabpanel`，按 APG 常见手动激活模型提供方向键/Home/End 和焦点移动。发射和轨道动画使用单一 RAF 循环、时间戳与可取消帧 ID；由固定物理步进驱动轨迹，渲染频率只影响图像更新时间。背景星点固定生成以免每帧闪烁。

6. **测验以题目 ID 而不是点击次数维护首次正确数。** 每次显示的选项作答后禁用；题库循环到已答过的 ID 时仍可练习，但不会再次影响完成。前三个不同首次正确 ID 点亮现有 `PageProgress`，其存储契约不变。

**物理依据：** OpenStax《University Physics Volume 1》列出万有引力、圆轨道速度、逃逸速度和轨道周期方程（[第 13 章公式](https://openstax.org/books/university-physics-volume-1/pages/13-key-equations)）；其开普勒章节说明反平方力轨迹由圆锥曲线、能量与离心率决定（[13.5](https://openstax.org/books/university-physics-volume-1/pages/13-5-keplers-laws-of-planetary-motion)）。卫星轨道章节以 400 km 高度示例计算约 7.67 km/s 和 5.55×10³ s（[13.4](https://openstax.org/books/university-physics-volume-1/pages/13-4-satellite-orbits-and-energy)）。NASA 地球资料给出体积平均半径 6,371 km 与 GM≈398,600 km³/s²（[地球数据表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)）；NASA 月球资料给出平均地月距离 384,400 km（[地月数据](https://science.nasa.gov/moon/by-the-numbers/)）。实现按定义区分中心距与离地高度。

## Risks / Trade-offs

- **固定步长仍是数值近似，且近地高速度可能在一步内碰撞。** → 限制时间累加，固定小步进；地表交点插值；单测一个轨道周期的能量漂移和碰撞半径。
- **近地高度和球形地球是抽象模型。** → 在模拟旁明确标出起始高度、忽略因素和地球参数来源；宇宙速度卡仍标为地表近似值。
- **对数轨道图或点质量近似周期可能被误读为真实月球轨迹。** → 常驻“示意图，对数压缩距离”及模型范围说明；所有数值独立按真实半径和地球点质量计算，并注明不含月球质量与日月摄动。
- **移动滑块增大范围后难以精确选取 GEO 和月球值。** → 保留可访问滑块，同时提供有名称的精确预设按钮；自动化验证控件值与预设文字一致。

## Migration Plan

1. 先加入可复现的物理单测和浏览器行为基线，再实现模型与页面。
2. 更新页面证据、生成交互覆盖和风险索引，跑专项桌面/窄屏、静态、全量浏览器与全站冒烟。
3. OpenSpec 严格校验后提交并推送；通过 Pages 发布工件和发布后验收核对 revision，再归档变更。
4. 若线上异常，回退页面和模型文件的同一提交，重新部署并按发布验收检查旧版本。
