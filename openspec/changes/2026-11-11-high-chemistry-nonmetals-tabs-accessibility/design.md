## Context

页面目前用 `.tab` 点击处理器显示四个 `.stage`，用 `.mode-btn` 点击处理器切换氮、硫数据。键盘基线复现首个 Tab 停在“高中化学”返回链接，四个主题和两个系列选择均没有键盘语义。320px 下页面当前宽度为 320px，无溢出。切换系列只更新图和列表，说明卡固定写有氮系列内容。

## Goals / Non-Goals

**Goals:**
- 为四个主题建立单停靠点页签导航，保持焦点、选中状态和面板一致。
- 为氮/硫选择建立可访问单选组，并同步系列图、列表和说明摘要。
- 保持现有实验、元素探索、反应详情和测验行为；320px 下不引入溢出。

**Non-Goals:**
- 重写元素数据、反应方程、实验步骤或测验题库。
- 重构画布绘制、学习进度、全站导航或页面结构。
- 新增运行时依赖或引入持久化状态。

## Decisions

- 顶部主题入口使用原生按钮和 `tablist` / `tab` / `tabpanel` 语义，通过一个激活函数同时更新焦点停靠点、ARIA 状态、活动样式与显示面板。原生按钮保留 Enter、Space、鼠标和触屏；方向键及 Home/End 提供自动激活和循环导航。
- 氮/硫选择使用命名 `radiogroup`，内部为原生按钮并暴露 `radio` / `aria-checked`，使用 roving tabindex 与方向键选择；点击和触屏仍通过同一状态函数更新。
- 为两组系列增加对应摘要数据，并在切换时统一更新摘要标题、文字、图的可访问名称和转化列表。摘要以文本呈现，避免字符串插入 HTML；图、列表和摘要读取同一 `transformSeries` 状态。切换系列时清除旧反应选择并恢复中性详情提示。
- 保留现有布局和绘图尺寸，只调整按钮样式及必要的窄屏间距。专项测试在 320px 下逐一检查主题与系列切换，避免默认按钮样式造成新溢出。

## Risks / Trade-offs

- 原生按钮默认样式可能改变现有外观 → 显式继承字体、颜色和对齐，并检查选中态及焦点可见性。
- 三处系列信息可能再次漂移 → 用单一系列状态更新关系图、列表和摘要，并在测试中同时断言。
- 动态绘图异步刷新可能造成瞬时不一致 → 测试以可观测的选中状态、列表物质及摘要作为同步条件，不依赖画布像素时序。

## Migration Plan

无持久化或 URL 迁移。仅更新控件语义、状态同步和专项回归；回滚时一起还原标记、激活处理与摘要数据。
