## Context

见 [proposal.md](proposal.md)。该页在解析脚本末尾立即生成读表、填表和制表练习；读表的具体值和合计题使用重复随机拒绝抽样，无法保证固定随机源下终止。

## Goals / Non-Goals

**Goals:**

- 为两类数字读表题提供有限且确定的干扰项候选。
- 保留现有题目、数据、单位、随机排序、反馈和计分行为。
- 使用真实页面浏览器回归验证固定边界随机值、答案唯一和正确计分。

**Non-Goals:**

- 改动比较题、填表题或制表题的内容与评分。
- 修改表格数据范围或引入共享随机数库。

## Decisions

- 具体值题以答案为中心，从 `[-5,-4,-3,-2,-1,1,2,3,4,5]` 有序偏移中过滤正数，合计题用同样方法但偏移扩展到 `[-6,6]` 且排除 0。数据生成范围保证两类题均有至少三个正数干扰项。
- 先加入正确答案，再从有限候选中取前三个互异干扰项，最后沿用现有 `shuffle`。因此是否完成不依赖 `Math.random()` 变化，答题呈现仍可打乱。
- 浏览器回归在初始化前固定随机值为 0 和接近 1，分别覆盖查值和合计题；依据表格独立计算正确答案，检查选项唯一、单位、反馈和计分。

## Risks / Trade-offs

- 固定随机源会重复同一组偏移和题型；本变更解决终止与答案歧义，不处理题目多样性。
- 若未来数据允许答案小于 1，正数候选池仍须至少提供三个干扰项；测试应随数据范围更新。

## Migration Plan

无需数据迁移。发布后页面初始化和读表后续题目即时使用有限偏移选项；若回归失败，可回退此生成器和对应测试。
