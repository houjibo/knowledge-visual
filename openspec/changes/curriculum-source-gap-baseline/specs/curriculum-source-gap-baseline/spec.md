## ADDED Requirements

### Requirement: 全站课程覆盖差距有来源与分母

系统 MUST 为本站六个学科的四阶段矩阵记录主题数量、阶段适用性、课程来源、教材／大纲示例及映射状态。基础教育学习目标 MUST 以教育部课程标准为主线，现行审定人教版仅作为适用学科的章次示例；无适用教科书的格子 MUST 说明所用指南或课程框架。正式课程覆盖比例 MUST 由逐条来源要求与验证证据计算；适用范围尚未拆解或存在未映射要求时 MUST 显示全局比例不可计算，且显式标出剩余范围，不得以页面数量冒充覆盖比例。

#### Scenario: 读取当前覆盖计划
- **WHEN** 维护者查看课程差距矩阵
- **THEN** 能看到每个学科/阶段的页面数、权威来源、已知候选缺口、映射状态和下一批任务

#### Scenario: 课程来源或教材版本变化
- **WHEN** 标准、指南或选定教材目录更新
- **THEN** 原版本、适用范围和映射口径仍可追溯，相关差距需要重新核查后再更新覆盖结论
