## 2. 逐项映射

- [ ] 2.1 用高中数学和初中计算机试点：先对照各自 2025 修订版与旧版，再拆解现行内容要求、学业质量与选定教材目录，给每项稳定 ID、原文位置、必修性、本站转述目标和证据字段；复核粒度。
- [x] 2.1a 初中信息科技 CE22 第四学段互联网、物联网和 AI 三模块的 19 条“内容要求”建立首轮稳定 ID、来源位置、站内证据与缺口；用脚本核对数量、状态和路径。这是历史版三个模块的首轮映射，不代表 CE25 或学段整体完成。
- [ ] 2.1b 先比对初中信息科技 CE22→CE25 的模块和 19 条历史要求，再按 CE25 重建内容要求、跨学科主题、学业要求与学业质量；复核初中教材例外及粒度。
- [ ] 2.1c 高中数学先取得并复核 HS25 原文，对照 HS20 条款变化，再按必修内容、学业质量与人教版 A 版现行逐册章目建立同格式试点。
- [ ] 2.2 小学数学、初中数学：先比对 CE22→CE25，再完成 CE25 分学段要求与本站主题的逐项映射。
- [x] 2.2a 以 CE22 第四学段“有理数”5 条内容要求试点，记录稳定 ID、课标位置、站内证据和缺口；该快照待按 CE25 复核，学业要求及其余初中数学范围仍待核。
- [ ] 2.3 初中物理、高中物理：完成 CE25/HS25 的必修和选修边界、实验探究要求映射；分别对照 CE22/HS20 变化。
- [ ] 2.4 初中化学、高中化学：完成 CE25/HS25 的物质、反应、实验和应用要求映射；分别对照 CE22/HS20 变化。
- [ ] 2.5 小学科学：按 CE25 完成物质、生命、地球宇宙、技术工程及探究要求映射；明确初中科学是否纳入本站。
- [ ] 2.6 小学计算机、高中计算机：完成 CE25 信息科技和 HS25 高中信息科技要求映射；先取得高中标准原文、核新旧模块边界，再与试点的初中计算机合并核对。
- [ ] 2.7 小学、初中、高中人工智能：完成 AI25 与 CE25/HS25 信息科技标准的分层映射，避免把 AI 导航类目等同独立国家必修课程。
- [ ] 2.8 大学数学、物理、化学：补齐基础和拓展公开课程大纲，再映射本站主题；不把单一学校课程当全国共同要求。
- [ ] 2.9 大学计算机、人工智能：按 CS2023 的知识领域和基础/拓展层次映射，同一来源要求在两个导航类目共享时避免重复计数。
- [ ] 2.10 逐格记录已验证、部分、缺失、未映射和不适用，关联页面、测试与内容核查；生成或校验分母、状态总数及版本差异。未拆解范围或已拆解但未映射要求存在时，不发布全局覆盖率。
