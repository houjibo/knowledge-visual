## 2. 逐项映射

- [ ] 2.1 用高中数学和初中计算机试点：拆解标准内容要求、学业质量与选定教材目录，给每项稳定 ID、原文位置、必修性、本站转述目标和证据字段；复核粒度。
- [ ] 2.2 小学数学、初中数学：完成 CE22 分学段要求与本站主题的逐项映射。
- [ ] 2.3 初中物理、高中物理：完成 CE22/HS20 的必修和选修边界、实验探究要求映射。
- [ ] 2.4 初中化学、高中化学：完成 CE22/HS20 的物质、反应、实验和应用要求映射。
- [ ] 2.5 小学科学：完成物质、生命、地球宇宙、技术工程及探究要求映射；明确初中科学是否纳入本站。
- [ ] 2.6 小学计算机、高中计算机：完成 CE22 信息科技和 HS20 信息技术要求映射；与试点的初中计算机合并核对。
- [ ] 2.7 小学、初中、高中人工智能：完成 AI25 与信息科技/信息技术标准的分层映射，避免把 AI 导航类目等同独立国家必修课程。
- [ ] 2.8 大学数学、物理、化学：补齐基础和拓展公开课程大纲，再映射本站主题；不把单一学校课程当全国共同要求。
- [ ] 2.9 大学计算机、人工智能：按 CS2023 的知识领域和基础/拓展层次映射，同一来源要求在两个导航类目共享时避免重复计数。
- [ ] 2.10 逐格记录已验证、部分、缺失、未映射和不适用，关联页面、测试与内容核查；生成或校验分母、状态总数及版本差异。未拆解范围或已拆解但未映射要求存在时，不发布全局覆盖率。
