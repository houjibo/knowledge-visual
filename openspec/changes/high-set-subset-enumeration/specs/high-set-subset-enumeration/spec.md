## ADDED Requirements

### Requirement: 列举给定集合的全部子集

页面 MUST 让学习者在非数字有限全集中构造 A，先预测 A 的子集个数，再从全集候选子集中选出且仅选出 A 的全部子集；空集与 A 自身均须计入。

#### Scenario: 双元素集合漏掉空集
- **WHEN** A 含苹果和梨、预测 4 个但未选择空集
- **THEN** 页面说明漏掉空集，并保持结果未通过

#### Scenario: 空集和三元素边界
- **WHEN** A 分别为空集及三元素全集
- **THEN** 正确答案分别为仅含空集以及全部八个候选，且 A 改动清除上一轮的选择与反馈

### Requirement: 给出可解释的差异反馈

页面 MUST 区分计数错误、漏选和误选；对误选说明该候选含有不属于 A 的元素，且不以脚本错误或仅颜色传达结果。

#### Scenario: 键盘和窄屏操作
- **WHEN** 学习者在 320px 宽屏通过键盘完成练习
- **THEN** 所有按钮和选择框均可操作，反馈可读，页面无横向溢出
