## Context

页面启动时的比较练习只调用有限范围内的算式生成；限时挑战点击“开始挑战”后才进入选项生成。挑战当前从正确答案附近反复抽取随机数，遇到重复值会永久占用主线程。题目答案范围为 0–99，原干扰项半径为 10。

## Goals / Non-Goals

**Goals:**

- 用有限候选池生成符合规格的挑战选项，并保留现有正确答案和干扰项范围。
- 用固定随机值覆盖开始、作答和下一题路径。

**Non-Goals:**

- 不修改其余三个学习模式、挑战计时/记录界面或公共随机数服务。
- 不调整加减题目范围或“限时挑战”学习规则。

## Decisions

- 用正确答案加有限整数偏移构造候选池，排除负数及正确答案后，去重并有限取足三个干扰项；最后打乱四个选项。替代方案是保留随机重抽并增加重试上限，但固定随机值下仍需提供可靠回退，直接有限候选池更简单且有明确终止条件。
- 利用答案范围证明候选池足够：正确答案为 0 时 +1 至 +10 可提供十个干扰项；答案为 1–99 时 0 至 109 范围内也至少有十个符合 ±10 的候选值。
- 显式检查候选数量，若未来题目范围变化致候选不足则快速报错，不以无界重试隐藏配置不变量；边界固定随机回归验证答案为 0 及近边界题目仍可完成。

## Risks / Trade-offs

- 固定偏移池使干扰项关系更有规律 → 每题打乱选项，并测试多个固定随机边界及答案边缘。
- 修改题目范围后候选池可能不足 → 保留数量断言并让边界回归覆盖最小、最大答案。

## Migration Plan

先添加固定随机浏览器回归并确认启动失败，再替换挑战选项生成并运行桌面/移动及全项目检查。合并前核对 Actions、Pages 清单和本地/公网挑战；若失败，回滚页面、测试和对应 OpenSpec/证据变更。
