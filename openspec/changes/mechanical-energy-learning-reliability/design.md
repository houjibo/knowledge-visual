## Context

当前页面初始化时调用全部三个 `resize*` 函数。隐藏 section 的 `offsetWidth` 为零，随后 `switchTab` 只切换 class，不再设置画布尺寸。使用本地 Chrome 复现后，初始 `keCanvas` 和 `conservCanvas` 内部宽度均为 0；切到对应主题后 CSS 宽度变为 726 px，但内部宽度仍为 0。守恒演示初始能量为 60.0 J，约 1.6 秒后变为 52.9 J。相关页面尚未登记专项交互测试。

## Goals / Non-Goals

**Goals:**

- 保证可见主题的画布具有当前设备像素比对应的缓冲尺寸并实际绘制；保留其他主题的参数。
- 用明确的时间变量计算平均功率，并消除零功判断中的浮点边界错误。
- 让动能动画按真实帧间时间推进，使用恒力运动学更新位置和速度，并对每一帧累计 `F·Δx`。
- 将自由落体说明、动画边界和能量反馈限定在同一个无耗散模型内；提供非鼠标输入可用的高度与释放控件。
- 让主题切换可键盘操作，并让每道测验题只接受一次作答。

**Non-Goals:**

- 不重构其他页面或建设全站通用 canvas 组件。
- 不模拟落地碰撞、反弹、空气阻力或真实设备物理实验。
- 不在本次变更中完成全站键盘、屏幕阅读器或真实设备审计。

## Decisions

1. **只初始化和重绘活动主题。** 用 section 到画布 resize/draw 入口的映射处理首次显示、切换和窗口尺寸变化。重设画布缓冲区后调用 `setTransform`，避免反复缩放上下文；切回主题时按保留的状态重新绘制。
2. **使用原生按钮实现主题入口。** 为按钮同步选中状态和 roving tabindex，并支持方向键、Home、End；面板用 `aria-controls` / `aria-labelledby` 建立关系。点击或键盘切换后再测量并绘制活动画布。
3. **将功率时间作为输入。** 增加 1–10 s 的时间滑块。显示的功率是恒力在给定位移和时间内的平均功率；工作分类依赖四舍五入到 0.1 J 的显示值，保证 90° 时分类与读数一致。
4. **让动能动画按恒力解析运动学更新。** 以 RAF 时间戳计算受限帧间隔，使用 `x += v·dt + ½a·dt²`、`v += a·dt`，累计每帧 `F·Δx`。运动时禁用质量、初速度与合力滑块；停止后修改任一条件都会回到新初始状态，避免展示混合条件下的错误合力功。
5. **以释放高度定义守恒状态。** 键盘可操作的高度滑块和释放按钮与画布拖动同步。动画忽略空气阻力，只模拟下落并在接触地面时停止，不发生耗散碰撞；速度大小由 `v² = 2g(h₀-h)` 得出，使 `½mv² + mgh = mgh₀` 在绘制和读数中保持一致。能量柱尺按当前初始总能量缩放。
6. **用每题作答状态保证完成计数。** 选择答案后禁用本题所有按钮并记录已作答状态，至少答对三道不同题才点亮知识地图。将第三题的干扰项写成明确有摩擦耗散的情形，避免圆周运动这一未限定条件产生多解。

## Verification

- 专项浏览器测试覆盖桌面和 320 px 窄屏：每个画布首次进入、往返切换和缩放后有非零缓冲及绘制像素；主题方向键可切换。
- 固定参数验证 `W`、`P`、正负/零功边界、动能定理 `ΔEk = W合`、守恒自由落体在多个采样点的 `Ek + Ep`，并验证落地停止时能量仍守恒。
- 验证相同题目的重复激活不会提前完成、三道不同题完成且刷新恢复；检查无页面脚本错误。
- 运行本专项桌面/移动回归、静态检查、全站浏览器冒烟和严格 OpenSpec 校验；推送后核对 Actions 与 Pages 发布清单。
