## Context

见 [proposal.md](proposal.md) 的问题说明。此页用单个内联脚本初始化四种学习模式；分类模式在加载阶段立即生成题目，即使内容处于隐藏状态也会执行。图形数据保存在 `SHAPES` 和 `shapeKeys` 中，选项现由该集合重复随机抽取。

## Goals / Non-Goals

**Goals:**

- 让选项生成次数由有限图形集合决定，不受随机值分布影响。
- 保留现有六种图形、题意和答错后重试行为。
- 让选项拥有稳定语义，并让一题的正确作答进入单一锁定状态。
- 让 320px 视口中的四个图形仍清楚可见且无需横向滚动。

**Non-Goals:**

- 不重写位置、拼图或认识图形模式，也不改变学习进度格式。
- 不要求固定随机源生成多样题目；固定值仅用于验证可终止和结果完整。

## Decisions

1. **从有限集合构建干扰项。** 保留目标图形，从其余图形中过滤出候选、打乱并取三个，再打乱完整选项。相较于限制重抽次数后回退，此方式不需要残余选项补救逻辑，并保证四个不同图形。
2. **使用原生按钮呈现图形。** 每个按钮使用图形名称作可访问名称，选项组关联题目提示，SVG 仅作为视觉内容；原生按钮自带 Enter/Space 行为。显式沿用现有外观并添加焦点可见样式，避免标签替换造成默认按钮外观漂移。
3. **正确作答后锁定本题。** 在第一次正确判定时同步置位答题状态并禁用该题所有选项；错误选择仍可继续尝试。用状态门和禁用语义共同阻止重复计分。
4. **窄屏改用两列。** 桌面维持四列，480px 及以下使用两列，避免 56px SVG 在窄列中溢出按钮并保持可触达尺寸。

## Risks / Trade-offs

- [原生按钮默认样式影响布局] → 明确设置边框、背景、字号、内边距和焦点样式，并在桌面及 320px 窄屏回归。
- [固定随机测试可能掩盖题目重复] → 测试只断言终止、四项唯一、答案存在和交互一致；题目多样性不在本变更范围。

## Migration Plan

不涉及持久化数据或接口迁移。部署静态页面即可；若窄屏或判题回归失败，回退该页面实现和本次浏览器用例。
