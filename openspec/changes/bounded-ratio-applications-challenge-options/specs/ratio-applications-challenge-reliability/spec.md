## Purpose

确保比的应用挑战能在随机输入重复时稳定生成与比例关系一致的选项，并使每题只接受一次作答，以支持连续、可信的交互练习。

## ADDED Requirements

### Requirement: 挑战题有限生成有效选项
比的应用挑战 SHALL 有限生成四个互异的正整数选项，且恰有一个正确答案；干扰项 MUST 与正确答案相差不超过 10。

#### Scenario: 固定随机值下初始化挑战
- **WHEN** 学习者以重复固定随机值 0、0.5 或 0.999999 打开挑战页面
- **THEN** 页面完成加载并显示四个互异的正整数选项，其中恰有一个等于按比分配计算出的答案

#### Scenario: 正确作答后继续挑战
- **WHEN** 学习者选择与题目比例计算一致的选项
- **THEN** 页面显示正确反馈、正确计数增加一次，并在反馈后生成有效的下一题

### Requirement: 每道挑战题仅接受一次作答
比的应用挑战 SHALL 在首次选择后锁定当前题的全部选项，并且 MUST 只更新一次对错计数和下一题任务。

#### Scenario: 尝试重复回答当前题
- **WHEN** 学习者首次选择答案后再次操作当前题的其他选项
- **THEN** 选项保持锁定，反馈和对错计数不再改变，且只生成一题后续题目

#### Scenario: 错误回答后锁定当前题
- **WHEN** 学习者首次选择错误选项
- **THEN** 错误计数只增加一次，显示正确选项，并锁定当前题直至进入下一题
