## Context

课程设计把初中网络路径列为候选。当前计算机目录只覆盖算法、二进制表示和数据结构；没有可观察的网络路径主题。新页应沿用静态文件、相对资源与 SubjectProgress，本机进度仅在明确完成后保存。

## Decisions

- 固定无向教学图：S—A 代价3，A—D 代价5，S—B 代价1，B—C 代价1，C—D 代价2，A—C 代价2。S 为起点，D 为终点，A/B/C 为中间节点；代价是人为指定的无量纲数，不表示实测延迟、带宽或费用。
- “最小总代价”先比较连线代价之和，再比较跳数；“最少跳数”先比较跳数，再比较总代价；仍相同时按节点字母序确定唯一演示路径。所有可用连线均视作双向。纯模型使用正权最短路径搜索；测试另以枚举简单路径作独立判据。
- 正常条件下，最小代价选 S→B→C→D，总代价4、3跳；最少跳数选 S→A→D，总代价8、2跳。断开 B—C 后，最小代价改走 S→A→C→D，总代价7、3跳；断开 B—C 与 A—C 后走 S→A→D。断开 A—D 与 C—D 后 D 不可达。四种情况用于区分“少经过节点”“总代价低”和“连通”。
- 先选条件与规则，再预测第一跳 A、B 或不可达；揭晓前不突出路径与数值。揭晓后 SVG、路径文本、总代价/跳数与当前位置由同一模型输出；按钮每次推进一条连线。修改条件或规则重置当前尝试，保留本次会话已完成的其他对照。
- 完成资格要求正常/最小代价、正常/最少跳数、B—C 断开/最小代价三种正确预测且逐跳到达，以及两条出口断开/最小代价正确预测并确认不可达。保存失败保留资格和重试入口；已存历史不充当本次正确预测。
- 页面脚本挂接前禁用主要操作；使用原生下拉框、按钮、常显文字与可见焦点，320px 不横向溢出。SVG 是额外视觉证据，核心状态可由文字读取。不提供自动播放，避免动态效果或页面隐藏时计时状态。

## Knowledge basis and boundary

- [RFC 1812 第5.2.1节](https://www.rfc-editor.org/rfc/rfc1812.html)描述路由器按目标确定下一跳；[RFC 2328 第16.1节](https://www.rfc-editor.org/rfc/rfc2328.html)描述在特定链路状态协议中累加连线代价求路径；[MIT OCW 6.033 网络课程](https://ocw.mit.edu/courses/6-033-computer-system-engineering-spring-2018/pages/week-5/lecture-9-outline/)提供链路状态与最短路径的教学背景。
- 页面只展示预先知道全图时的两种教学选路规则。真实网络中的路由表生成、链路状态传播、负载、拥塞、丢包、重传、多条等价路径及协议选择均不在模型内。尤其不能把本页指定代价解释为现实延迟，也不能声称全部互联网流量遵循本页规则。

## Risks / tradeoffs

- 五节点图便于逐步核验，却不能代表真实网络规模。断线立即重算是教学假设，不表示真实网络收敛时间。
- 最少跳数策略用于与指定代价作比较，不把它称为 IP 或 OSPF 的通用路由算法。并列路径用稳定字母序只为了演示一致；实际协议的等价路径处理不同。
