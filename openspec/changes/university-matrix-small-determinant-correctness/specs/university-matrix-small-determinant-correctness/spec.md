## ADDED Requirements

### Requirement: 固定格点矩阵的秩与逆保持一致
逆矩阵与秩实验 MUST 对四个 0.05 步长滑块对应的 2×2 矩阵准确判断可逆性、秩及零空间，并使用足够精度显示行列式。

#### Scenario: 小但非零的行列式
- **WHEN** 输入矩阵 diag(0.05,0.05)
- **THEN** 行列式显示 0.0025，显示秩 2、可逆、零空间为零向量并给出正确逆矩阵

#### Scenario: 真实奇异情况
- **WHEN** 输入零矩阵或非零行列式为零的矩阵
- **THEN** 分别显示秩 0 或 1、不可逆及对应零空间，不展示逆矩阵

### Requirement: 通过键盘连续调节
滑块重新绘制 MUST 在原滑块已有焦点时保留焦点，允许连续方向键操作。

#### Scenario: 键盘调整矩阵
- **WHEN** 聚焦滑块并连续按方向键
- **THEN** 每次变化都作用于同一滑块且显示的行列式和秩随之更新
