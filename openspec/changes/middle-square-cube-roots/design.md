## 学习路径

探索区选择边长 `1..10` 及平方／立方。平方用 `n×n` 格展示面积；立方用 `n` 层、每层 `n×n` 的逐层计数图展示体积。另给负数立方的代数式，注明形体体积始终非负。图下文字与控件同步，不只依赖颜色。

逆向区提供平方正数、平方零、立方正数、立方零、立方负数、平方负数六类可选案例，数值范围落在课标规定范围内。先写算术平方根／立方根或选“实数内无解”；正确后再选逆运算理由；两步都正确才启用本地计算器验算。具体答案与图中边长在预测前不揭示。完成一类后可换例继续，进度须六类独立完成才写入。

模型在 Node 与浏览器共用，按整数输入建立平方／立方案例并拒绝越界、非整数及错误记号；对完全幂用整数根核对，不依赖浮点结果判分。计算器显示 JavaScript `sqrt/cbrt` 输出及回代关系，但展示仅作验算，不当作学习掌握证明。

## 边界与验收

正数 `a` 的平方根是 `±√a`，`√a` 为非负算术平方根；`a=0` 只有 0；负数在实数范围无平方根。立方根对负数仍唯一，例如 `∛(-64)=-4`，与真实立方体体积区别。页面应支持 320px、键盘、`file://` 和 Pages 子路径；进度失败保留待写状态。验证模型全范围、错误反馈、六类完成、目录徽章、发布版本。
