## ADDED Requirements

### Requirement: 非金属练习题设具有唯一可解释答案

第五题 MUST 明确要求物质既与足量稀盐酸反应放出 CO₂，又与 NaOH 溶液反应生成 Na₂CO₃，使现有四个选项中仅 NaHCO₃ 符合题设。反馈 MUST 给出两条配平反应，说明 Al(OH)₃ 也能与强酸、强碱反应，但不满足本题指定产物条件，并提供可核验的知识依据。

#### Scenario: 根据指定产物区分两类酸碱反应
- **WHEN** 学习者查看并作答第五题
- **THEN** NaHCO₃ 为唯一正确选项，反馈解释指定产物条件与两条反应，且不再宣称 Al(OH)₃ 不能与酸或碱反应

### Requirement: 首次作答与成绩在本轮中保持一致

五题选项 MUST 使用有名称、可见焦点的原生按钮，支持 Enter、Space、鼠标和触屏。本轮每题 MUST 只记录首次选择，明确显示选择、正确答案和文字反馈；返回题目或切换主题 MUST 保留选择及反馈。得分 MUST 由逐题结果计算且不超过 5。未答当前题 MUST 不能进入下一题或结束。页面 MUST 显示题号、已答题数和本轮得分，并在 320 CSS 像素下无页面级横向溢出。

#### Scenario: 返回已答题不会重复加分
- **WHEN** 学习者答对第一题，进入第二题后返回，或离开并重新进入互动练习
- **THEN** 第一题首次答案与解释仍然显示，选项锁定，再次激活不会增加分数

#### Scenario: 错误答案也保持本轮状态
- **WHEN** 学习者答错后回看该题
- **THEN** 页面仍显示首次错误选择、正确答案与说明，本轮不能覆盖为另一答案

#### Scenario: 顺序完成与键盘作答
- **WHEN** 学习者使用键盘作答并前进
- **THEN** 未答题时下一步不可用，作答后可以前进，题号与反馈同步，焦点有可理解的去向

### Requirement: 完成记录以完整回合结果为依据

页面 MUST 在五题均已作答且学习者主动结束后报告本轮成绩。至少答对三题 MUST 才尝试保存非金属主题完成记录；低于三题 MUST 显示未达标并提供重做。重新练习 MUST 清空本轮五题选择、成绩和结果，且 MUST 保留之前保存的主题完成记录。结束后 MUST 可以回看本轮答案且不改变成绩。

#### Scenario: 两题正确不会记录完成
- **WHEN** 学习者完整答完五题但仅答对两题并结束
- **THEN** 显示 2/5 和未达标，未新增完成记录；学习者可以重新练习

#### Scenario: 三题及以上正确后主动完成
- **WHEN** 学习者本轮答对至少三题并主动结束
- **THEN** 报告真实的本轮成绩并尝试保存完成记录，反复结束或回看不会追加得分

### Requirement: 存储失败具有诚实反馈与重试途径

保存成功 MUST 显示已保存；写入被拒绝或已有存储损坏时 MUST 保留本轮结果、显示进度未保存并提供重试。损坏原文 MUST 不被覆盖。存储恢复后重试 MUST 可保存同一达标结果，不要求重新作答，也不能把仅存于内存的状态误报为已保存。

#### Scenario: 达标但写入失败
- **WHEN** 五题完成并达标但本机存储拒绝写入
- **THEN** 学习结果可继续回看，页面明确未保存并提供重试，不显示持久化完成成功

#### Scenario: 恢复后重试保存
- **WHEN** 存储恢复后学习者重试保存
- **THEN** 同一结果保存成功并显示已保存，成绩和答案不改变
