## Context

参见 proposal.md 的 Why。练习和挑战共同调用同一题目生成函数；题目答案可能为零，选项需保持正整数干扰项。

## Goals / Non-Goals

**Goals:**
- 让四个互异选项由固定有限候选生成，确保所有合法答案均可补齐。
- 保持练习、挑战现有题意、判分和计分节奏。

**Non-Goals:**
- 不改变集合人数、交集、并集的题目模型或视觉呈现。
- 不引入新的随机库或运行时依赖。

## Decisions

- 使用相对答案的有限偏移序列 `[1, -1, 2, -2, 3, -3, 4, -4]`，过滤非正数及正确答案，直到得到四个互异选项。最小正确答案为零时，正向候选足以提供三个干扰项；答案为正数时，正负偏移共同提供足够候选。
- 不再为干扰项持续调用随机数重抽。固定候选使输入随机源重复时仍可终止，也避免正确答案为零时负候选全部被过滤导致卡死。
- 回归通过练习与挑战的可见选项和反馈检查生成结果，采用固定随机值与零交集序列覆盖复现边界。

## Risks / Trade-offs

- 固定偏移会使选项分布更可预测 → 本次优先保证题目可靠与唯一判分；固定偏移候选含多个近邻值，不改变题目答案或说明。
- 未来若题目答案范围扩大，偏移候选仍保证最小非负答案有足够正向数值；回归会继续验证恰有四项。

## Migration Plan

部署由 GitHub Actions 构建并验证静态发布产物；若发布验证失败，修复后再次推送通过完整检查的提交。
