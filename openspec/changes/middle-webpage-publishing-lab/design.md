## Context

初中计算机页面是静态 HTML/CSS/JavaScript，以 `SubjectProgress` 保存主题完成；`file://` 与 Pages 子路径是既有使用方式。CE25 对应条目涉及真实网页编辑和发布，但本站不要求未成年人注册公开账号，也没有发布用户内容的后端。

## Goals / Non-Goals

**Goals:** 让学习者通过“结构化数据 → 草稿预览 → 已发布快照”看见网页信息的组成和发布时序；用两次实作与两题判断留下局部理解证据。

**Non-Goals:** 真实托管或公开传播、HTML/CSS 自由代码编辑、多人协作、真实网络数据协议、自动识别任意文本中的个人信息。

## Decisions

1. 使用标题、正文、图像说明与限定内部链接四个字段。图形为站内固定 SVG，输入只以 `textContent` / `aria-label` 进入预览；链接目标由白名单选项选出。这样能看到数据与呈现的关系，也避免把用户文本解释为代码或产生任意外链。
2. 纯模型负责修整、校验、快照与内容差异；控制器只渲染和记录操作。发布快照存于本次页面会话内，不写入 localStorage；进度只写主题布尔值。默认示例可预览，完成资格要求学习者确实修改并发布两个不同版本。
3. 两题在预览与版本操作之后仍可重做；错误反馈说明原因，不直接把答案写到选项之外。完成资格保留于内存，存储拒绝时显示重试按钮。

## Risks / Trade-offs

- [模拟发布可能被误解为真正上线] → 页首、发布按钮、状态和边界说明都标明“本页模拟”；已发布视图只在当前页面会话存在。
- [有限数据字段不能覆盖互联网应用全部数据构成] → 课程映射仅从缺失改为部分，真实网络应用、资源协作与公开发布继续列为差距。
- [预设图形和链接限制创作自由] → 保留文字编辑与两个版本的真实状态差异；自由 HTML、媒体上传和托管放在后续任务。
