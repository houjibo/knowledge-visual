# chemistry-reaction-rate-concept-access Specification

## Purpose
规定高中化学“反应速率与平衡”页的可核查概念边界和基本键盘交互：区分按化学计量换算的浓度变化速率与粒子示意模型指标，准确表述催化剂和温度影响，并让学习者通过键盘切换主题、完成测验及获得如实的进度保存反馈。此规格不证明平衡数值模型的定量准确性。

## Requirements

### Requirement: 区分反应速率定义与示意指标

页面 MUST 对浓度变化速率声明化学计量和恒容前提，并将粒子动画给出的数值标为无量纲模型指标，展示其计算规则，避免当作实验测得的 mol/(L·s)。

#### Scenario: 比较温度和浓度档位
- **WHEN** 学习者调整模型档位
- **THEN** 指标随档位及剩余粒子数更新，页面说明档位和指标都不是实测温度、浓度或反应速率

### Requirement: 准确表述催化和温度影响

页面 MUST 说明催化剂可参与反应步骤、在催化循环中再生，通常不改变平衡位置；温度对速率的具体倍数不能写成普遍定律。单位题 MUST 指明采用 mol/L 和秒的条件。

#### Scenario: 阅读影响因素和作答
- **WHEN** 学习者查看影响因素或单位题
- **THEN** 页面给出适用条件，不将经验倍数或常用单位误称为通用规律或 SI 单位

### Requirement: 键盘与完成反馈

五个主题入口和测验选项 MUST 可通过键盘激活且有可见焦点；主题选中状态可识别；作答后选项锁定；合格且写入成功才显示“已记录完成”，写入失败明确显示未保存并可通过重测重试。

#### Scenario: 键盘作答与保存失败
- **WHEN** 学习者用键盘完成至少三道题且浏览器存储写入失败
- **THEN** 页面仍给出得分与未保存提示，不错误宣称完成已记录
