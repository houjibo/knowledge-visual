# homepage-interactive-start Specification

## Purpose
本规格规范首页提供可动手的学习起点，核心边界为：首页必须提供跨学科的可视化主题入口，说明学段及进入后的具体操作，并支持键盘、窄屏与本地文件访问。

## Requirements

### Requirement: 首页提供可动手的学习起点
首页 SHALL 提供跨学科的可视化主题入口，说明学段及进入后的具体操作，并支持键盘、窄屏与本地文件访问。

#### Scenario: 选择一个主题体验
- **WHEN** 学习者从动手入口选择主题
- **THEN** 进入对应主题并可执行卡片描述的操作

#### Scenario: 直接打开或禁用脚本
- **WHEN** 学习者直接打开本地首页或浏览器禁用脚本
- **THEN** 这些主题入口仍可见且链接可用
