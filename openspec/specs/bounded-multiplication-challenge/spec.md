# bounded-multiplication-challenge Specification

## Purpose
定义多位数乘法限时挑战生成单选题的可靠行为，使每档题目都能及时提供完整、互异且只有一个正确答案的选项。

## Requirements

### Requirement: 限时挑战在有限步骤内生成唯一正确选项

多位数乘法限时挑战 MUST 在有限步骤内为当前题目展示恰好四个互不相同的选项，其中 MUST 恰有一个选项等于正确乘积。选项生成 MUST 在随机源重复返回同一数值时仍然结束。每道题 MUST 只处理首次作答或计时结束；首次作答或超时后 MUST 立即锁定全部选项，并且只安排一次下一题。

#### Scenario: 三档难度展示完整且互异的答案选项
- **WHEN** 学习者开始简单、中等或困难挑战
- **THEN** 页面展示当前乘法题和四个互不相同的选项，且只有一个选项等于该题乘积

#### Scenario: 随机值重复时挑战仍能启动
- **WHEN** 随机源在生成简单、中等或困难挑战题时持续返回同一数值
- **THEN** 页面在有限步骤内展示四个有效选项，且不会因补充干扰项而阻塞交互

#### Scenario: 选择正确选项后只计一次并继续挑战
- **WHEN** 学习者选择当前题目唯一正确的选项
- **THEN** 页面立即锁定全部选项，只增加一次正确计数，并在反馈后展示一组可作答的新题选项

#### Scenario: 选择正确选项后可继续挑战
- **WHEN** 学习者选择当前题目唯一正确的选项
- **THEN** 页面按既有规则增加一次正确计数，并继续生成下一题

#### Scenario: 首次答错后锁定当前题
- **WHEN** 学习者选择错误选项后再次触发本题的答案
- **THEN** 页面保留首次错误反馈，错误计数只增加一次，且不重复安排下一题

#### Scenario: 计时结束后拒绝当前题作答
- **WHEN** 当前题计时结束而学习者尚未作答
- **THEN** 页面锁定所有选项并显示超时反馈；后续输入不计分，且只在既有反馈间隔后展示下一题

### Requirement: 挑战题目和选项支持键盘及辅助技术

挑战题 MUST 将实时更新的题目名称与答案组关联，并通过状态区域播报作答及超时反馈。答案 MUST 以可见焦点的按钮提供，支持键盘激活。键盘答题后进入下一题时 MUST 将焦点移到新题的第一个答案。

#### Scenario: 键盘选择并获得可读反馈
- **WHEN** 学习者用键盘聚焦答案并按 Enter 或 Space
- **THEN** 答案组以当前题目作为可访问名称，按钮提交一次答案，反馈由状态区域呈现并锁定本题

#### Scenario: 键盘连续作答
- **WHEN** 学习者通过键盘答题并等待反馈结束
- **THEN** 页面显示新题，焦点位于新题的第一个答案按钮，且该组按钮可继续作答
