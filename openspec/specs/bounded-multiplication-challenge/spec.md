# bounded-multiplication-challenge Specification

## Purpose
定义多位数乘法限时挑战生成单选题的可靠行为，使每档题目都能及时提供完整、互异且只有一个正确答案的选项。

## Requirements

### Requirement: 限时挑战在有限步骤内生成唯一正确选项

多位数乘法限时挑战 MUST 在有限步骤内为当前题目展示恰好四个互不相同的选项，其中 MUST 恰有一个选项等于正确乘积。选项生成 MUST 在随机源重复返回同一数值时仍然结束。

#### Scenario: 三档难度展示完整且互异的答案选项
- **WHEN** 学习者开始简单、中等或困难挑战
- **THEN** 页面展示当前乘法题和四个互不相同的选项，且只有一个选项等于该题乘积

#### Scenario: 随机值重复时挑战仍能启动
- **WHEN** 随机源在生成简单、中等或困难挑战题时持续返回同一数值
- **THEN** 页面在有限步骤内展示四个有效选项，且不会因补充干扰项而阻塞交互

#### Scenario: 选择正确选项后可继续挑战
- **WHEN** 学习者选择当前题目唯一正确的选项
- **THEN** 页面按既有规则增加一次正确计数，并继续生成下一题
