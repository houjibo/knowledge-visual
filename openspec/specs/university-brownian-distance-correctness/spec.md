# university-brownian-distance-correctness Specification

## Purpose
规范大学随机过程页面二维布朗运动离散模拟的径向距离、尺度相关理论期望和参数重置，清楚说明有限样本与连续模型的边界。

## Requirements

### Requirement: 二维径向距离与尺度一致
页面 MUST 对独立二维高斯增量模拟显示正确的固定尺度径向期望，并区分一维标准布朗运动与有限步模拟。

#### Scenario: 运行二维样本
- **WHEN** 以固定尺度 σ 运行到时间 t
- **THEN** 显示粒子当前径向距离的样本均值及最大值，理论期望为 σ√(πt/2)，并说明有限样本波动与离散近似

### Requirement: 修改参数后不得混合不同样本
页面 MUST 在更改尺度或粒子数时停止并重置模拟并告知学习者。

#### Scenario: 在运行中修改尺度
- **WHEN** 已运行后修改 σ
- **THEN** 粒子回到起点、时间及统计归零、模拟暂停，下一次开始使用新的尺度

### Requirement: 合法零随机值不使模拟卡死
页面 MUST 对随机数生成器返回零的情况正常产生有限值，不得无限重试。

#### Scenario: 随机值为零
- **WHEN** 随机源持续返回 0 且学习者启动模拟
- **THEN** 单步可结束且页面继续响应
