# university-markov-stationary-correctness Specification

## Purpose
规范大学随机过程页面固定马尔可夫链的平稳概率、单条轨迹频率及其距离的数学一致性，并区分不变分布与有条件收敛。

## Requirements

### Requirement: 平稳分布和单轨迹频率准确
页面 MUST 使用与显示的转移矩阵相符的平稳概率向量计算频率距离，并区分单轨迹时间频率和边际分布。

#### Scenario: 校验固定矩阵与距离
- **WHEN** 学习者查看矩阵或对固定随机轨迹单步
- **THEN** 给出的 π 满足 πP=π，距离是含初始状态的样本频率与 π 的欧氏距离，且说明有限轨迹可能波动

### Requirement: 不变分布不等同于无条件收敛
页面 MUST 说明该固定有限链满足收敛的充分条件并提供有平稳分布却不收敛的周期链反例；练习解释 MUST 不宣称所有链收敛。

#### Scenario: 阅读反例与练习解释
- **WHEN** 学习者查看马尔可夫链说明和对应练习反馈
- **THEN** 看到两状态交替链的平稳分布与从单一状态出发的振荡，并能辨别与本例收敛条件的区别
