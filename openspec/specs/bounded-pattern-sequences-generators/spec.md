# bounded-pattern-sequences-generators Specification

## Purpose
保证规律与序列页面的各类题目在随机值重复时仍可及时生成，让学习者能够进入图形、数字和涂色练习并继续挑战。

## Requirements

### Requirement: 选择题在有限步骤内生成互异且唯一正确的选项

图形规律和数字规律练习及限时挑战 MUST 在有限步骤内生成恰好四个互不相同的选项，其中 MUST 恰有一个选项符合当前规律。随机源重复返回相同值 MUST NOT 阻塞页面初始化、模式切换或挑战开始。

#### Scenario: 固定随机值下页面和练习模式仍可用
- **WHEN** 随机源持续返回 0 或接近 1，学习者打开页面并切换图形、数字和涂色模式
- **THEN** 页面完成初始化，各模式显示题目和完整选项或可填写网格，且交互仍可响应

#### Scenario: 图形练习及图形挑战展示唯一正确选项
- **WHEN** 学习者在随机源重复返回同一值时进入图形练习或开始图形挑战
- **THEN** 当前题目在有限步骤内展示四个互异选项，且其中恰有一个选项符合显示规律

#### Scenario: 数字练习及数字挑战展示唯一正确选项
- **WHEN** 学习者在重复随机值下进入数字练习或开始数字挑战
- **THEN** 当前题目在有限步骤内展示四个互异选项，且其中恰有一个选项符合显示规律

### Requirement: 涂色规律有限生成互异空格

涂色规律 MUST 在有限步骤内从网格选择 2 至 4 个互不相同的空格。重复随机值 MUST NOT 让网格生成卡住；每个空格 MUST 可按显示规律填色，并由检查按钮正确反馈。

#### Scenario: 重复随机值下生成可作答网格
- **WHEN** 随机源持续返回同一值且学习者进入涂色模式
- **THEN** 网格在有限步骤内显示 2 至 4 个不同的待填单元，页面保持响应

#### Scenario: 按规律填色并获得正确反馈
- **WHEN** 学习者按页面显示的行、列或对角线规律填完所有空格并检查答案
- **THEN** 页面接受所有正确颜色，显示完成反馈并提供下一题入口
