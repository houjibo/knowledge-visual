# chemistry-periodic-table-tab-navigation Specification

## Purpose
帮助高中化学学习者通过可感知、可聚焦的页签导航进入元素周期律的三个主题，并让辅助技术获知当前选择及其对应内容。

## Requirements

### Requirement: 元素周期律主题页签可访问
“元素周期律”页面的三个顶层主题入口 SHALL 作为带有可访问名称、选中状态和内容面板关联关系的水平页签呈现。页面 SHALL 在任一时刻只显示当前页签对应的主题内容，并让当前页签成为页签组唯一的 Tab 顺序入口。

#### Scenario: 页面初始加载
- **WHEN** 学习者打开元素周期律页面
- **THEN** “周期表结构”页签被选中且可通过 Tab 聚焦，另外两个页签不在独立的 Tab 顺序中，并且只有对应面板显示

#### Scenario: 使用水平键盘导航
- **WHEN** 学习者聚焦一个页签并按左方向键、右方向键、Home 或 End
- **THEN** 焦点按页签顺序移动并在两端循环或到达首尾，当前页签随焦点自动选中，选中状态与显示的面板同步更新

#### Scenario: 使用按钮激活或指针选择
- **WHEN** 学习者用 Enter、Space、鼠标或触摸选择一个页签
- **THEN** 对应页签变为选中状态并显示相关主题内容，其余主题面板隐藏

#### Scenario: 窄屏访问主题页签
- **WHEN** 学习者在 320 CSS 像素宽度浏览页面
- **THEN** 三个页签均可见、可操作并能换行布局，页面不出现横向溢出
