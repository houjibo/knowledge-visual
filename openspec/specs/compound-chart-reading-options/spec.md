# compound-chart-reading-options Specification

## Purpose
保障复式统计图读图练习在数据接近或相等时仍能提供完整、可判定的数值选项，让学习者能根据图表作答并从结果反馈中检查理解。

## Requirements

### Requirement: 数值读图题提供四个互异的非负整数选项
复式统计图读图练习中的数值题 SHALL 显示恰好四个互不相同的非负整数选项。

#### Scenario: 两组总量相等时求差
- **WHEN** 学习者回答两组总量相差题且两组总量相等
- **THEN** 练习显示四个互异的非负整数选项，且其中包含 0

#### Scenario: 候选干扰项重复
- **WHEN** 数值题根据当前数据生成的一个或多个干扰项与正确答案或其他干扰项相同
- **THEN** 练习仍显示四个互异的非负整数选项

### Requirement: 数值读图题保留唯一正确答案
复式统计图读图练习中的数值题 SHALL 在选项中包含且仅包含一个与当前图表数据计算结果相等的正确答案。

#### Scenario: 学习者选择正确结果
- **WHEN** 学习者选择与图表数据计算结果相等的选项
- **THEN** 练习判定为答对并更新正确计数

#### Scenario: 零差值答案
- **WHEN** 两组总量相等且正确差值为 0
- **THEN** 数值选项中恰有一个 0，选择它会获得正确反馈
