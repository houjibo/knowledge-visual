# high-function-correspondence-lab Specification

## Purpose
帮助高中学习者亲手构造有限数集之间的对应，比较漏配、一对多和合法多对一三种情况，理解函数要求定义域中每个输入恰有一个输出，并根据真正取到的函数值区分值域与陪域。

## Requirements

### Requirement: 构造并判定有限集合对应
函数概念页 SHALL 允许学习者编辑 A 中每个元素到 B 的箭头、预测是否为函数，并在核对后说明每个输入的对应数量。

#### Scenario: 合法多对一
- **WHEN** −2 和 2 都指向 4，0 指向 0
- **THEN** 判为函数，说明不同输入可以对应同一输出；值域为 {0,4}，B 中的 2 不属于值域

#### Scenario: 漏配与一对多
- **WHEN** 某个 A 元素没有箭头或同时指向两个不同 B 元素
- **THEN** 判为非函数，指出具体输入及其零个或多个输出，不称该关系具有函数值域

#### Scenario: 更改对应或预测
- **WHEN** 学习者修改任一箭头、函数判断或预测值域
- **THEN** 旧核对反馈消失，下一次核对按当前完整状态重新计算

### Requirement: 图文和输入可访问
对应图 SHALL 与矩阵选择一致，并提供等价文字；小屏与键盘可完成选箭头、预测和核对。

#### Scenario: 用键盘在窄屏操作
- **WHEN** 学习者在 320px 视口通过键盘修改对应并提交
- **THEN** 输入和反馈可见且可操作，无水平页面溢出
