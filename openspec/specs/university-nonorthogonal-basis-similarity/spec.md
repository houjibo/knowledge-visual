# university-nonorthogonal-basis-similarity Specification

## Purpose
规定大学线性代数非正交基有限工作台的精确运算、退化矩阵边界与学习完成条件。学习者应通过坐标乘回理解同一向量和线性变换在标准基与一般可逆基下的表示关系，并识别相关列无法构成平面基。

## Requirements

### Requirement: 精确非正交基坐标与相似矩阵
工作台 MUST 对有效的 2×2 有界整数基矩阵 W、变换矩阵 A 和向量 x，以精确有理数展示 `c=W⁻¹x`、`B=W⁻¹AW`，并核验 `Wc=x`、`AW=WB`、`W(Bc)=Ax` 及迹、行列式不变。

#### Scenario: 分数坐标
- **WHEN** 学习者选择 det(W) 非零且坐标为分数的例子
- **THEN** 页面保留简分数，显示同一变换在两种坐标中的矩阵与乘回

### Requirement: 线性相关列的边界
工作台 MUST 在 det(W)=0 时拒绝计算 W⁻¹、c 或 B，并根据 x 是否在列空间，区分坐标不唯一与无法表示；零矩阵也 MUST 有明确反馈。

#### Scenario: 相关列且 x 在列空间
- **WHEN** W 的两列相关而 x 在其列空间
- **THEN** 页面说明两列不能成为 R² 的基、表示不唯一且 B 未定义

### Requirement: 预测反馈与完成
工作台 MUST 逐项核对行列式、是否为基，并在有效基下核对 c 的两项及 B₁₁；主动揭示不记录完成，相关列分支不能单独记录完成，编辑或无效输入清除旧结果。

#### Scenario: 先错后改
- **WHEN** 学习者先答错 B₁₁ 后改正
- **THEN** 页面先提示错误项，改正后显示相似矩阵和乘回并记录完成
