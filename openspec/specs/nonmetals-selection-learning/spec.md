# nonmetals-selection-learning Specification

## Purpose
为高中非金属学习提供可由键盘、鼠标和触屏操作的元素及反应选择，保持焦点、选中态、真实图示和文字说明一致，明确电子层示意与反应标签边界，并保护已有练习、计分和本机进度。

## Requirements

### Requirement: 元素与具体反应可由单选组操作
页面 MUST 将8个元素和当前系列6条转化分别呈现为有名称的单选组，选项为原生button且有radio语义、名称及aria-checked。组内 MUST 只有一个Tab入口；右/下方向键选择下一项、左/上选择前一项并循环，Home/End选择首尾。Enter/Space、鼠标和触屏 MUST 可激活，焦点可见且选中项不重复计数。

#### Scenario: 元素初始与切换
- **WHEN** 进入元素面板并用键盘遍历八项
- **THEN** 默认Cl唯一选中，焦点、选中态、属性与当前元素图同步，只有所选元素可作为组内Tab入口

#### Scenario: 反应初始未选
- **WHEN** 首次进入转化面板并Tab到第一条转化
- **THEN** 全部反应仍未选、详情显示中性提示，按Space后才选择第一条并展示方程与条件

### Requirement: 激活选择不删除焦点或误清状态
选择具体反应 MUST 原位更新状态，不删除当前焦点节点；重复选择当前元素、反应和系列 MUST 幂等。实际切换系列 MUST 清除旧反应及详情，列表重建后焦点仍在有效系列选项或新有效节点，返回主题 MUST 保留当前选择。

#### Scenario: 连续键盘选择
- **WHEN** 一条反应被激活后继续按方向键及Enter/Space
- **THEN** 当前焦点节点仍连接文档，选择和详情正确更新，不跳回body或页首

#### Scenario: 同系列重复激活
- **WHEN** 已选择氮系列一条反应后再次激活氮系列
- **THEN** 该反应、详情和高亮保持，实际切到硫系列时才清空

### Requirement: 可视化与可读说明来自同一选择数据
初始化与选择后 MUST 用同一数据生成元素属性和电子层替代说明；转化摘要和画布替代 MUST 列出当前数组中真实关系，并明确当前未选或已选反应的方程和条件。替代说明 MUST 在选择事件更新，不随每帧反复播报。元素图 MUST 明确为电子层与族区域示意，不把区域框或电子轨迹说成真实周期表或真实轨迹。

#### Scenario: 电子层说明与实际绘制
- **WHEN** 选择Cl、S、N、Si、O、F、C、P
- **THEN** 原子序数和电子分布分别为17/2-8-7、16/2-8-6、7/2-5、14/2-8-4、8/2-6、9/2-7、6/2-4、15/2-8-5，属性、画布标签与绘制一致

#### Scenario: 氮系列摘要不漂移
- **WHEN** 显示氮系列图及说明
- **THEN** 摘要对应实际六条转化，包含HNO₃→NO₂及N₂→NO，不把不存在的硝酸盐中和边写成本图关系

#### Scenario: 已选反应替代
- **WHEN** 选择硫酸与Cu反应的转化项
- **THEN** 方程、条件与画布高亮一致，浓硫酸限定保留，并将数据标签称为本页标签而不作统一反应分类

### Requirement: 元素示例与模型边界准确
碳的单质状态 MUST 不概括为全为黑色，说明固体石墨和金刚石示例；氧的常见化合价 MUST 包含-1及-2以对应过氧化氢。页面 MUST 提供核验来源，现有十二条转化方程及练习题设/完成门槛保持原行为。

#### Scenario: 碳与氧选择
- **WHEN** 分别选择碳和氧
- **THEN** 碳显示含石墨、金刚石的固体示例，氧显示-1/-2及H₂O₂，其他属性保持原数据

### Requirement: 选择路径在本地与窄屏下可用且不改变学习分数
新增选择路径 MUST 在320px、减少动态、file与项目子路径可用；减少动态时元素电子位置静止，画布不可用时文字选择可继续。探索选择 MUST 不修改练习答案、得分或完成存储，既有异常存储行为仍有效。

#### Scenario: 选择与练习隔离
- **WHEN** 已答一道题后遍历元素和两系列反应，再返回练习
- **THEN** 原答案、得分、已答数与原进度记录保持，不因探索触发完成

#### Scenario: 无画布及窄屏
- **WHEN** 320px下禁用2D上下文或直接打开文件
- **THEN** 元素和反应仍可键盘选择，文字信息及状态可读，无页面横向溢出或脚本错误
