# slider-crank-simulation Specification

## Purpose
为无学段的模拟世界提供可观察旋转与往复关系的曲柄滑块场景，以刚性无偏置几何统一图形、读数和时间，明确行程、路程与模型边界，保障暂停、手动、键盘、移动和静态发布体验。

## Requirements

### Requirement: 共线曲柄滑块几何与读数
场景 MUST 用刚性无偏置几何计算曲柄、连杆与滑块位置，共同比例显示SVG，读数与真实图形同步。MUST 区分单程行程2r及整圈往返路程4r，并解释旋转匀速时滑块通常非匀速。

#### Scenario: 极端尺寸与四个关键角度
- **WHEN** r=60mm、l=100mm，依次选0/90/180/270/360°
- **THEN** 从外止点位移分别为0/80/120/80/0mm，滑块沿导轨且两杆长度始终60/100mm

#### Scenario: 只改连杆长度
- **WHEN** 同曲柄半径下切换连杆100和200mm
- **THEN** 中间角度位置变化，但行程保持2r；角度和半径保留

### Requirement: 可控时间和无意播放保护
场景 MUST 初始暂停，支持开始、暂停、15°步进、手动角度、全重置，按实际经过秒数和rpm计算角度。修改参数/角度/预设/步进 MUST 暂停；隐藏页面或减少动态偏好变化 MUST 暂停且不自动恢复。

#### Scenario: 步进绕回与重置
- **WHEN** 手动角度350°后步进一次
- **THEN** 角度为5°且暂停；重置后为40/140/30rpm/0°暂停

#### Scenario: 暂停及偏好变化
- **WHEN** 播放后暂停、隐藏页面或启用减少动态
- **THEN** 角度保持，返回页面不隐式播放，仍可手动探索

### Requirement: 可访问静态集成
场景 MUST 提供原生标签控件、可见焦点、读数文字和示意边界，在320px与file直接打开可用，不写学科进度。MUST 从模拟目录及首页分类搜索进入，发布子路径资源可解析。

#### Scenario: 键盘与文件直开
- **WHEN** 学习者离线直接打开文件并用键盘改变角度和步进
- **THEN** 图形与读数更新，无外部资源请求，无学习进度写入

#### Scenario: 发布目录发现
- **WHEN** 在公开站模拟目录或首页模拟分类搜索曲柄
- **THEN** 可进入曲柄滑块模拟并操作，导航返回正确子路径
