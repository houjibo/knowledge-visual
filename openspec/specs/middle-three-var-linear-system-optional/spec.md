# middle-three-var-linear-system-optional Specification

## Purpose
通过固定整数系数的三元一次方程组选学案例，帮助初中学习者掌握“两次消元、化三元为一元”的求解思路，作为二元一次方程组必学内容之后的选学补充。

## Requirements

### Requirement: 演示三元到一元的消元化归

学习页面 MUST 展示每个固定方程组通过两次消元逐步化为二元、再化为一元求解并回代的步骤，并说明其核心是消元化归思想。步骤说明 MUST 与参考解一致。

#### Scenario: 学习者查看消元步骤
- **WHEN** 学习者在学习模式查看一个三元方程组案例
- **THEN** 页面按“消去同一未知数→二元方程组→再消元→一元解→回代求其余未知数”的顺序展示可核对步骤

### Requirement: 校验三元整数解

求解模式 MUST 让学习者为固定案例输入 x、y、z 三个未知数，模型 MUST 校验是否等于参考整数解；全部正确才判为正确，任一错误给出反馈并允许重试。模型 MUST 拒绝非有限数或注入字符串等非法输入。

#### Scenario: 错误解被拒绝并可重试
- **WHEN** 学习者提交的三个未知数中有一个与参考解不符
- **THEN** 页面提示至少一项不正确且不标记完成，学习者可修改后重新提交

#### Scenario: 非法输入被拒绝
- **WHEN** 学习者输入空值、`Infinity` 或包含脚本标签的内容
- **THEN** 模型返回无效状态，页面提示输入需为有效数字，且不执行任何注入内容

### Requirement: 标注选学边界

页面 MUST 显著标注本内容为选学、不作为考试要求，并与二元一次方程组必学页面建立前置链接；不得把选学内容描述为必修要求。

#### Scenario: 学习者识别选学属性
- **WHEN** 学习者打开页面
- **THEN** 页面可见“选学内容，不作为考试要求”的说明，并提供到二元一次方程组页面的链接

### Requirement: 本地数据与无外部请求

页面 MUST 使用固定、合成的教学案例，不收集自由文本、不发送网络请求、不连接外部服务。

#### Scenario: 离线可用
- **WHEN** 页面在无网络的本地或发布子路径中打开
- **THEN** 所有求解与反馈逻辑仍可运行，且不发起任何第三方请求

### Requirement: 键盘与窄屏可用

页面的求解输入与按钮 MUST 可通过键盘操作，在 320px 宽视口下无横向溢出。

#### Scenario: 窄屏键盘完成求解
- **WHEN** 学习者在 320px 视口用键盘聚焦输入并提交正确整数解
- **THEN** 页面给出正确反馈，且文档宽度不超过视口宽度
