# primary-computer-sequential-search Specification

## Purpose
让小学学习者通过预测比较次数和逐张查看固定数字卡片，理解顺序查找从第一项开始、遇到目标立即停止、全部检查后才能判断未找到，并在本机可靠记录两类练习的完成状态。

## Requirements

### Requirement: 逐项比较并在正确时刻终止
主题 MUST 从第一张开始每步只比较当前卡片与目标，显示本次卡片、比较结果、累计次数和下一张。命中 MUST 立刻停止；未命中 MUST 比较完全部五张才报告目标不在这组卡片中。更换预置顺序 MUST 影响比较顺序，不得通过预知目标直接跳到匹配项。

#### Scenario: 第一张与末张命中
- **WHEN** 目标分别位于第一张和第五张，学习者逐步执行
- **THEN** 分别比较 1 次和 5 次后报告正确位置，终止后额外执行不增加比较次数

#### Scenario: 不存在的目标
- **WHEN** 选择不在五张卡片中的 9 并执行
- **THEN** 依次比较五张后才报告未找到，比较次数为 5

### Requirement: 预测与两类练习才获得完成资格
学习者 MUST 在执行前预测比较次数，执行结束后才得知预测是否正确。只有分别完整执行且正确预测一次“找到”和一次“未找到”轮次才 SHALL 尝试记录 `computer/primary/sequential-search` 完成。错误预测、未执行完和重复同类轮次 SHALL 不提前完成或重复增加进度。

#### Scenario: 找到再未找到
- **WHEN** 学习者正确预测目标位于第三张时需比较 3 次，随后正确预测目标 9 不存在时需比较 5 次，并完整执行两轮
- **THEN** 页面说明两类练习完成，尝试写入一次独立的顺序查找完成记录

### Requirement: 参数与运行状态不串轮
主题 MUST 提供单步、连续执行、暂停、重新查找及恢复示例。更换排列或目标 MUST 停止自动推进并清空本轮比较记录；执行中不得修改该轮预测。重新查找 MUST 保留当前参数，恢复示例 MUST 还原默认参数。两类已正确练习及已赢得但尚未保存的资格 MUST 跨本轮重置保留。

#### Scenario: 自动执行中改目标
- **WHEN** 连续执行一到两次比较后学习者更换目标
- **THEN** 旧计时器停止，新轮从第 1 张与 0 次比较开始，不继续追加旧比较轨迹

### Requirement: 保存状态准确且可重试
主题 MUST 仅在 `SubjectProgress.markComplete` 实际成功后声称保存成功；拒绝写入或损坏记录 MUST 不被覆盖，已赢得资格 MUST 可在恢复存储后重试保存。已有完成记录不得被误称为当前轮完成。

#### Scenario: 赢得资格后存储失败并重置
- **WHEN** 两类预测完成但保存被拒绝，随后重置本轮并恢复存储
- **THEN** 页面仍可重试保存之前赢得的资格，且不把当前零比较状态描述为刚完成

### Requirement: 本地可访问且可被发现
主题 MUST 有原生键盘控件、可见焦点、文字状态、320px 无横向溢出，并在 file 协议及 GitHub Pages 子路径下加载本地脚本；首页搜索、小学目录和计算机进度 SHALL 发现及计入新增主题。

#### Scenario: 离线窄屏学习
- **WHEN** 学习者在 320px 直接打开本地 HTML，并用键盘选择目标、预测及单步
- **THEN** 五张卡片、比较轨迹、结果和进度反馈正常，不向远程地址请求运行资源
