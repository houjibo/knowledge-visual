# bounded-multiplication-table-practice Specification

## Purpose
保证小学乘法口诀表中的填空和看积找口诀练习能够及时生成答案语义正确的选项，使学习者在重复或边界随机输入下仍可开始并继续练习。

## Requirements

### Requirement: 填空练习有限生成唯一正确答案

填空练习 MUST 在有限步骤内生成恰好四个互不相同、范围为 1–81 的整数选项，其中 MUST 恰有一个选项满足题目中的乘法等式。选项生成 MUST 在随机源重复返回同一数值时仍然结束。

#### Scenario: 页面加载时填空题可及时生成
- **WHEN** 随机源在页面加载期间持续返回相同值，包括 0、0.5 或接近 1 的值
- **THEN** 页面在有限步骤内完成加载并生成四个互不相同的填空选项

#### Scenario: 三类缺项题只有一个正确答案
- **WHEN** 填空题分别缺少乘积、前一个因数或后一个因数
- **THEN** 四个选项中恰有一个整数满足显示的乘法等式，其他选项均不满足

#### Scenario: 正确作答后继续填空
- **WHEN** 学习者选择当前填空题的正确答案并等待反馈结束
- **THEN** 页面显示答对反馈并在有限步骤内生成下一道含四个互异选项的填空题

### Requirement: 看积找口诀有限生成并保留全部正确口诀

看积找口诀练习 MUST 在有限步骤内为显示的乘积生成恰好四个互不相同的规范因数对，其中每一对均满足 `1 ≤ a ≤ b ≤ 9`，所有可组成该积的因数对 MUST 保留，其余选项 MUST 不能组成该积。生成过程 MUST 在随机源重复返回同一数值时仍然结束。

#### Scenario: 页面加载时找口诀题可及时生成
- **WHEN** 随机源在页面加载期间持续返回相同值，包括 0、0.5 或接近 1 的值
- **THEN** 页面在有限步骤内完成加载并为看积找口诀题生成四个互异因数对

#### Scenario: 有多个正确口诀时全部保留
- **WHEN** 当前乘积在 1–9 的规范因数对中有多个正确口诀
- **THEN** 每个正确因数对都作为正确选项呈现，其他选项为互异且乘积不匹配的规范因数对

#### Scenario: 正确选择后继续找口诀
- **WHEN** 学习者选择任意一个当前乘积的正确口诀并等待反馈结束
- **THEN** 页面显示对应口诀反馈并在有限步骤内生成下一题的四个因数对
