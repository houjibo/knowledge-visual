# simulation-world-gear-transmission Specification

## Purpose
让学习者通过可操作的齿轮对观察齿数、转速、转矩与效率之间的关系，并清楚区分定量关系示意和真实机械设计。

## Requirements

### Requirement: 齿轮传动模拟依据齿数计算输出

齿轮传动场景 MUST 展示一对外啮合齿轮，并允许调整输入齿数、输出齿数、输入转速、输入转矩和效率。页面 MUST 提供单位明确的输入/输出读数和关系说明：输出转速 MUST 等于输入转速乘以输入齿数再除以输出齿数；输出转矩 MUST 等于输入转矩乘以输出齿数再除以输入齿数再乘以效率。效率以 0 到 1 的比例参与计算。

#### Scenario: 小齿轮驱动大齿轮
- **WHEN** 输入齿数为 12、输出齿数为 48、输入转速为 60 rpm、输入转矩为 10 N·m 且效率为 90%
- **THEN** 页面显示输出转速为 15 rpm、输出转矩为 36 N·m，且输出功率为输入功率的 90%

#### Scenario: 大齿轮驱动小齿轮
- **WHEN** 输入齿数为 48、输出齿数为 12、输入转速为 60 rpm、输入转矩为 10 N·m 且效率为 90%
- **THEN** 页面显示输出转速为 240 rpm、输出转矩为 2.25 N·m，且输出功率为输入功率的 90%

#### Scenario: 零输入转速
- **WHEN** 学习者将输入转速设为零
- **THEN** 输入和输出转速及功率均为零，齿轮动画停止

### Requirement: 动画展示外啮合齿轮的方向与传动比例

输入齿轮和输出齿轮 MUST 以相反方向旋转；两者角速度 MUST 与齿数比一致。学习者 MUST 能启动和暂停动画，改变控制值后视觉齿轮与读数 MUST 使用相同的当前输入值。

#### Scenario: 正常传动时观察方向和速度比
- **WHEN** 学习者以非零输入转速启动模拟
- **THEN** 两个齿轮以相反方向旋转，且较大齿数齿轮的角速度较低

#### Scenario: 暂停和重新启动
- **WHEN** 学习者暂停齿轮动画并再次启动
- **THEN** 暂停期间齿轮不移动，启动后按当前转速和齿数比继续显示

### Requirement: 齿轮模型遵守功率边界并说明简化假设

输出功率 MUST 等于输入功率乘以设定效率，且 MUST NOT 大于输入功率。页面 MUST 说明这是单级外啮合齿轮的示意模型，效率为固定设定值；模型不计算齿面接触、惯性、温升、润滑或真实机械负载，结果不得表述为工程选型或实机预测。改变效率 MUST 改变输出转矩/功率但 MUST NOT 改变由齿数决定的转速比。

#### Scenario: 观察效率损耗
- **WHEN** 学习者降低传动效率但保持齿数、输入转速和输入转矩不变
- **THEN** 输出转速不变，输出转矩和输出功率按效率降低，且输出功率仍不高于输入功率

#### Scenario: 查看模型适用边界
- **WHEN** 学习者查看模型说明
- **THEN** 页面能读到单级外啮合齿轮和固定效率假设，以及未模拟的真实机械因素

### Requirement: 齿轮场景支持键盘、辅助技术和减少动态效果偏好

所有齿轮参数 MUST 有可访问名称并可用键盘调节；动画按钮 MUST 可由键盘操作；齿轮画面 MUST 有随参数更新的文字替代，且页面 MUST 显示可见焦点。启用减少动态效果偏好时，场景 MUST 默认暂停并允许学习者主动启动。

#### Scenario: 键盘调节传动参数
- **WHEN** 学习者通过 Tab 聚焦参数控件并使用方向键调整齿数、转速、转矩或效率
- **THEN** 控件值、数值读数和齿轮文字替代同步更新，焦点保持可见

#### Scenario: 减少动态效果时主动运行
- **WHEN** 浏览器启用减少动态效果偏好并首次打开场景
- **THEN** 齿轮保持静止，学习者仍可通过动画按钮主动启动或暂停

#### Scenario: 窄屏浏览
- **WHEN** 学习者在 320 CSS 像素宽度访问场景
- **THEN** 模型说明、输入控件和输出关系均可见，页面不产生横向溢出

#### Scenario: 画布绘制不可用
- **WHEN** 浏览器不能创建二维画布上下文
- **THEN** 页面显示可理解的状态提示，公式、输入控件及数字结果仍可使用
