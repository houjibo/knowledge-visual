# university-linear-system-signed-input Specification

## Purpose
约束大学线性方程组高斯消元面板的系数输入、方程预览与实际计算使用同一组有符号数，并在输入无效时撤销旧求解状态，避免教学展示与计算结果相互矛盾。

## Requirements

### Requirement: 展示方程与计算系数一致
高斯消元面板 MUST 使用明确的带符号系数输入，方程预览、初始增广矩阵和最后解 MUST 由同一有效输入生成。

#### Scenario: 正负零系数
- **WHEN** 学习者输入正数、负数和零系数
- **THEN** 方程预览显示相应加减号，增广矩阵保留同一有符号数，消元结果能代回原方程

### Requirement: 无效输入不生成误导解
输入为空、非有限数或超出限定范围时 MUST 报告字段错误、停止自动播放、清除旧求解结果并禁用下一步；修复后从新矩阵的初始状态开始。

#### Scenario: 修改一个已求解系统为无效输入再修复
- **WHEN** 学习者清空一项系数或输入越界值
- **THEN** 旧解不可见且不能继续播放；输入恢复有效后可重新消元，显示新系统的结果
