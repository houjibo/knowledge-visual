📝 互动练习

1. 关于磁感线，下列说法正确的是？

A. 磁感线是磁场中实际存在的曲线
B. 磁感线从 N 极出发，终止于 S 极
C. 磁感线上某点的切线方向表示该点的磁场方向
D. 两条磁感线可以相交
答案：C
A 错：磁感线是假想的曲线，不是实际存在的。
B 错：磁感线是闭合曲线，外部从 N→S，内部从 S→N。
C 对：磁感线的切线方向 = 该点磁场方向 = 小磁针 N 极指向。
D 错：如果相交，交点处将有两个磁场方向，这不可能。

2. 一根长 0.2m 的导线，通以 3A 的电流，放在磁感应强度为 0.5T 的匀强磁场中，当导线与磁场方向垂直时，受到的安培力为？

A. 0.15 N
B. 0.3 N
C. 0.6 N
D. 1.5 N
答案：B
F = BIL = 0.5 × 3 × 0.2 = 0.3 N
当导线与磁场垂直时，sinθ = sin90° = 1，安培力最大。

3. 带电粒子垂直射入匀强磁场做匀速圆周运动，若增大磁感应强度 B，则？

A. 轨道半径增大，周期增大
B. 轨道半径减小，周期减小
C. 轨道半径增大，周期减小
D. 轨道半径减小，周期不变
答案：B
r = mv/(qB)：B 增大 → r 减小 ✓
T = 2πm/(qB)：B 增大 → T 减小 ✓
注意：周期 T 与速度 v 无关，只与 m、q、B 有关。

4. 关于洛伦兹力，下列说法正确的是？

A. 洛伦兹力可以对带电粒子做功
B. 洛伦兹力不改变带电粒子的速率
C. 洛伦兹力的方向与粒子运动方向平行
D. 静止在磁场中的电荷一定受洛伦兹力
答案：B
A 错：洛伦兹力始终垂直于速度方向，不做功。
B 对：不做功 → 不改变动能 → 不改变速率。
C 错：洛伦兹力垂直于速度方向（和磁场方向组成的平面垂直）。
D 错：f = qvB，v = 0 时 f = 0，静止电荷不受洛伦兹力。

5. 在地球磁场中，一个带正电的宇宙射线粒子从赤道上空竖直向下射向地面，它将向哪个方向偏转？

A. 向东
B. 向西
C. 向南
D. 向北
答案：B
赤道处地磁场方向水平向北。粒子竖直向下运动（v 向下），正电荷。
用左手定则：四指指向 v（向下），弯向 B（向北），大拇指指向西。
所以洛伦兹力方向向西，粒子向西偏转。
