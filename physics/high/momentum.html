📖 核心概念

• 动量 p = mv：描述物体运动状态的物理量，是矢量

• 冲量 I = FΔt：力对时间的累积效应

• 动量定理：合外力的冲量等于物体动量的变化

• 动量定理揭示了力-时间-动量变化三者的内在联系

📖 碰撞分类

• 完全弹性碰撞：动量守恒 + 动能守恒（e=1）

• 一般碰撞：动量守恒，动能部分损失（0<e<1）

• 完全非弹性碰撞：动量守恒，动能损失最大，碰后粘在一起（e=0）

📖 反冲原理

• 系统初始静止，总动量为零

• 抛射物向前飞出 → 主体向后反冲

• Mv₁ = mv₂（动量等大反向）

• 应用：火箭发射、枪械后坐力、章鱼喷水推进

📝 动量练习

题目 1：冲量计算

一个质量为 2kg 的物体以 3m/s 的速度运动，受到一个与运动方向相同的 10N 的力作用 2s，求末动量。

答案：C
初动量 p₀ = mv₀ = 2×3 = 6 kg·m/s
冲量 I = FΔt = 10×2 = 20 N·s
由动量定理：p = p₀ + I = 6 + 20 = 26 kg·m/s

题目 2：碰撞问题

质量分别为 1kg 和 3kg 的A、B两球，A以 4m/s 向右运动，B静止。发生完全弹性碰撞后，A的速度为？

答案：A
完全弹性碰撞公式：
v₁' = (m₁-m₂)v₁/(m₁+m₂) = (1-3)×4/(1+3) = -8/4 = -2 m/s
v₂' = 2m₁v₁/(m₁+m₂) = 2×1×4/4 = 2 m/s
验证：动量 1×(-2)+3×2 = 4 ✓，动能 ½×1×4+½×3×4 = 8 ✓

题目 3：反冲运动

质量为 200kg 的小船上站着一个 50kg 的人，船静止在水面。人以 4m/s（相对地面）向前跳上岸，忽略水的阻力，船的速度为？

答案：B
系统初始静止，总动量为零。
由动量守恒：m人v人 + m船v船 = 0
50×4 + 200×v船 = 0
v船 = -200/200 = -1 m/s（向后）
