🔴 α 衰变
原子核放出 α 粒子（⁴₂He，2 质子 + 2 中子），质量数 A 减 4，电荷数 Z 减 2。例：²³⁸U → ²³⁴Th + α。穿透力弱，电离能力强。
🔵 β 衰变
中子转化为质子并放出电子（β⁻）和反中微子：n → p + e⁻ + ν̄ₑ。A 不变，Z 加 1。例：¹⁴C → ¹⁴N + e⁻ + ν̄ₑ。
🟣 γ 衰变
激发态原子核跃迁到基态，放出高能光子 γ。A 和 Z 均不变。穿透力最强，需铅板或厚混凝土屏蔽。
🟡 结合能与裂变/聚变
比结合能曲线在 Fe-56 处达极大（≈ 8.8 MeV/核子）。重核裂变（²³⁵U + n → ¹⁴¹Ba + ⁹²Kr + 3n + 200 MeV）与轻核聚变（²H + ³H → ⁴He + n + 17.6 MeV）都释放能量。
