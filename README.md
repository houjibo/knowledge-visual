# 知识可视化学习站

一个面向不同学段学习者的交互式学习网站，覆盖数学、物理、化学、科学、计算机、人工智能和模拟世界。通过图示、动画、可操作的图表与练习，帮助学习者观察变化、理解概念并检验自己的判断。

**在线站点：**[打开知识可视化学习站](https://houjibo.github.io/knowledge-visual/)

**项目代码：**[GitHub 仓库](https://github.com/houjibo/knowledge-visual)

## 学习内容

- **数学：**小学、初中、高中和大学主题
- **物理：**初中、高中和大学主题
- **化学：**初中、高中和大学主题
- **科学：**小学主题
- **计算机：**小学顺序、循环、条件分支与逐项查找，初中数据表示
- **人工智能：**小学分类线索、初中数据质量、信息最小化与回答核验、高中模型评价、大学神经网络入门
- **模拟世界：**太阳系、齿轮传动、曲柄滑块与工业流水线，动手观察天体运动、机械传动、往复运动和生产流程中的排队与瓶颈；该分类不计入学科进度

## 如何使用

### 在线学习

打开[在线站点](https://houjibo.github.io/knowledge-visual/)，按学科、学段或模拟场景找到主题。使用页面中的动画、图表、滑块和练习探索内容；学科主题的学习进度保存在当前浏览器中。

### 本地预览

项目是静态网页，无需安装依赖或构建。克隆仓库后，在项目目录运行：

```sh
git clone https://github.com/houjibo/knowledge-visual.git
cd knowledge-visual
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。
