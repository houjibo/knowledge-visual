# 知识可视化学习站

一个面向不同学段学习者的交互式学习网站，覆盖数学、物理、化学、科学、计算机和人工智能。通过图示、动画、可操作的图表与练习，帮助学习者观察变化、理解概念并检验自己的判断。

**在线站点：**[打开知识可视化学习站](https://houjibo.github.io/knowledge-visual/)

**项目代码：**[GitHub 仓库](https://github.com/houjibo/knowledge-visual)

## 学习内容

- **数学：**小学、初中、高中和大学主题
- **物理：**初中、高中和大学主题
- **化学：**初中、高中和大学主题
- **科学：**小学主题
- **计算机：**小学算法、初中数据表示
- **人工智能：**高中分类器、大学神经网络入门

## 如何使用

### 在线学习

打开[在线站点](https://houjibo.github.io/knowledge-visual/)，选择学科、学段和主题。使用页面中的动画、图表、滑块和练习探索内容；学习进度保存在当前浏览器中。

### 本地预览

项目是静态网页，无需安装依赖或构建。克隆仓库后，在项目目录运行：

```sh
git clone https://github.com/houjibo/knowledge-visual.git
cd knowledge-visual
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。
